# Поля

Поля сопоставляют произвольным точкам двумерного пространства значения. Эти руководства помогут
преобразовать разрозненные измерения, управляющие точки или значения на кривых в непрерывные
данные, которые можно вычислять напрямую или растеризовать в изображение.

## Выберите способ построения поля

| Задача | С чего начать |
| --- | --- |
| Вычислить значение по формуле или получить его из внешнего источника | Реализуйте <xref:Akeldov.Math.Spatial2D.Fields.IField`1>, <xref:Akeldov.Math.Spatial2D.Fields.IFloatField> или <xref:Akeldov.Math.Spatial2D.Fields.IIntField>. |
| Интерполировать вещественные значения, привязанные к точкам | <xref:Akeldov.Math.Spatial2D.Fields.FloatPointInfluenceSource> и <xref:Akeldov.Math.Spatial2D.Fields.FloatPointInfluenceField>. |
| Назначать целочисленные или логические значения по точечным источникам | <xref:Akeldov.Math.Spatial2D.Fields.IntPointInfluenceField> или <xref:Akeldov.Math.Spatial2D.Fields.BoolPointInfluenceField>. |
| Изменять вещественное значение вдоль пути или границы | <xref:Akeldov.Math.Spatial2D.Fields.FloatCurveInfluenceSource> и <xref:Akeldov.Math.Spatial2D.Fields.FloatCurveInfluenceField>. |
| Преобразовать поле в пиксели | Задайте <xref:Akeldov.Math.Spatial2D.Rasterization.RasterGeometry> и растеризуйте поле по центрам его ячеек. |

При построении поля влияния нужно сделать три выбора:

1. Источники определяют, откуда берутся значения и насколько сильно они влияют на результат.
2. Необязательный отсекатель выбирает локальные источники для каждой вычисляемой точки.
3. Семплер объединяет вклады выбранных источников в значение поля.

Ограниченные вещественные и целочисленные поля проверяют результат и ограничивают его своим
публичным диапазоном значений.

## Выберите способ объединения источников

| Требуемый результат | Семплер |
| --- | --- |
| Резкие территории вокруг ближайшего источника | <xref:Akeldov.Math.Spatial2D.Fields.NearestInfluenceSampler`2> или типизированный семплер ближайшего источника. |
| Плавная смесь с учётом расстояния и веса источника | <xref:Akeldov.Math.Spatial2D.Fields.InverseDistanceWeightedFloatSampler`1>. |
| Кусочно-линейные значения внутри локальных треугольников источников | <xref:Akeldov.Math.Spatial2D.Fields.BarycentricFloatSampler`1>, обычно вместе с <xref:Akeldov.Math.Spatial2D.Fields.DelaunayCuller`1>. |

Отсечение меняет не только стоимость вычислений, но и окрестность интерполяции. Используйте
<xref:Akeldov.Math.Spatial2D.Fields.DelaunayCuller`1> для локальной интерполяции по треугольникам
или <xref:Akeldov.Math.Spatial2D.Fields.HalfPlaneCuller`1>, чтобы исключить источники, скрытые за
границами полуплоскостей более близких источников.

## Практические руководства

  её в PNG.
