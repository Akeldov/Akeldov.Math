# Разбить объекты с помощью взвешенного Вороного

Взвешенное разбиение Вороного распределяет существующие расположенные объекты по смысловым
группам. Каждая группа принадлежит настроенному сайту; увеличение веса позволяет сайту получать
элементы с большего расстояния. Результат содержит группы элементов, а не геометрию
многоугольных ячеек Вороного.

## Определите расположенные элементы

Тип элемента должен реализовать <xref:Akeldov.Math.Spatial2D.IHasPosition2D>. Его `Position`
сравнивается с настроенными сайтами.

```csharp
using Akeldov.Math.Spatial2D;

public sealed class MapCell : IHasPosition2D
{
    public MapCell(string id, PointXY position)
    {
        Id = id;
        Position = position;
    }

    public string Id { get; }

    public PointXY Position { get; }
}
```

Создайте непустую коллекцию элементов с конечными положениями:

```csharp
var items = new[]
{
    new MapCell("west", new PointXY(20f, 30f)),
    new MapCell("center", new PointXY(50f, 30f)),
    new MapCell("east", new PointXY(80f, 30f)),
    new MapCell("far-east", new PointXY(105f, 30f))
};
```

## Настройте взвешенные сайты

<xref:Akeldov.Math.Spatial2D.Partitioning.Voronoi.Site> объединяет конечное положение с
неотрицательным весом. При равных весах распределение сводится к сравнению расстояний до сайтов.

```csharp
using Akeldov.Math.Spatial2D.Partitioning.Voronoi;

var sites = new[]
{
    new Site(new PointXY(25f, 30f), weight: 1f),
    new Site(new PointXY(95f, 30f), weight: 2f)
};
```

В стороне от точного положения сайта конечные сайты с положительным весом сравниваются по
квадрату расстояния, делённому на квадрат веса. Поэтому второй сайт в примере может получить
элемент `center`, хотя геометрически тот находится ближе к первому сайту.

Для обычного взвешенного разбиения используйте конечные положительные веса. Особые случаи заданы
явно:

- сайт в точном положении элемента побеждает до сравнения взвешенных расстояний;
- сайт с нулевым весом получает только совпадающие с ним элементы;
- при наличии сайтов с положительным бесконечным весом ближайший из них получает каждый
  несовпадающий элемент;
- как минимум один настроенный сайт должен иметь положительный вес.

## Разбейте элементы

Выберите <xref:Akeldov.Math.Spatial2D.Partitioning.Voronoi.EmptyCellPolicy> явно, чтобы размер
результата соответствовал требованиям следующего этапа:

```csharp
using System.Collections.Generic;

var partitioner = new VoronoiItemPartitioner<MapCell>(
    sites,
    EmptyCellPolicy.LeaveAsIs);

IReadOnlyList<VoronoiItemPartition<MapCell>> partitions =
    partitioner.Partition(items);
```

При `LeaveAsIs` результат содержит по одному разделу на настроенный сайт в порядке сайтов.
Владеющий сайт доступен через `Site`, а назначенные объекты — через `Items`:

```csharp
VoronoiItemPartition<MapCell> westernPartition = partitions[0];
Site westernSite = westernPartition.Site;
IReadOnlyList<MapCell> westernItems = westernPartition.Items;
```

Список разделов доступен только для чтения, поскольку его порядок, размер и связи с сайтами
являются частью результата алгоритма. Каждая коллекция `Items` также представляет скопированную
структуру только для чтения.

## Обработайте пустые разделы

Некоторые сайты могут не получить элементов. Выберите политику с учётом требований потребителя:

| Политика | Поведение |
| --- | --- |
| `ThrowException` | Выбрасывает исключение, если любой конечный раздел пуст. Используется по умолчанию, если политика не передана. |
| `Exclude` | Удаляет пустые разделы; индексы результата больше не обязательно соответствуют всем настроенным сайтам. |
| `LeaveAsIs` | Сохраняет по одному разделу на сайт, включая пустые разделы. |

Используйте `ThrowException`, когда каждая следующая группа обязана содержать данные, `Exclude`,
когда важны только заполненные группы, и `LeaveAsIs`, когда важно соответствие индексов сайтов и
результата.

## Переместите сайты к центроидам элементов

Передайте `relaxationIterations`, если перед возвратом конечного результата сайты должны
сместиться к центроидам назначенных им элементов:

```csharp
var relaxedPartitioner = new VoronoiItemPartitioner<MapCell>(
    sites,
    relaxationIterations: 2,
    emptyCellPolicy: EmptyCellPolicy.LeaveAsIs);

IReadOnlyList<VoronoiItemPartition<MapCell>> relaxedPartitions =
    relaxedPartitioner.Partition(items);
```

Каждый заполненный сайт перемещается в центроид своих дискретных элементов с сохранением веса,
после чего элементы распределяются снова. Пустые сайты сохраняют прежние положения. Это не
вычисление центроидов непрерывных многоугольных ячеек, поэтому сайты в конечных разделах могут
отличаться от исходных настроенных положений.

## Проверьте входные данные

Коллекции сайтов и элементов должны быть непустыми. Положения сайтов и элементов должны быть
конечными, элементы не должны быть равны `null`, веса сайтов должны быть неотрицательными и не
равными `NaN`, а как минимум один сайт должен иметь положительный вес.

Подробное описание взвешенной метрики и контрактов владения см. в разделе
[Пространственные алгоритмы](../../concepts/spatial-algorithms.md). Чтобы сначала сгенерировать
равномерно разреженные положения сайтов, см. руководство
[Сгенерировать точки Пуассона](../sampling/generate-poisson-disk-points.md).
