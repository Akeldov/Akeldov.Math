# Точки и векторы

На этом шаге учебника вы зададите два положения, вычислите перемещение между ними и с помощью
этого перемещения построите новые точки. Продолжайте работу в проекте
`Spatial2D.Fundamentals`, созданном на предыдущем шаге.

## Создание двух точек

<xref:Akeldov.Math.Spatial2D.PointXY> задаёт положение в непрерывном двумерном пространстве.
Замените содержимое `Program.cs`:

```csharp
using Akeldov.Math.Spatial2D;

var start = new PointXY(1f, 1f);
var end = new PointXY(5f, 4f);

Console.WriteLine($"Начало: {start}");
Console.WriteLine($"Конец:  {end}");
```

Запустите приложение:

```powershell
dotnet run
```

Ожидаемый вывод:

```text
Начало: (1, 1)
Конец:  (5, 4)
```

Spatial2D использует декартовы координаты. Значения координат не привязаны к конкретной единице
измерения: они могут обозначать пиксели, метры или любые другие мировые единицы, последовательно
используемые в приложении.

## Вычисление перемещения

<xref:Akeldov.Math.Spatial2D.VectorXY> задаёт направление, перемещение или размер, а не положение.
При вычитании одной точки из другой получается вектор, направленный от правого операнда к левому.

Добавьте следующий код после объявлений точек:

```csharp
VectorXY displacement = end - start;
float distance = start.Distance(end);
VectorXY direction = displacement.Normalize();

Console.WriteLine($"Перемещение: {displacement}");
Console.WriteLine($"Расстояние:  {distance}");
Console.WriteLine($"Направление: {direction}");
```

Результат:

```text
Перемещение: (4, 3)
Расстояние:  5
Направление: (0.8, 0.6)
```

В `displacement` сохраняются и направление, и расстояние между точками. Вектор `direction`
направлен так же, но имеет единичную длину. Это удобно, когда требуется независимо задать новое
расстояние перемещения.

## Перенос точки

Сложение точки с вектором переносит точку. Умножение вектора на скаляр меняет его длину, поэтому
середину между `start` и `end` можно построить с помощью половины вектора перемещения:

```csharp
PointXY midpoint = start + displacement * 0.5f;
PointXY oneUnitPastEnd = end + direction;

Console.WriteLine($"Середина:                  {midpoint}");
Console.WriteLine($"На единицу дальше конца:   {oneUnitPastEnd}");
```

Результат:

```text
Середина:                  (3, 2.5)
На единицу дальше конца:   (5.8, 4.6)
```

Результатом переноса точки является другая точка. Напротив, вычитание двух точек возвращает
вектор. Разделение этих смыслов делает геометрические выражения наглядными:

```csharp
VectorXY offset = end - start; // положение - положение = перемещение
PointXY moved = start + offset; // положение + перемещение = положение
```

## Сравнение направлений

Скалярное произведение, псевдоскалярное векторное произведение и знаковый угол описывают взаимное
положение двух векторов:

```csharp
VectorXY right = VectorXY.BasisX;
VectorXY up = VectorXY.BasisY;

float dot = VectorXY.Dot(right, up);       // 0: векторы перпендикулярны
float cross = VectorXY.Cross(right, up);   // 1: up находится слева от right
float angle = VectorXY.Angle(right, up);   // PI / 2 радиан
```

`VectorXY.Angle` возвращает значение в радианах. Положительный угол означает поворот от первого
вектора ко второму против часовой стрелки, отрицательный — по часовой стрелке.
