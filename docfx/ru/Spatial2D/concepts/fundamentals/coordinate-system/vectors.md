# Векторы

Akeldov.Math.Spatial2D предоставляет два типа декартовых векторов:

- <xref:Akeldov.Math.Spatial2D.VectorXY> хранит компоненты одинарной точности с плавающей точкой
  и применяется для направлений, смещений, размеров и других непрерывных величин.
- <xref:Akeldov.Math.Spatial2D.VectorXYInt> — целочисленный аналог `VectorXY`. Он задаёт
  целочисленные направления, смещения и размеры, а также специальные значения API, например
  индексы и разрешения растров.

Оба типа — неизменяемые типы значений. Компоненты `X` и `Y` направлены вдоль тех же декартовых
осей, что и координаты [точек](points.md), но вектор задаёт направление или перемещение, а не
положение.

## Выбор типа вектора

Используйте `VectorXY` для геометрических вычислений и операций, способных дать дробный
результат. Выбирайте `VectorXYInt`, если целочисленность компонентов является частью контракта
предметной области, а не случайным свойством текущего представления.

| Свойство | `VectorXY` | `VectorXYInt` |
|---|---|---|
| Тип компонента | `float` | `int` |
| Типичный смысл | Направление, перемещение, размер в мировых единицах | Целочисленное направление, перемещение, размер, индекс или разрешение |
| Деление на скаляр | Деление с плавающей точкой | Целочисленное деление |
| Результат поворота | `VectorXY` | `VectorXY` |
| Преобразование из другого типа | Неявное; очень большие целые могут потерять точность | Явное с возможной потерей данных |

Не используйте `VectorXYInt` только потому, что текущие значения оказались целыми. Например,
после нормализации или поворота направление может стать дробным, поэтому его следует хранить в
`VectorXY`. Значения, обозначающие ячейки и элементы дискретной структуры, рассматриваются в
разделе [«Дискретные индексы»](discrete-indices.md).

## Создание и чтение векторов

Передайте декартовы компоненты конструкторам:

```csharp
using Akeldov.Math.Spatial2D;

var offset = new VectorXY(3f, 4f);
var resolution = new VectorXYInt(192, 128);

float offsetX = offset.X; // 3
float offsetY = offset.Y; // 4

int width = resolution.X;  // 192
int height = resolution.Y; // 128
```

Оба типа объявлены как `readonly struct`. При присваивании вектора переменной или передаче в
метод копируются его компоненты. Арифметическая операция или преобразование возвращает новый
вектор и не изменяет исходный.

Стандартные константы задают нулевой вектор, равные компоненты и направления базиса декартовой
системы:

```csharp
VectorXY zero = VectorXY.Zero;     // (0, 0)
VectorXY one = VectorXY.One;       // (1, 1)
VectorXY right = VectorXY.BasisX;  // (1, 0)
VectorXY up = VectorXY.BasisY;     // (0, 1)

VectorXYInt gridRight = VectorXYInt.BasisX; // (1, 0)
VectorXYInt gridUp = VectorXYInt.BasisY;    // (0, 1)
```

Компоненты можно получить и деконструкцией:

```csharp
var (x, y) = new VectorXY(3f, 4f);
```

`VectorXY` принимает любые значения `float`. На границе, где `NaN` и бесконечность не имеют
смысла, проверяйте свойство `IsFinite`:

```csharp
bool usableForGeometry = offset.IsFinite; // true
```

## Различие между положениями и перемещениями

<xref:Akeldov.Math.Spatial2D.PointXY> обозначает положение. Вектор может переносить это
положение, а вычитание двух точек создаёт вектор перемещения между ними:

```csharp
var start = new PointXY(2f, 3f);
var displacement = new VectorXY(4f, -1f);

PointXY end = start + displacement;       // (6, 2)
VectorXY measured = end - start;          // (4, -1)
PointXY restored = end - displacement;    // (2, 3)
```

Векторы можно складывать, поскольку перемещения можно последовательно применять. Точки нельзя
складывать, так как сумма двух положений не имеет однозначного геометрического смысла.

## Сложение, вычитание и масштабирование

Векторная арифметика выполняется покомпонентно:

```csharp
var a = new VectorXY(3f, 4f);
var b = new VectorXY(1f, 2f);

VectorXY sum = a + b;        // (4, 6)
VectorXY difference = a - b; // (2, 2)
VectorXY doubled = a * 2f;   // (6, 8)
VectorXY halved = a / 2f;    // (1.5, 2)
```

Деление с плавающей точкой подчиняется обычным правилам .NET, поэтому деление на ноль может
дать `NaN` или бесконечность. Если следующая операция не допускает такой результат, проверьте
`IsFinite`.

Арифметика целочисленного вектора остаётся целочисленной при целом скаляре:

```csharp
var size = new VectorXYInt(7, 5);

VectorXYInt doubled = size * 2; // (14, 10)
VectorXYInt halved = size / 2;  // (3, 2)
VectorXY scaled = size * 0.5f;  // (3.5, 2.5)
```

Целочисленное деление усекает каждое частное к нулю, а деление на ноль приводит к
`DivideByZeroException`. Умножение на скаляр с плавающей точкой возвращает `VectorXY`, чтобы не
отбрасывать дробную часть результата.

## Длина и направление

`Length` возвращает евклидову длину вектора обоих типов. Свойство `VectorXY.SquaredLength`
позволяет не извлекать квадратный корень, если длины нужно только сравнить:

```csharp
var vector = new VectorXY(3f, 4f);

float length = vector.Length;               // 5
float squaredLength = vector.SquaredLength; // 25
```

Метод `Normalize` сохраняет направление и возвращает вектор единичной длины:

```csharp
VectorXY direction = new VectorXY(3f, 4f).Normalize(); // (0.6, 0.8)
```

У нулевого вектора нет единственного геометрического направления. Spatial2D обрабатывает этот
граничный случай возвратом `VectorXY.Zero` при нормализации.

Если векторы рассматриваются как координатные значения, метод `Distance` вычисляет евклидово
расстояние между ними:

```csharp
float distance = new VectorXY(1f, 1f).Distance(
    new VectorXYInt(4, 5)); // 5
```

## Отношения между направлениями

Скалярное произведение измеряет сонаправленность. Для перпендикулярных векторов оно равно нулю,
а знак в общем случае различает сходные и противоположные направления.

Скалярное двумерное векторное произведение определяет знаковую ориентацию. Положительный
результат означает, что правый вектор расположен против часовой стрелки от левого, а
отрицательный — по часовой стрелке.

```csharp
VectorXY right = VectorXY.BasisX;
VectorXY up = VectorXY.BasisY;

float dot = VectorXY.Dot(right, up);         // 0
float cross = VectorXY.Cross(right, up);     // 1
float angle = VectorXY.Angle(right, up);     // PI / 2
```

`Angle(from, to)` объединяет эти значения с помощью `Atan2` и возвращает кратчайший знаковый
угол в радианах. Углы против часовой стрелки положительны, по часовой стрелке — отрицательны.

## Поворот векторов

Метод `Rotate` поворачивает вектор вокруг начала координат. Угол задаётся в радианах:

```csharp
VectorXY rotated = VectorXY.BasisX.Rotate(MathF.PI / 2f);
// Приблизительно (0, 1)
```

Поворот обычно даёт дробные компоненты, поэтому поворот `VectorXYInt` также возвращает
`VectorXY`:

```csharp
VectorXY diagonal = new VectorXYInt(1, 0).Rotate(MathF.PI / 4f);
// Приблизительно (0.7071, 0.7071)
```

Угол должен быть конечным. `NaN`, положительная и отрицательная бесконечность приводят к
`ArgumentOutOfRangeException`.

## Преобразование на границе дискретного представления

Преобразование `VectorXYInt` в `VectorXY` неявное, поскольку оно сохраняет непрерывный смысл
вектора и не отбрасывает дробную часть:

```csharp
var integer = new VectorXYInt(3, 2);
VectorXY continuous = integer; // (3, 2)
```

Тип одинарной точности с плавающей точкой не может точно представить каждое большое значение
`int`. Поэтому компоненты, модуль которых выходит за диапазон точного целочисленного
представления `float`, могут округлиться даже при таком расширяющем преобразовании.

Обратное преобразование явное, потому что оно отбрасывает дробные части компонентов, усекая их
к нулю:

```csharp
var continuous = new VectorXY(3.8f, -2.4f);
var truncated = (VectorXYInt)continuous; // (3, -2)
```

Если нужны ближайшие целые компоненты, используйте `RoundToInt`. Метод вызывает `MathF.Round`,
поэтому значения ровно посередине округляются к ближайшему чётному целому:

```csharp
VectorXYInt rounded = new VectorXY(2.5f, 3.5f).RoundToInt();
// (2, 4)
```

Сохраняйте промежуточные результаты в `VectorXY` до операции, которой действительно нужны
целые значения. Так преобразование с потерей данных остаётся заметным, а ошибка усечения не
накапливается между шагами.

## Точное и приближённое равенство

Оба типа имеют структурную семантику равенства. Методы `Equals`, операторы `==` и `!=` точно
сравнивают компоненты, и хеш-коды следуют тому же правилу:

```csharp
bool sameFloatVector = new VectorXY(1f, 2f) == new VectorXY(1f, 2f); // true
bool sameIntVector = new VectorXYInt(1, 2) == new VectorXYInt(1, 2); // true
```

Для значений `VectorXY`, полученных вычислениями с плавающей точкой, используйте `AlmostEquals`.
Допуск задаёт включительное евклидово расстояние. По умолчанию используется
`GeometryConstants.GeometryEpsilon`:

```csharp
bool almostEqual = new VectorXY(1f, 2f).AlmostEquals(
    new VectorXY(1.000001f, 2f));

bool withinCustomTolerance = new VectorXY(1f, 2f).AlmostEquals(
    new VectorXY(1.01f, 2f),
    epsilon: 0.02f); // true
```

Для ключей словаря и дискретных векторов используйте точное равенство. Приближённое сравнение
применяйте явно, когда требуется проверить геометрическую близость.
