# Система координат

Akeldov.Math.Spatial2D использует двумерную декартову систему координат. Положения, перемещения,
направления, размеры и координаты дискретной сетки содержат компоненты `X` и `Y`, но разные типы
сохраняют различный смысл этих значений.

## Декартовы оси

Положительная ось X направлена вправо, положительная ось Y — вверх. Стандартные базисные векторы
с плавающей точкой имеют вид:

```csharp
using Akeldov.Math.Spatial2D;

VectorXY right = VectorXY.BasisX; // (1, 0)
VectorXY up = VectorXY.BasisY;    // (0, 1)
```

Направление поворота, представление углов и соглашения о линейных величинах описаны на странице
[«Углы и единицы измерения»](../angles-and-units.md).

## Выбор значения по смыслу

Выбирайте тип по роли значения, а не только по числовому представлению его компонентов:

| Тип | Смысл | Типичные применения |
|---|---|---|
| <xref:Akeldov.Math.Spatial2D.PointXY> | Положение в непрерывном пространстве | Концы кривых, центры областей, точки выборки и пересечения |
| <xref:Akeldov.Math.Spatial2D.VectorXY> | Непрерывное направление или перемещение | Смещения, направления, размеры в мировых единицах и преобразования |
| <xref:Akeldov.Math.Spatial2D.VectorXYInt> | Целочисленная пара, смысл которой задаёт принимающий API | Индексы и разрешения растров, размеры и дискретные смещения |

Точка и вектор могут содержать одинаковые числа, но выражать разные геометрические понятия.
Компоненты дискретного индекса также могут совпадать с координатами мировой точки, не обозначая
то же положение.

## Сочетание положений и перемещений

Система типов отражает стандартные аффинные отношения между точками и векторами:

```csharp
var start = new PointXY(2f, 3f);
var offset = new VectorXY(4f, -1f);

PointXY end = start + offset;         // (6, 2)
VectorXY displacement = end - start; // (4, -1)
PointXY restored = end - offset;      // (2, 3)
```

Полезные отношения имеют вид:

```text
точка + вектор = точка
точка - вектор = точка
точка - точка  = вектор
вектор + вектор = вектор
```

Сложение двух точек намеренно не поддерживается, поскольку результат не имеет однозначного
геометрического смысла. По той же причине преобразование между `PointXY` и `VectorXY` является
явным: числовые компоненты сохраняются, но изменение роли видно непосредственно в месте вызова.

## Разделение непрерывного и дискретного пространства

`PointXY` и `VectorXY` используют компоненты `float` для непрерывных геометрических вычислений.
`VectorXYInt` использует компоненты `int`, когда целочисленность является частью контракта.

Сохраняйте вычисление непрерывным до момента, когда API действительно потребует дискретное
значение. Преобразование `VectorXY` в `VectorXYInt` может усечь или округлить компоненты, поэтому
способ необходимо выбирать явно. Правила преобразования описаны на странице
[«Векторы»](vectors.md).

Растровые сетки явно показывают эту границу.
<xref:Akeldov.Math.Spatial2D.Rasterization.RasterGeometry> объединяет непрерывное начало
`PointXY` и размер `VectorXY` с разрешением `VectorXYInt`, а затем преобразует индексы ячеек от
нуля в положения выборки `PointXY`. Храните индекс и мировое положение как разные значения, не
подменяя одно другим. Границы, перебор и правила преобразования рассмотрены на странице
[«Дискретные индексы»](discrete-indices.md).

## Сохранение семантических различий

Предпочитайте сигнатуры API и локальные имена, которые показывают предполагаемую роль:

```csharp
PointXY position = new PointXY(3f, 2f);
VectorXY translation = new VectorXY(3f, 2f);
VectorXYInt cellIndex = new VectorXYInt(3, 2);
```

Не считайте эти значения взаимозаменяемыми парами координат. Сохранение ролей затрудняет запись
недопустимых операций и упрощает проверку границ между непрерывным и дискретным представлением.
