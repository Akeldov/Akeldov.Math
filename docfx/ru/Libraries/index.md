# Библиотеки

Пакеты Akeldov.Math охватывают двумерную геометрию, пространственные алгоритмы и обработку гексагональных сеток. Выберите библиотеку, чтобы перейти к документации и справочнику API нужной версии.

| Библиотека | Описание |
| --- | --- |
| <a href="/Akeldov.Math/ru/Spatial2D/index.html">Akeldov.Math.Spatial2D</a> | Двумерная геометрия, контуры, области, растеризация, пространственная выборка, разбиение и поля влияния. |
| <a href="/Akeldov.Math/ru/Hexes/index.html">Akeldov.Math.Hexes</a> | Гексагональные координаты, топология, геометрия, поиск пути, растеризация, полигексы и взвешенное разбиение. |
