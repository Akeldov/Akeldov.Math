# Akeldov.Math.Hexes

Akeldov.Math.Hexes предоставляет координаты, раскладки, топологию, геометрию, карты, поиск пути, растеризацию, обработку полигексов и взвешенное разбиение гексагональных сеток.

## Установка

```powershell
dotnet add package Akeldov.Math.Hexes
```

## Основные возможности

- Дробные и целочисленные координаты QRS
- Раскладки с горизонтальной и вертикальной ориентацией гексов
- Гексагональные карты, топология и геометрия
- Взвешенный поиск пути
- Растеризация и хроматизация
- Контуры и области полигексов
