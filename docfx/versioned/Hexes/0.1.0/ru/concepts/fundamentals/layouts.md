# Раскладки

<xref:Akeldov.Math.Hexes.Layout> описывает, как индекс прямоугольного хранилища `VectorXYInt`
размещается на гексагональной решётке. Раскладка объединяет два решения: ориентацию каждого гекса
и выбор чередующихся строк или столбцов, к которым применяется смещение.

Поэтому раскладка точнее, чем <xref:Akeldov.Math.Hexes.HexOrientation>. Ориентация различает гексы
вершиной вверх и горизонтальной стороной вверх, но не позволяет отличить `OddR` от `EvenR` или
`OddQ` от `EvenQ`.

## Четыре раскладки

| Раскладка | Ориентация | Измерение со смещением | Чётность смещения |
| --- | --- | --- | --- |
| `OddR` | `PointyTop` | строки (`Y`, или `R` в QRS) | нечётные строки |
| `EvenR` | `PointyTop` | строки (`Y`, или `R` в QRS) | чётные строки |
| `OddQ` | `FlatTop` | столбцы (`X`, или `Q` в QRS) | нечётные столбцы |
| `EvenQ` | `FlatTop` | столбцы (`X`, или `Q` в QRS) | чётные столбцы |

В раскладке `PointyTop` сверху находится вершина гекса, а прямоугольное хранилище организовано по
строкам. В раскладке `FlatTop` сверху находится горизонтальная сторона, а хранилище организовано
по столбцам. Суффиксы `R` и `Q` указывают компонент QRS, который сохраняется как индекс строки
или столбца.

В системе Spatial2D положительная ось X направлена вправо, а положительная ось Y — вверх. Поэтому
выбранные строки смещаются вдоль положительной оси X, а выбранные столбцы — вдоль положительной
оси Y. На схемах, где индекс строки растёт вниз, смещение столбцов визуально направлено в другую
сторону; правило чётности и формулы преобразования от этого не меняются.

Если коду важно только геометрическое различие, используйте методы определения ориентации:

```csharp
using Akeldov.Math.Hexes;

Layout layout = Layout.OddR;

bool isPointy = layout.IsPointyTop();       // true
bool isFlat = layout.IsFlatTop();           // false
HexOrientation orientation = layout.GetHexOrientation(); // PointyTop
```

`GetHexOrientation()` отклоняет неподдерживаемое значение перечисления. Два предиката
классифицируют соответствующие пары определённых раскладок и возвращают `false` для значений вне
своей пары.

## Индексы со смещением и индексы QRS

`VectorXYInt` удобен для прямоугольного массива: `X` выбирает столбец, а `Y` — строку.
<xref:Akeldov.Math.Hexes.Vectors.QRS.VectorQRSInt> обозначает тот же гекс независимо от правила
смещения нечётных или чётных индексов. Для преобразования используйте `ToQRSIndex(layout)` и
`ToXYIndex(layout)`.

```csharp
using Akeldov.Math.Hexes;
using Akeldov.Math.Hexes.Vectors.QRS;
using Akeldov.Math.Spatial2D;

Layout layout = Layout.OddR;
var storageIndex = new VectorXYInt(-3, -3);

VectorQRSInt hexIndex = storageIndex.ToQRSIndex(layout);
// Q = -1, R = -3, S = 4

VectorXYInt restored = hexIndex.ToXYIndex(layout);
// X = -3, Y = -3
```

Для каждой поддерживаемой раскладки прямое и обратное преобразования целочисленного индекса с
одной раскладкой восстанавливают исходное значение, если преобразованные компоненты помещаются в
`Int32`. Это перекодирование целых индексов, а не округление к ближайшему гексу. Преобразования
сохраняют математическую чётность как положительных, так и отрицательных индексов.

Точные формулы преобразования, правила прямоугольного хранения и особенности проверки чётности
отрицательных индексов приведены на странице
[«Индексы строк и столбцов»](coordinate-systems/row-and-column-indices.md).

## Используйте одну раскладку во всей операции

`VectorXYInt` не хранит раскладку. Если интерпретировать индекс с другой раскладкой, он может
незаметно начать обозначать другой логический гекс. Аналогично, обратное преобразование QRS с
другой раскладкой может изменить индекс хранилища:

```csharp
var storageIndex = new VectorXYInt(-3, -3);
VectorQRSInt hexIndex = storageIndex.ToQRSIndex(Layout.OddR);

VectorXYInt sameCell = hexIndex.ToXYIndex(Layout.OddR);  // (-3, -3)
VectorXYInt otherEncoding = hexIndex.ToXYIndex(Layout.EvenR); // (-2, -3)
```

Выберите раскладку один раз и передавайте это значение в API топологии, геометрии, преобразования
координат, окрестностей и растеризации. <xref:Akeldov.Math.Hexes.HexMapTopology> хранит выбранное
значение в свойстве `Layout`; созданная из такой топологии геометрия использует то же значение.

```csharp
using Akeldov.Math.Hexes;
using Akeldov.Math.Hexes.Geometry;
using Akeldov.Math.Spatial2D;

const Layout layout = Layout.OddR;
var topology = new HexMapTopology(width: 32, height: 24, layout: layout);
var geometry = new HexMapGeometry(topology, origin: VectorXY.Zero, radius: 10f);
```

Не сохраняйте только `HexOrientation`, если позднее нужно восстановить индекс со смещением:
ориентация не содержит правило нечётного или чётного смещения. Сохраняйте полный `Layout` вместе
с индексированными данными.

## Раскладки в непрерывном пространстве

Нечётный и чётный варианты одной ориентации имеют одинаковый непрерывный базис QRS. Поэтому
пространственные преобразования непрерывных QRS-координат одинаково обрабатывают `OddR` и
`EvenR`, а также одинаково обрабатывают `OddQ` и `EvenQ`. Выбор нечётного или чётного варианта
становится важен, когда результат кодируется как прямоугольный `VectorXYInt`.

Например, `PointXY.ToXYIndex(hexRadius, hexFieldOrigin, layout)` сначала находит ближайшую ячейку
QRS с учётом ориентации раскладки, а затем кодирует её по выбранному правилу нечётного или чётного
смещения. Передавайте те же радиус, начало координат и раскладку, которые задают геометрию карты.

Назначение QRS-координат, индексов со смещением и пространственных координат разобрано на странице
[«Системы координат»](coordinate-systems/index.md). Затем переходите к
[«Дискретизации координат»](coordinate-discretization.md), где описаны преобразование мировых
точек и округление к ближайшему гексу.
