# Повороты и преобразования

Akeldov.Math.Hexes поддерживает два связанных вида поворотов:

- точные повороты на угол, кратный 60 градусам, которые сохраняют гексагональную решётку в
  пространстве QRS;
- повороты с плавающей точкой и аффинные преобразования непрерывных координат.

Все положительные углы задают поворот против часовой стрелки. Повороты QRS не зависят от
[раскладки](layouts.md), поэтому аргумент `Layout` им не нужен.

## Углы с шагом 60 градусов

<xref:Akeldov.Math.Hexes.SixfoldAngle> представляет шесть поворотов, сохраняющих правильную
гексагональную решётку.

| Значение | Числовое значение | Градусы | Радианы |
|---|---:|---:|---:|
| `Deg0` | 0 | 0 | 0 |
| `Deg60` | 1 | 60 | π / 3 |
| `Deg120` | 2 | 120 | 2π / 3 |
| `Deg180` | 3 | 180 | π |
| `Deg240` | 4 | 240 | 4π / 3 |
| `Deg300` | 5 | 300 | 5π / 3 |

Методы расширения для углов возвращают соответствующие значения `float` и выполняют операции
по модулю полного оборота:

- `Sin()` и `Cos()` возвращают сохранённые тригонометрические значения;
- `AsFloatRadians()` возвращает угол из диапазона `[0, 2π)`;
- `AsFloatDegrees()` возвращает угол из диапазона `[0, 360)`;
- `Negate()` возвращает обратный поворот: например, `Deg60` превращается в `Deg300`;
- `Add60()`, `Add120()`, `Add180()`, `Add240()` и `Add300()` прибавляют указанный угол с
  переходом через 360 градусов.

`Negate()` и `Add180()` выполняют разные операции. Первый метод обращает поворот, а второй
добавляет к нему ещё половину полного оборота.

```csharp
using Akeldov.Math.Hexes;

SixfoldAngle angle = SixfoldAngle.Deg300.Add120(); // Deg60
SixfoldAngle inverse = angle.Negate();              // Deg300
float radians = angle.AsFloatRadians();             // Примерно 1.0471976
float sine = angle.Sin();                            // Примерно 0.8660254

SixfoldAngle[] ordered = SixfoldAngles.All;
```

<xref:Akeldov.Math.Hexes.SixfoldAngles.All> возвращает значения против часовой стрелки от
`Deg0` до `Deg300`. При каждом обращении создаётся новый изменяемый массив, принадлежащий
вызывающему коду. Изменение этого массива не влияет на результат следующего обращения.

Приведение к перечислению позволяет создать неопределённое значение, например
`(SixfoldAngle)42`. Методы получения значений, сложения углов и поворота отклоняют такие
значения с `ArgumentOutOfRangeException`.

## Направление поворота

Методы для XY используют стандартную матрицу поворота:

```text
x' = x cos(angle) - y sin(angle)
y' = x sin(angle) + y cos(angle)
```

Поэтому положительный угол означает поворот против часовой стрелки в системе координат, где
положительная полуось Y направлена вверх. Если результат отображается в экранных или растровых
координатах с полуосью Y, направленной вниз, то визуально тот же поворот выглядит как поворот
по часовой стрелке.

Единица угла определяется типом перегрузки. `SixfoldAngle` задаёт один из именованных шагов в
градусах, а `float angleRad` задаётся в радианах. Перегрузки с числом градусов нет:
`Rotate(60f)` означает 60 радиан, а не 60 градусов.

## Точные повороты QRS

<xref:Akeldov.Math.Hexes.Vectors.QRS.VectorQRS> и
<xref:Akeldov.Math.Hexes.Vectors.QRS.VectorQRSInt> можно повернуть относительно начала
координат QRS на `SixfoldAngle`. Эти перегрузки переставляют компоненты и меняют их знаки, не
вычисляя синус и косинус.

Для `v = (Q, R, S)` получаются следующие значения:

| Угол | Результат `(Q, R, S)` |
|---|---|
| `Deg0` | `(Q, R, S)` |
| `Deg60` | `(-R, -S, -Q)` |
| `Deg120` | `(S, Q, R)` |
| `Deg180` | `(-Q, -R, -S)` |
| `Deg240` | `(R, S, Q)` |
| `Deg300` | `(-S, -Q, -R)` |

Таким образом, инвариант `Q + R + S = 0` сохраняется. Сохраняется и вид входного значения: поворот
`VectorQRS` возвращает `VectorQRS`, а поворот `VectorQRSInt` — `VectorQRSInt`, если все компоненты
результата помещаются в `Int32`. Если целочисленный результат выходит за диапазон, метод
выбрасывает `ArgumentOutOfRangeException`.

```csharp
using Akeldov.Math.Hexes;
using Akeldov.Math.Hexes.Vectors.QRS;

var index = new VectorQRSInt(2, -5); // S равен 3

VectorQRSInt rotated = index.Rotate(SixfoldAngle.Deg60);
// rotated равен (5, -3), а S равен -2
```

Перегрузки поворота QRS всегда используют начало координат как центр. Для поворота относительно
другого QRS-индекса сначала перенесите точку относительно центра поворота, затем поверните и
верните смещение:

```csharp
var pivot = new VectorQRSInt(1, -1);
var point = new VectorQRSInt(3, -2);

VectorQRSInt aroundPivot =
    (point - pivot).Rotate(SixfoldAngle.Deg120) + pivot;
```

## Повороты QRS на произвольный угол

Перегрузка `Rotate(float angleRad)` принимает любой конечный угол в радианах. Она выполняет
поворот в координатной плоскости QRS и возвращает дробные QRS-координаты:

| Получатель | Вызов | Тип результата |
|---|---|---|
| `VectorQRS` | `Rotate(float angleRad)` | `VectorQRS` |
| `VectorQRSInt` | `Rotate(float angleRad)` | `VectorQRS` |

```csharp
using System;
using Akeldov.Math.Hexes;
using Akeldov.Math.Hexes.Vectors.QRS;

var index = new VectorQRSInt(2, -5);

VectorQRSInt exactStep = index.Rotate(SixfoldAngle.Deg60);
VectorQRS arbitrary = index.Rotate(MathF.PI / 6f); // 30 градусов
```

Перегрузка для целочисленного вектора намеренно возвращает `VectorQRS`: произвольный поворот
обычно не попадает в целочисленный индекс гекса. Если после него нужен дискретный индекс,
явно округлите результат методом `ToQRSIndex(Layout)`, как описано в разделе
[«Дискретизация координат»](coordinate-discretization.md). Явное приведение к `VectorQRSInt`
лишь отбрасывает дробную часть `Q` и `R` по направлению к нулю и не выполняет округление до
ближайшего гекса.

Перегрузка с произвольным углом отклоняет неконечный угол. Для получателя `VectorQRS` она также
отклоняет неконечные компоненты QRS.

## Повороты XY

Методы расширения Hexes для XY поворачивают только на `SixfoldAngle`; перегрузки с произвольным
углом в радианах для XY нет. Получатель и центр поворота могут быть дробными или
целочисленными, но все перегрузки возвращают `VectorXY`.

| Получатель | Центр поворота | Тип центра | Тип результата |
|---|---|---|---|
| `VectorXY` | Начало координат | — | `VectorXY` |
| `VectorXYInt` | Начало координат | — | `VectorXY` |
| `VectorXY` | Явно заданный | `VectorXY` или `VectorXYInt` | `VectorXY` |
| `VectorXYInt` | Явно заданный | `VectorXY` или `VectorXYInt` | `VectorXY` |

В перегрузке с центром поворота этот аргумент расположен перед углом:
`point.Rotate(pivot, angle)`. Центр остаётся неподвижным; поворачивается только смещение точки
относительно него.

```csharp
using Akeldov.Math.Hexes;
using Akeldov.Math.Hexes.Vectors.QRS;
using Akeldov.Math.Spatial2D;

var point = new VectorXY(3f, 1f);
var pivot = new VectorXY(1f, 1f);

VectorXY result = point.Rotate(pivot, SixfoldAngle.Deg60);
// result примерно равен (2, 2.7320508)

VectorXY fromInteger =
    new VectorXYInt(2, -3).Rotate(SixfoldAngle.Deg180);
// fromInteger равен (-2, 3), но его тип — VectorXY
```

Возвращаемый тип `VectorXY` необходим, поскольку после поворота XY на 60 градусов компоненты
обычно становятся дробными. Даже у вызова `VectorXYInt.Rotate(Deg180)` тип результата на этапе
компиляции остаётся `VectorXY`.

## Аффинный метод `Transform`

`Transform` определён для `VectorXY` и `VectorXYInt`. Все перегрузки возвращают `VectorXY` и
принимают смещение типа `VectorXY` или `VectorXYInt`.

Поддерживаются две последовательности операций:

```text
Transform(angle, offset)
    result = Rotate(point, angle) + offset

Transform(scaleFactor, angle, offset)
    result = Rotate(point * scaleFactor, angle) + offset
```

Масштабирование равномерное и выполняется первым. Затем происходит поворот относительно начала
координат. Перенос выполняется последним, поэтому само смещение не масштабируется и не
поворачивается.

```csharp
using Akeldov.Math.Hexes;
using Akeldov.Math.Hexes.Vectors.QRS;
using Akeldov.Math.Spatial2D;

var source = new VectorXY(2f, 0f);
var translation = new VectorXY(10f, 20f);

VectorXY transformed = source.Transform(
    scaleFactor: 2f,
    angle: SixfoldAngle.Deg60,
    offset: translation);

// Масштаб:       (2, 0) -> (4, 0)
// Поворот на 60°: (4, 0) -> примерно (2, 3.464102)
// Перенос:                    примерно (12, 23.464102)
```

У `Transform` нет аргумента центра поворота и нет перегрузки с произвольным углом в радианах.
Для преобразования относительно заданного центра явно перенесите значение относительно этого
центра, выполните нужное масштабирование или поворот и перенесите его обратно.

## Практические замечания

- Для именованных шагов в градусах используйте перегрузку с `SixfoldAngle`; числовые углы QRS
  задаются в радианах.
- Повороты QRS на `SixfoldAngle` сохраняют целочисленные индексы, если компоненты результата
  помещаются в `Int32`; выход за диапазон отклоняется. Произвольные повороты QRS возвращают
  дробные координаты.
- Все перегрузки поворота и преобразования XY возвращают `VectorXY`, в том числе при вызове для
  `VectorXYInt`.
- Результаты XY с плавающей точкой используют тригонометрические константы, поэтому обычно их
  следует сравнивать с допуском.
- `Transform` всегда выполняет перенос последним и всегда поворачивает относительно начала
  координат.
- Методы поворота возвращают новые значения и не изменяют неизменяемые исходные векторы.

Подробнее об инварианте координат читайте в разделе
[«QRS-координаты»](coordinate-systems/qrs-coordinates.md), а об ориентации сетки при последующем
переходе в пространственные координаты — в разделе [«Раскладки»](layouts.md).
