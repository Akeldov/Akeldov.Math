# Карты

Гекс-карта сопоставляет одно значение каждой ячейке прямоугольной
<xref:Akeldov.Math.Hexes.HexMapTopology>. Топология задаёт допустимые строковые и столбцовые
индексы, их раскладку и число хранимых значений, а карта содержит сами данные. Карты подходят для
ландшафта, масок, стоимостей, меток и любого другого состояния отдельных ячеек.

## Выбор типа карты

Hexes 0.1.0 предоставляет две реализации карт общего назначения и соответствующие интерфейсы
только для чтения:

| Тип | Сохраняемые метаданные | Доступ к значениям | Типичное назначение |
|---|---|---|---|
| `IHexMap<TValue>` | Топология | Только чтение | Принимать любую карту с топологией |
| `HexMap<TValue>` | Топология | Чтение и запись | Хранить произвольные значения ячеек |
| `ISpatialHexMap<TValue>` | Топология и геометрия | Только чтение | Принимать карту, размещённую в пространстве |
| `SpatialHexMap<TValue>` | Топология и геометрия | Чтение и запись | Хранить значения вместе с их физическим размещением |

Интерфейсы предоставляют индексаторы только для чтения. Они ограничивают способ доступа
потребителя к карте, но не делают изменяемую реализацию или хранимые объекты ссылочных типов
неизменяемыми.

В этой версии пакета булевы, целочисленные и вещественные карты — это специализации обобщённого
типа: `HexMap<bool>`, `HexMap<int>` и `HexMap<float>`. Отдельных типов `BoolHexMap`, `IntHexMap` и
`FloatHexMap` в Hexes 0.1.0 нет.

## Создание и изменение карты

Передайте конструктору топологию, общую для всех ячеек. Конструктор только с топологией создаёт
новый внутренний массив и заполняет каждую ячейку значением `default(TValue)`:

```csharp
using Akeldov.Math.Hexes;
using Akeldov.Math.Spatial2D;

var topology = new HexMapTopology(
    width: 4,
    height: 3,
    layout: Layout.OddR);

var terrain = new HexMap<string?>(topology);
var cell = new VectorXYInt(2, 1);

terrain[cell] = "лес";
string? value = terrain[cell];

IHexMap<string?> readOnlyTerrain = terrain;
string? sameValue = readOnlyTerrain[cell];
```

Карта сохраняет `Topology` как часть своего состояния. `HexMapTopology` — неизменяемый тип
значения, поэтому несколько карт могут безопасно хранить равные топологии и адресовать одни и те
же логические ячейки.

## Координатные и плоские индексы

Оба интерфейса карты поддерживают две формы индекса:

- `map[new VectorXYInt(x, y)]` адресует строку и столбец и проверяет обе компоненты по разрешению
  топологии;
- `map[flatIndex]` напрямую адресует линейную последовательность в построчном порядке.

Для топологии ширины `W` индексы связаны формулами:

```text
flatIndex = y * W + x
x = flatIndex % W
y = flatIndex / W
```

Первым изменяется `X`, а любой допустимый плоский индекс лежит от `0` до
`Topology.Count - 1`. Раскладка не меняет порядок хранения: она определяет, как индекс `(x, y)`
интерпретируется на гексагональной сетке.

```csharp
var index = new VectorXYInt(2, 1);
int flatIndex = index.Y * topology.Resolution.X + index.X; // 6

terrain[index] = "вода";
bool sameCell = terrain[flatIndex] == "вода";              // true
```

Недопустимый `VectorXYInt` или плоский индекс приводит к `IndexOutOfRangeException`. Преобразования
координат и средства получения соседей могут вернуть ячейку за пределами конечной топологии,
поэтому перед индексированием проверяйте границы, если значение не получено из заведомо
существующей ячейки карты. Точная прямоугольная область описана на странице
[«Топология»](../hex-grid-model/topology.md).

## Инициализация готовыми значениями

Если значения уже расположены в построчном порядке, передайте массив конструктору. Его длина
должна совпадать с `topology.Count`:

```csharp
var topology = new HexMapTopology(3, 2, Layout.EvenR);
var values = new[]
{
    10, 11, 12, // y = 0
    20, 21, 22, // y = 1
};

var elevation = new HexMap<int>(topology, values);

elevation[new VectorXYInt(1, 1)] = 99;
bool sharedStorage = values[4] == 99; // true
```

Конструктор сохраняет переданный массив без копирования. Вызывающий код и карта совместно владеют
изменяемым хранилищем: изменения через любую из ссылок видны через другую. Если карта не должна
разделять внутренний массив с вызывающим кодом, скопируйте его перед созданием:

```csharp
var ownedElevation = new HexMap<int>(topology, (int[])values.Clone());
```

Копирование поверхностное: объекты ссылочного типа `TValue` останутся общими, хотя сам внутренний
массив общим не будет.

Карта не предоставляет доступ к своему внутреннему массиву. Для `null` конструктор выбрасывает
`ArgumentNullException`, а при длине, отличной от `Topology.Count`, — `ArgumentException`.

Пустая топология допустима, поэтому карта может содержать ноль ячеек. Её внутренний массив пуст,
а любой индекс недопустим. Карта проверяет форму хранилища, но не смысловую допустимость отдельных
значений `TValue`.

## Хранение распространённых типов значений

Тип `TValue` не меняет контракт хранилища. Выбирайте его по смыслу одной ячейки:

```csharp
var blocked = new HexMap<bool>(topology);       // везде false
var movementCost = new HexMap<int>(topology);  // везде 0
var temperature = new HexMap<float>(topology); // везде 0f
var labels = new HexMap<string?>(topology);     // везде null
```

В Hexes 0.1.0 у `HexMap<int>` и `HexMap<float>` нет дополнительных операций арифметики,
минимума/максимума, фильтрации или генерации шума. Для вычисления или преобразования значений
обходите плоские индексы от `0` до `Topology.Count - 1` либо передавайте карту алгоритму,
принимающему `IHexMap<TValue>`.

## Сохранение пространственной геометрии

Используйте `SpatialHexMap<TValue>`, когда вместе со значениями нужно хранить
<xref:Akeldov.Math.Hexes.Geometry.HexMapGeometry>. Унаследованное свойство `Topology` соответствует
топологии геометрии, а `Geometry` дополнительно сохраняет центр нулевого гекса и радиус:

```csharp
using Akeldov.Math.Hexes.Geometry;

var geometry = new HexMapGeometry(
    topology,
    origin: new VectorXY(100f, 50f),
    radius: 8f);

var moisture = new SpatialHexMap<float>(geometry);
moisture[new VectorXYInt(0, 0)] = 0.75f;

ISpatialHexMap<float> spatialInput = moisture;
bool sameTopology = spatialInput.Topology == geometry.Topology; // true
```

Конструктор без значений создаёт новый массив со значениями по умолчанию. Перегрузка с массивом
имеет тот же контракт совместного владения, что и `HexMap<TValue>`. `SpatialHexMap<TValue>`
отвергает геометрию, если компонента начала координат не является конечной либо радиус не является
конечным положительным числом. Соглашения координатного пространства описаны на странице
[«Геометрия»](../hex-grid-model/geometry.md).

## Объединение булевых карт

<xref:Akeldov.Math.Hexes.BooleanHexMapExtensions> предоставляет поэлементные операции `And` и `Or`
для `IHexMap<bool>` и `ISpatialHexMap<bool>`:

```csharp
IHexMap<bool> walkable = new HexMap<bool>(topology, new[]
{
    true,  true,  false,
    false, true,  true,
});

IHexMap<bool> visible = new HexMap<bool>(topology, new[]
{
    true, false, true,
    true, true,  false,
});

HexMap<bool> visibleAndWalkable = walkable.And(visible);
HexMap<bool> visibleOrWalkable = walkable.Or(visible);
```

Обе операции создают новую изменяемую карту во владении вызывающего кода и не меняют аргументы.
Результат сохраняет общую топологию. Различные топологии приводят к `ArgumentException`, а
аргумент `null` — к `ArgumentNullException`.

Пространственные перегрузки возвращают `SpatialHexMap<bool>` и сохраняют геометрию
пространственного аргумента. У двух пространственных карт должны совпадать полные геометрии, а не
только топологии. В смешанной операции топологии должны быть равны; если формально
непространственный аргумент во время выполнения тоже оказывается пространственным, его геометрия
также должна совпадать.

Выбор перегрузки зависит от статических типов переменных. Если результат должен сохранить
геометрию, хотя бы один аргумент должен иметь пространственный статический тип, например
`ISpatialHexMap<bool>` или `SpatialHexMap<bool>`. В Hexes 0.1.0 нет встроенных операций булевого
отрицания и исключающего «или» для карт.

## Явное преобразование значений

Неявных преобразований между картами с разными типами `TValue` нет. Создайте значения результата,
преобразуйте каждую плоскую ячейку и сконструируйте карту с метаданными, которые нужно сохранить:

```csharp
var elevation = new HexMap<int>(topology, values);
var normalizedValues = new float[elevation.Topology.Count];

for (int i = 0; i < normalizedValues.Length; i++)
    normalizedValues[i] = elevation[i] / 100f;

var normalized = new HexMap<float>(elevation.Topology, normalizedValues);
```

Для пространственного источника создавайте `SpatialHexMap<TOutput>` с исходной `Geometry`, а не
`HexMap<TOutput>` только с топологией. Так при изменении типа значения не будут случайно потеряны
начало координат и масштаб.
