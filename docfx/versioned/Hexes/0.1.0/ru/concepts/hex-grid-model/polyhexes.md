# Полигексы

Полигекс — конечное множество занятых гексов. Akeldov.Math.Hexes представляет это множество
прямоугольной Q/R-маской: первое измерение массива соответствует Q, второе — R, а значение `true`
включает ячейку в фигуру. <xref:Akeldov.Math.Hexes.Topology.Polyhex> — неизменяемое значение для
хранения и совместного использования такой маски.

## Модель маски

Элементу маски `[q, r]` соответствует целочисленная QRS-координата `(q, r, -q - r)`. Оба индекса
начинаются с нуля и должны удовлетворять условиям:

```text
0 <= q < QRSResolution.Q
0 <= r < QRSResolution.R
```

Таким образом, `QRSResolution.Q` и `QRSResolution.R` — размеры массива. Вычисляемый компонент `S`
не является третьим измерением массива. Прямоугольный диапазон Q/R выглядит параллелограммом на
гексагональной сетке; <xref:Akeldov.Math.Hexes.Layout> в этом представлении не участвует.

Тип намеренно хранит маску и не требует связности в математическом смысле. Маска может быть
пустой, содержать отверстия, пустые поля или несколько несвязных компонентов. Исходные размеры
сохраняются.

## Выбор способа создания

| Исходные данные | Занятые ячейки | Владение данными |
| --- | --- | --- |
| `new Polyhex(bool[,])` | Элементы со значением `true` | Массив копируется. |
| `new Polyhex(int[,])` | Все ненулевые элементы | Преобразованная маска копируется. |
| `new Polyhex(VectorQRSInt)` | Нет | Создаётся новая пустая маска заданных размеров Q и R. |
| Неявное преобразование из `bool[,]` | Элементы со значением `true` | Эквивалентно конструктору из логической маски и копирует массив. |
| <xref:Akeldov.Math.Hexes.Topology.PolyhexBuilder> | Ячейки, выбранные через изменяемые индексаторы | `ToPolyhex()` создаёт независимый снимок. |

Используйте конструктор, если готова вся маска. Используйте построитель, если ячейки находятся
или изменяются постепенно.

## Создание неизменяемого полигекса

В инициализаторе прямоугольного массива C# внешние группы выбирают Q, а значения внутри группы —
R:

```csharp
using Akeldov.Math.Hexes.Topology;

bool[,] mask =
{
    { true,  true,  false }, // q = 0, r = 0..2
    { false, true,  true  }  // q = 1, r = 0..2
};

var polyhex = new Polyhex(mask);

bool containsQ1R2 = polyhex[1, 2]; // true
int occupiedCellCount = polyhex.HexCount; // 4

mask[1, 2] = false;
bool stillPresent = polyhex[1, 2]; // true: конструктор скопировал маску
```

Маска `int[,]` использует тот же порядок Q/R. Ноль означает отсутствие ячейки, а положительные и
отрицательные значения — её наличие.

## Пошаговое построение маски

<xref:Akeldov.Math.Hexes.Topology.PolyhexBuilder> использует ту же индексацию Q/R, но предоставляет
сеттеры:

```csharp
using Akeldov.Math.Hexes.Topology;
using Akeldov.Math.Hexes.Vectors.QRS;

var builder = new PolyhexBuilder(qSize: 3, rSize: 2);
builder[0, 0] = true;
builder[new VectorQRSInt(1, 0)] = true;

Polyhex snapshot = builder.ToPolyhex();

builder[0, 0] = false;
bool snapshotIsUnchanged = snapshot[0, 0]; // true
```

Конструктор `new PolyhexBuilder(existingPolyhex)` также копирует существующее значение. Построитель
не владеет полигексом и не изменяет его, а каждый вызов `ToPolyhex()` возвращает новый неизменяемый
снимок.

## Чтение и экспорт ячеек

<xref:Akeldov.Math.Hexes.Topology.IPolyhex> — общий интерфейс только для чтения, реализованный
`Polyhex` и типами полигексов с геометрией. Он предоставляет:

| Член | Значение |
| --- | --- |
| `QRSResolution` | Размеры Q и R сохранённой маски |
| `HexCount` | Количество занятых ячеек, а не полная ёмкость маски |
| `this[q, r]` | Наличие ячейки по индексам Q/R |
| `this[VectorQRSInt]` | Та же проверка по компонентам Q и R координаты |
| `GetExtended()` | Новая маска с фигурой и её окрестностью толщиной в одну ячейку |
| `GetContour()` | Новая маска с отсутствующими ячейками, соседними с фигурой |

`Polyhex.ToBoolArray()` возвращает новый изменяемый массив `bool[,]`, принадлежащий вызывающему
коду. Изменение этого массива не влияет на полигекс:

```csharp
bool[,] editableCopy = polyhex.ToBoolArray();
editableCopy[0, 0] = false;

bool originalIsUnchanged = polyhex[0, 0]; // true
```

Сам интерфейс гарантирует только чтение; конкретный тип `Polyhex` дополнительно обеспечивает
неизменяемость и равенство по значению.

## Расширение фигуры и выделение границы из ячеек

Обе топологические операции возвращают новый `Polyhex`, размеры которого по Q и R увеличены на
два. Координаты исходной маски `[q, r]` соответствуют координатам результата `[q + 1, r + 1]`;
`GetContour()` использует это соответствие, но не копирует занятые исходные ячейки в результат.

`GetExtended()` отмечает сдвинутые исходные ячейки и всех их шестерых соседей по QRS. Поэтому одна
занятая исходная ячейка превращается в фигуру из семи ячеек. Пустые ячейки, не соседствующие с
исходной фигурой, остаются пустыми.

`GetContour()` отмечает каждую ранее отсутствовавшую ячейку, которая касается занятой исходной
ячейки в одном из шести направлений. Сами занятые исходные ячейки в результат не входят. Для
одной ячейки результатом будет кольцо из шести ячеек; у фигуры с отверстиями в результат могут
попасть и соседние ячейки внутри отверстия.

Эти методы изменяют и разрешение, и начало индексации. Не объединяйте результат с координатами
исходной маски без сдвига индексов `[+1, +1]`. Для границ и заполненных областей в мировых
координатах используйте API из раздела [«Геометрия»](geometry.md), а не интерпретируйте
`GetContour()` как геометрический контур.

## Добавление физических размеров

<xref:Akeldov.Math.Hexes.Geometry.IPolyhexGeometry> расширяет `IPolyhex` двумя размерами в единицах
пространства координат:

- `HexRadius` — расстояние от центра ячейки до вершины;
- `HexApothem` — расстояние от центра ячейки до ребра.

<xref:Akeldov.Math.Hexes.Geometry.PolyhexGeometry> — стандартная реализация. Она делегирует чтение
маски неизменяемому `Polyhex` и вычисляет `HexApothem` как `HexRadius * sqrt(3) / 2`:

| Конструктор | Поведение маски и владение данными |
| --- | --- |
| `PolyhexGeometry(Polyhex, radius)` | Сохраняет существующее неизменяемое значение, не копируя его маску повторно. |
| `PolyhexGeometry(bool[,], radius)` | Создаёт `Polyhex` и копирует логическую маску. |
| `PolyhexGeometry(int[,], radius)` | Создаёт `Polyhex`: каждый ненулевой элемент занят, а маска копируется. |
| `PolyhexGeometry(VectorQRSInt, radius)` | Создаёт пустую маску заданных размеров Q и R, а не заполненный прямоугольник. |

Радиус должен быть конечным и больше нуля, иначе конструктор выбрасывает
`ArgumentOutOfRangeException`. Значение `null` вместо `Polyhex` приводит к
`ArgumentNullException`, а маски и разрешение проверяются по описанным выше правилам.
`HexRadius`, `HexApothem`, `QRSResolution`, `HexCount` и оба индексатора занятости доступны только
для чтения.

```csharp
using Akeldov.Math.Hexes.Geometry;

var geometry = new PolyhexGeometry(polyhex, radius: 2f);

float radius = geometry.HexRadius;   // 2 единицы пространства координат
float apothem = geometry.HexApothem; // sqrt(3) единицы пространства координат
bool occupied = geometry[1, 2];
```

`GetExtended()` и `GetContour()` по-прежнему возвращают обычные топологические значения
`Polyhex`. Они не переносят радиус в новую геометрическую оболочку. Если физический размер нужно
сохранить, оберните результат явно:

```csharp
var extended = geometry.GetExtended();
var extendedGeometry = new PolyhexGeometry(extended, geometry.HexRadius);
```

## Преобразование маски в пространственные области

Методы расширения из
<xref:Akeldov.Math.Hexes.Geometry.Contours.HexMatrixExtensions> преобразуют любую корректную
реализацию `IPolyhexGeometry` в новые Spatial2D-объекты `ContourBasedRegion`:

| Операция | Результат |
| --- | --- |
| `ToRegion(layout)` | Точное заполненное объединение занятых правильных гексов с границей из отрезков. Общие внутренние рёбра исключаются. |
| `ToApothemOffsetRegion(layout)` | Заполненная область, граница которой смещена наружу от исходной на `HexApothem`; выпуклые соединения используют дуги того же радиуса. |

Импортируйте `Akeldov.Math.Hexes.Geometry.Contours`, чтобы методы расширения стали доступны:

```csharp
using Akeldov.Math.Hexes;
using Akeldov.Math.Hexes.Geometry;
using Akeldov.Math.Hexes.Geometry.Contours;

var geometry = new PolyhexGeometry(polyhex, radius: 2f);

var exactRegion = geometry.ToRegion(Layout.OddR);
var offsetRegion = geometry.ToApothemOffsetRegion(Layout.OddR);
```

Перегрузки без аргумента `layout` используют `Layout.OddR`. Раскладка не хранится в
`PolyhexGeometry`: выбирайте её согласованно при каждом преобразовании маски. R-раскладки создают
гексы вершиной вверх, а Q-раскладки — гексы горизонтальной стороной вверх. Для Q/R-маски нечётный
и чётный варианты одной ориентации размещаются одинаково: чётность важна только при преобразовании
смещённых индексов строк и столбцов.

Параметра пользовательского начала координат нет. Преобразование использует стандартное
размещение нулевого гекса:

| Раскладка | Центр ячейки маски `[0, 0]` |
| --- | --- |
| `OddR` или `EvenR` | `(HexApothem, HexRadius)` |
| `OddQ` или `EvenQ` | `(HexRadius, HexApothem)` |

Центры остальных ячеек размещаются от этой точки вдоль базиса QRS. Поэтому ограничивающий
прямоугольник первого гекса начинается с нуля, а его центр не лежит в начале пространственных
координат. Если требуется прикладное размещение, учитывайте его при включении возвращённых
контуров в остальную геометрию; оболочка не хранит начало координат.

Отверстия и несвязные занятые компоненты допустимы. `ToRegion()` создаёт отдельные замкнутые
контуры для цепочек границ отверстий и компонентов и использует правило заполнения even-odd.
`ToApothemOffsetRegion()` обрабатывает те же цепочки, разбивает пересекающиеся участки смещения и
возвращает замкнутые выходные граничные контуры. Если смещения встречаются, не полагайтесь на
совпадение количества или порядка контуров с исходной областью. Ни одно преобразование не изменяет
геометрическую оболочку или её маску.

Ошибки преобразования сообщаются явно:

- `null` вместо `IPolyhexGeometry` приводит к `ArgumentNullException`;
- любое значение раскладки, кроме `OddR`, `EvenR`, `OddQ` и `EvenQ`, приводит к
  `ArgumentOutOfRangeException`;
- маска без занятых ячеек (`HexCount == 0` у `PolyhexGeometry`) приводит к
  `InvalidOperationException`, потому что у неё нет границы;
- `ToRegion()` также выбрасывает `InvalidOperationException`, если отрезки границы не образуют
  замкнутые непрерывные цепочки;
- `ToApothemOffsetRegion()` выбрасывает `InvalidOperationException`, если невозможно получить
  подходящие участки смещённой границы или замкнутые цепочки.

Конструктор `PolyhexGeometry` исключает некорректные физические размеры. Пользовательская
реализация `IPolyhexGeometry` также должна предоставлять конечные положительные радиус и апофему,
а её разрешение и индексаторы должны быть согласованы.

## Равенство и идентичность

Два экземпляра `Polyhex` равны, если совпадают их размеры Q/R и каждое значение маски. `Equals`,
`==`, `!=` и `GetHashCode()` используют это структурное определение. Пустые поля являются частью
значения, поэтому маски с одинаковой занятой фигурой, но разными размерами не равны.

Благодаря неизменяемости хеш-код остаётся стабильным, и `Polyhex` подходит для ключей словаря.
`ToString()` — диагностическое представление нулей и единиц в порядке Q-major, а не формат
хранения.

`PolyhexGeometry` — ссылочный тип, который не переопределяет равенство. Две геометрические оболочки
сравниваются по идентичности ссылки, даже если их маски и радиусы содержат одинаковые значения.

## Проверка данных и граничные случаи

- Логическая и целочисленная исходные маски не могут быть `null`: конструкторы выбрасывают
  `ArgumentNullException`.
- Размеры Q и R должны быть больше нуля. Нулевое измерение массива, неположительный компонент
  `QRSResolution.Q` или `.R` и неположительный размер построителя приводят к
  `ArgumentOutOfRangeException`.
- Полностью пустая маска допустима и имеет `HexCount == 0`.
- Чтение или запись за пределами сохранённого диапазона Q/R, в том числе по отрицательному индексу,
  приводит к `IndexOutOfRangeException`. Индексы не прижимаются к границе и не зацикливаются.
- Произведение размеров вычисляется с проверкой переполнения; непредставимая длина внутреннего
  массива приводит к `OverflowException`.
- При создании пустые поля не обрезаются, отверстия не заполняются, а связность не проверяется.

Если отсутствие координаты за пределами маски является нормальной ветвью выполнения, проверяйте
внешние координаты до обращения по индексу.

## Двоичная сериализация

Парные двоичные расширения сохраняют полигекс, допускающий `null`, его разрешение и значения
ячеек сначала по Q:

```csharp
using System.IO;
using Akeldov.Math.Hexes.Topology;

using var stream = new MemoryStream();
using (var writer = new BinaryWriter(stream, System.Text.Encoding.UTF8, leaveOpen: true))
{
    writer.Write(polyhex);
}

stream.Position = 0;
using var reader = new BinaryReader(stream);
Polyhex? restored = reader.ReadPolyhexStamp();

bool roundTripSucceeded = restored == polyhex; // true
```

Метод записи принимает `null`, а метод чтения возвращает `null` при соответствующем флаге
отсутствующего значения. При успешном чтении непустого значения создаётся новый `Polyhex`.
Используйте согласованные методы чтения и записи одного контракта данных: поток не содержит
независимой версии схемы.
