# Получить хроматический индекс гекса

Используйте `GetChromaticClass`, чтобы отнести индекс гекса к одному из трёх классов: `0`, `1` или
`2`. Гексы с общим ребром всегда принадлежат разным классам, поэтому результат подходит для
независимых проходов обработки или устойчивых каналов интерполяции.

## Классифицировать индекс

Подключите расширения хроматизации и передайте ту же раскладку, которая задана в исходной топологии:

```csharp
using Akeldov.Math.Hexes;
using Akeldov.Math.Hexes.Chromatization;
using Akeldov.Math.Spatial2D;

var topology = new HexMapTopology(
    width: 4,
    height: 3,
    layout: Layout.OddR);

var hexIndex = new VectorXYInt(2, 1);
int chromaticIndex = hexIndex.GetChromaticClass(topology.Layout);

Console.WriteLine(chromaticIndex); // 1
```

Возвращаемое число — идентификатор класса, а не цвет изображения. При необходимости сопоставьте
классам `0`, `1` и `2` любые прикладные значения или цвета палитры.

Всегда используйте фактическую раскладку топологии. Один индекс `(X, Y)` может получить разные
классы в раскладках со смещением строк и столбцов. Неподдерживаемое значение `Layout` приводит к
`ArgumentOutOfRangeException`.

## Использовать метод конкретной раскладки

Если раскладка зафиксирована окружающим кодом, вызовите специализированное расширение:

```csharp
int chromaticIndex = hexIndex.GetOddRChromaticClass();
```

Доступны методы `GetOddRChromaticClass`, `GetEvenRChromaticClass`, `GetOddQChromaticClass` и
`GetEvenQChromaticClass`. Они возвращают тот же результат, что и `GetChromaticClass` с соответствующей
раскладкой.

## Правильно применить результат

Класс зависит только от логического индекса и раскладки. Размеры и значения карты, радиус гекса и
начало мировых координат на него не влияют. Отрицательные индексы допустимы и также дают результат
от `0` до `2`, поэтому метод классифицирует и подразумеваемую бесконечную гексагональную решётку.

Трёхцветная гарантия относится к непосредственным соседям по ребру. Ячейки одного класса не имеют
общего ребра, но всё ещё могут влиять друг на друга в алгоритмах с окрестностью глубже одного шага.
