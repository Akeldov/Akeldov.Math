# Координаты и раскладки

Используйте эти рецепты, чтобы преобразовывать координаты между логической QRS-сеткой,
прямоугольным хранилищем и пространством Akeldov.Math.Spatial2D. Примеры относятся к
Akeldov.Math.Hexes 0.1.0 и выполняются независимо друг от друга.

| Задача | Рецепт |
| --- | --- |
| Получить индекс столбца и строки из целочисленного QRS | [Преобразовать QRS в индекс строки и столбца](convert-qrs-to-row-and-column-indices.md) |
| Получить QRS из индекса хранилища | [Преобразовать индекс строки и столбца в QRS](convert-row-and-column-indices-to-qrs.md) |
| Разместить QRS в непрерывном пространстве | [Преобразовать QRS в координаты Spatial2D](convert-qrs-to-spatial2d-coordinates.md) |
| Определить гекс по пространственной точке | [Найти ближайший гекс для точки](find-the-nearest-hex-to-a-point.md) |
| Выбрать целочисленный гекс для дробного QRS | [Округлить дробные QRS-координаты](round-fractional-qrs-coordinates.md) |
| Выполнить точный или произвольный поворот | [Повернуть гексагональные координаты](rotate-hex-coordinates.md) |

Во всех преобразованиях используйте одну и ту же <xref:Akeldov.Math.Hexes.Layout>. Для
пространственных преобразований дополнительно сохраняйте радиус гекса и центр нулевого гекса:
одинаковые числовые координаты с другими параметрами описывают другую сетку.

Если нужна последовательная вводная практика, сначала пройдите руководство
[«Создание гексагональной карты»](../../tutorials/creating-a-hex-map/index.md).
