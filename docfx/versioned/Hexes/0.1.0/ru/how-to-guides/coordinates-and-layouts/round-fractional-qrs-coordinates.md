# Округлить дробные QRS-координаты

Используйте `VectorQRS.ToQRSIndex(layout)`, когда непрерывную QRS-координату нужно сопоставить с
ближайшим целочисленным гексом.

## Округление к допустимому QRS-индексу

```csharp
using Akeldov.Math.Hexes;
using Akeldov.Math.Hexes.Vectors.QRS;

var fractional = new VectorQRS(q: 1.2f, r: -2.3f);

VectorQRSInt nearest = fractional.ToQRSIndex(Layout.OddR);

Console.WriteLine(
    $"Nearest: ({nearest.Q}, {nearest.R}, {nearest.S})");
```

Результат:

```text
Nearest: (1, -2, 1)
```

Метод округляет три компонента кубической координаты, затем исправляет компоненту с наибольшей
ошибкой, чтобы сохранить инвариант `Q + R + S = 0`. Аргумент `Layout` определяет правило
разрешения граничных случаев для ориентации сетки; нечётный и чётный варианты одной ориентации
дают одинаковый QRS-результат.

## Не используйте явное приведение для поиска ближайшего гекса

```csharp
VectorQRSInt truncated = (VectorQRSInt)fractional;
```

Явное приведение усекает `Q` и `R` к нулю. Оно не выполняет кубическое округление и в общем случае
может выбрать другой гекс. Используйте его только тогда, когда именно усечение является частью
алгоритма.

`ToQRSIndex` отклоняет `NaN`, бесконечность, неизвестную раскладку и результаты, которые не
помещаются в `Int32`. После округления преобразуйте индекс в строки и столбцы методом
`ToXYIndex(layout)`, если нужно обратиться к прямоугольной карте.

Подробнее о типах координат см. в разделе
[«QRS-координаты»](../../concepts/fundamentals/coordinate-systems/qrs-coordinates.md).
