# Преобразование значений в цвета

Преобразуйте интерполированный скалярный растр в пиксели изображения. Встроенная температурная
палитра отображает низкие значения синим, а высокие — красным; выборки за пределами карты становятся
прозрачными.

## Создание растра RGBA

Добавьте этот код после создания `elevationRaster`:

```csharp
SpatialRaster<RGBA8BitColor> colorRaster =
    elevationRaster.MapValues(ToColor);

static RGBA8BitColor ToColor(float elevation)
{
    return float.IsNaN(elevation)
        ? new RGBA8BitColor(0, 0, 0, 0)
        : RGBA8BitColor.FromTemperature(elevation);
}
```

`MapValues` вызывает `ToColor` один раз для каждого пикселя и создаёт новый растр с прежней
`RasterGeometry`. Метод `FromTemperature` ожидает конечное нормализованное значение и ограничивает
значения вне диапазона от `0` до `1`. Предварительная проверка маркера `NaN` не допускает передачи
некорректного значения и сохраняет прозрачное поле.

Функцию `ToColor` можно заменить, не перестраивая служебные растры. Например, для полутонового
изображения она может возвращать `Gray8BitColor`, а для классифицированной карты — выбирать
дискретные цвета вместо непрерывной палитры.
