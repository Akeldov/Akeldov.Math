# Создание барицентрического растра

Индексный растр находит три окружающих центра гексов. Барицентрический растр задаёт соответствующие
веса интерполяции для этих центров.

## Повторное использование геометрии выборки

Сразу после создания `indexRaster` добавьте:

```csharp
var barycentricRaster = new BarycentricPartialTripletRaster(
    mapGeometry,
    rasterGeometry);
```

Оба растра должны использовать одинаковые `HexMapGeometry` и `RasterGeometry`. Совпадения одного
лишь разрешения недостаточно: начала координат и размеры в пространстве тоже должны совпадать.
При общих геометриях плоский индекс `i` описывает одну и ту же пиксельную выборку и одинаковые
позиции `Main`, `Left`, `Right` в обоих растрах.

У внутренней выборки сумма весов `Main`, `Left`, `Right` приблизительно равна `1`. На границе
конечной карты частичный растр сохраняет только присутствующие позиции и их исходные веса. Он
намеренно не нормализует их повторно — это будет сделано на следующем шаге при объединении весов
со значениями карты.

При создании растров вся пространственная классификация выполняется заранее. Используйте готовые
растры повторно, если значения карты меняются, а геометрия остаётся прежней.

Перейдите к [переносу значений карты в пиксели](mapping-map-values-to-pixels.md).
