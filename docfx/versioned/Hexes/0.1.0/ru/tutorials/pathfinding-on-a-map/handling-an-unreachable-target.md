# Обработка недоступной цели

В этой части руководства вы временно заблокируете цель и обработаете отсутствие маршрута.
Неудачный поиск является штатным результатом и представляется значением `null`.

## Блокировка цели

Добавьте этот код после успешного поиска и вывода его результата:

```csharp
float originalGoalEntryCost = entryCosts[goal];
entryCosts[goal] = float.PositiveInfinity;

HexPath? blockedPath = transferCosts.FindShortestPath(start, goal);

Console.WriteLine(
    blockedPath is null
        ? "Заблокированная цель недостижима."
        : "Маршрут неожиданно найден.");

entryCosts[goal] = originalGoalEntryCost;
```

Последняя строка результата:

```text
Заблокированная цель недостижима.
```

Любой маршрут должен войти в конечный гекс из соседнего. Поэтому бесконечная стоимость входа в
`goal` делает его недостижимым. Затем код восстанавливает прежнюю стоимость, чтобы перед
визуализацией успешный `path` снова соответствовал картам стоимости.

Проверяйте результат на `null` до чтения `HexIndexes` или `TotalCost`. Если `start` и `goal`
совпадают, метод возвращает путь из одного элемента с нулевой стоимостью при условии, что все
значения стоимости допустимы.
