# Поиск пути по карте

Создайте консольное .NET-приложение, которое ищет маршрут с минимальной стоимостью по небольшой
карте местности с помощью Akeldov.Math.Hexes 0.1.0. Вы назначите разные цены движения по равнине
и лесу, сделаете воду непроходимой, обработаете отсутствие пути и выведете результат в терминал.

Установите .NET 6 SDK или более новую версию. Все шаги дополняют один файл `Program.cs`, поэтому
их следует выполнять по порядку:

1. [Создайте карту местности](creating-a-terrain-map.md) и выберите начало и конец маршрута.
2. [Назначьте стоимости переходов](assigning-transfer-costs.md) для равнины, леса и воды.
3. [Добавьте непроходимые гексы](adding-impassable-hexes.md) с помощью положительной
   бесконечности.
4. [Найдите путь](finding-a-path.md) алгоритмом Дейкстры.
5. [Обработайте недостижимую цель](handling-an-unreachable-target.md), не обращаясь к `null`.
6. [Визуализируйте маршрут](visualizing-the-route.md) поверх карты местности.

В руководстве используется прямоугольная топология `OddR`. Поиск пути зависит от топологии и
стоимостей, но не от радиуса гекса или геометрии в мировых координатах.

Начните с раздела [Создание карты местности](creating-a-terrain-map.md).
