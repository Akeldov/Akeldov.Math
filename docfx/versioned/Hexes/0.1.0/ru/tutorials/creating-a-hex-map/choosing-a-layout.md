# Выбор раскладки

В этой части руководства вы выберете правило размещения прямоугольной гексагональной карты.
Продолжайте работу в проекте `HexMap.Tutorial`, созданном на предыдущем шаге.

## Ориентация и смещение

<xref:Akeldov.Math.Hexes.Layout> одновременно задаёт ориентацию гексов и строки или столбцы,
которые смещаются относительно соседних:

| Значение | Ориентация | Смещённая ось |
| --- | --- | --- |
| `OddR` | вершиной вверх | нечётные строки вправо |
| `EvenR` | вершиной вверх | чётные строки вправо |
| `OddQ` | плоской стороной вверх | нечётные столбцы вниз |
| `EvenQ` | плоской стороной вверх | чётные столбцы вниз |

В этом руководстве используется `OddR`: индексы `X` и `Y` удобно читать как столбец и строку, а
нечётные строки будут сдвинуты вправо при выводе.

Замените проверочный код в `Program.cs` выбором раскладки:

```csharp
using Akeldov.Math.Hexes;

Layout layout = Layout.OddR;

Console.WriteLine($"Раскладка:          {layout}");
Console.WriteLine($"Вершиной вверх:     {layout.IsPointyTop()}");
Console.WriteLine($"Плоской стороной:   {layout.IsFlatTop()}");
Console.WriteLine($"Ориентация:         {layout.GetHexOrientation()}");
```

Программа выведет:

```text
Раскладка:          OddR
Вершиной вверх:     True
Плоской стороной:   False
Ориентация:         PointyTop
```

Одна и та же раскладка должна использоваться при преобразовании координат, поиске соседей,
создании топологии и визуализации. Иначе один индекс будет обозначать разные гексы на разных
этапах.

Оставьте переменную `layout` в `Program.cs` и переходите к разделу
[«Работа с QRS-координатами»](working-with-qrs-coordinates.md).
