# Построение топологии полигекса

В этой части руководства вы скопируете маску в неизменяемый
<xref:Akeldov.Math.Hexes.Topology.Polyhex> и проверите его топологию.

## Создание полигекса

Замените `Console.WriteLine` после маски следующим кодом:

```csharp
var polyhex = new Polyhex(mask);

Console.WriteLine(
    $"Маска: {polyhex.QRSResolution.Q} x {polyhex.QRSResolution.R}");
Console.WriteLine($"Занято гексов: {polyhex.HexCount}");
Console.WriteLine($"Отверстие занято: {polyhex[2, 2]}");
```

Ожидаемый результат:

```text
Маска: 4 x 4
Занято гексов: 11
Отверстие занято: False
```

`QRSResolution.Q` и `.R` сохраняют размеры двух измерений маски. `HexCount` считает только
элементы со значением `true`, а не все 16 позиций.

Конструктор копирует логический массив. Последующие изменения `mask` не влияют на `polyhex`,
поэтому полигекс можно безопасно передавать как неизменяемое значение. Пустые фигуры, отверстия
и отдельные компоненты допустимы: тип не требует связности занятых ячеек.

Оставьте `polyhex` в `Program.cs` и переходите к разделу
[Получение рёбер и вершин](obtaining-edges-and-vertices.md).
