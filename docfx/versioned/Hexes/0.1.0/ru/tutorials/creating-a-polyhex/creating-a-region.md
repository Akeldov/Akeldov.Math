# Создание региона

В этой части руководства вы преобразуете все занятые ячейки в единый регион Spatial2D
<xref:Akeldov.Math.Spatial2D.Regions.ContourBasedRegion>. Общие внутренние рёбра будут удалены,
а окружённая фигурой незанятая ячейка останется отверстием.

## Построение границы

Добавьте в начало `Program.cs` пространства имён:

```csharp
using Akeldov.Math.Hexes.Geometry.Contours;
using Akeldov.Math.Spatial2D.Regions;
```

Затем добавьте после создания `geometry` следующий код:

```csharp
ContourBasedRegion region = geometry.ToRegion(layout);

Console.WriteLine($"Контуров региона: {region.Contours.Count}");
Console.WriteLine($"Правило заливки: {region.FillRule}");
```

Последние строки результата:

```text
Контуров региона: 2
Правило заливки: EvenOdd
```

Один замкнутый контур ограничивает фигуру снаружи, второй — отверстие в `[2, 2]`. По правилу
«чёт-нечет» точки внутри обоих вложенных контуров находятся вне заполненного региона.

`ToRegion` возвращает новый семантический результат и не изменяет `geometry` или `polyhex`.
Фигуры из нескольких отдельных компонентов тоже могут создавать несколько контуров. Не
полагайтесь на порядок контуров: публичным геометрическим контрактом являются операции заливки
и расстояния региона.

Переходите к разделу [Растеризация результата](rasterizing-the-result.md).
