# Учебники

Учебники знакомят с Hexes на примере последовательных практических проектов. Пройдите выбранный
учебник от первой страницы до последней, чтобы создать гексагональную карту, найти путь, построить
полигекс или подготовить карту к растеризации. Учебник по хроматизации — это короткое законченное
упражнение, в котором карта разбивается на три устойчивых класса.

Учебник [«Полные и частичные индексные карты»](creating-index-neighborhood-maps.md) содержит
два самостоятельных примера визуализации индексов соседей и сравнение обработки границ.
