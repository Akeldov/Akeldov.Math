# Creating a Hex Map

Build a .NET console application with a rectangular hex map using Akeldov.Math.Hexes. You
will configure its layout and QRS coordinates, store values, find neighbors and rings, and render
the result in the terminal.

Install the .NET 6 SDK or later. The steps build on one another and should be completed in order:

1. [Create the project](creating-a-project.md) and install the package.
2. [Choose the layout](choosing-a-layout.md) of the hex grid.
3. [Work with QRS coordinates](working-with-qrs-coordinates.md).
4. [Create the topology](creating-the-topology.md) for a 7×5 map.
5. [Store map data](storing-map-data.md) in a `HexMap<char>`.
6. [Find neighbors and rings](finding-neighbors-and-rings.md).
7. [Visualize the map](visualizing-the-map.md) in the console.

Start with [Creating a Project](creating-a-project.md).
