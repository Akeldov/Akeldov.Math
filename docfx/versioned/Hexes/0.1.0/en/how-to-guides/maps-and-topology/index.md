# Maps and Topology

Practical recipes for creating finite hex maps and working with relationships between their
cells:

- [Create and populate a HexMap](create-and-populate-a-hex-map.md) to store one value per cell.
- [Find hex neighbors](find-hex-neighbors.md) in the selected layout.
- [Get a ring of a given radius](get-a-ring-of-a-given-radius.md) by hex-grid distance.
- [Get edges and vertices](get-edges-and-vertices.md) to work with shared sides and corners.
- [Build polyhex topology from a mask](build-polyhex-topology-from-a-mask.md) to represent an
  arbitrary finite shape.

For the underlying model, see [Topology](../../concepts/hex-grid-model/topology.md),
[Maps](../../concepts/data-storage/maps.md), and
[Polyhexes](../../concepts/hex-grid-model/polyhexes.md).
