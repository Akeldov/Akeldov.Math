# Индексы строк и столбцов

Akeldov.Math.Hexes использует `VectorXYInt` как индекс прямоугольного хранилища гексагональной
карты. `X` — столбец, а `Y` — строка. Благодаря этому карты совместимы с обычными двумерными
массивами и построчным хранением, а <xref:Akeldov.Math.Hexes.Layout> указывает, как смещены гексы
в чередующихся строках или столбцах.

XY-индекс — это адрес в хранилище, а не декартово положение и не независимая от раскладки
координата гекса.

## Интерпретация индекса через раскладку

Все четыре раскладки используют один тип `VectorXYInt`:

| Раскладка | Ориентация гексов | Смещаемое измерение |
|---|---|---|
| `OddR` | Вершиной вверх | Нечётные строки |
| `EvenR` | Вершиной вверх | Чётные строки |
| `OddQ` | Горизонтальной стороной вверх | Нечётные столбцы |
| `EvenQ` | Горизонтальной стороной вверх | Чётные столбцы |

Поэтому числовая пара `(2, 3)` сама по себе не задаёт полный адрес на гексагональной сетке.
Храните связанную раскладку вместе с картой или передавайте её каждому преобразованию и операции
смежности.

Ориентации и правила смещения описаны на странице [«Раскладки»](../layouts.md).

## Преобразование QRS в индекс хранилища

Для преобразования целочисленной QRS-координаты вызовите `ToXYIndex(Layout)`. Точное обратное
преобразование выполняет `ToQRSIndex(Layout)`:

```csharp
using Akeldov.Math.Hexes;
using Akeldov.Math.Hexes.Vectors.QRS;
using Akeldov.Math.Spatial2D;

Layout layout = Layout.OddR;
var qrs = new VectorQRSInt(q: 2, r: -1);

VectorXYInt index = qrs.ToXYIndex(layout);
VectorQRSInt restored = index.ToQRSIndex(layout);

// index равен (1, -1)
// restored равен qrs
```

Прямое и обратное преобразования точны, если оба вызова используют одну раскладку. Обратное
преобразование с другой раскладкой обычно даёт другую QRS-координату.

Для справки обозначим `p(n) = n & 1`: это `0` для чётных целых и `1` для нечётных, включая
отрицательные нечётные числа. Преобразование QRS в XY использует следующие формулы:

| Раскладка | Столбец `X` | Строка `Y` |
|---|---|---|
| `OddR` | `Q + (R - p(R)) / 2` | `R` |
| `EvenR` | `Q + (R + p(R)) / 2` | `R` |
| `OddQ` | `Q` | `R + (Q - p(Q)) / 2` |
| `EvenQ` | `Q` | `R + (Q + p(Q)) / 2` |

Числители всегда чётные, поэтому целочисленное деление точно. В прикладном коде используйте
методы библиотеки вместо повторения этих формул; таблица нужна для объяснения соответствия.

## Адресация прямоугольных карт

<xref:Akeldov.Math.Hexes.HexMapTopology> объединяет неотрицательное разрешение `VectorXYInt` и
раскладку. Для топологии шириной `W` и высотой `H` корректные индексы удовлетворяют условиям:

```text
0 <= X < W
0 <= Y < H
```

`HexMap<T>` хранит по одному значению для каждого корректного индекса в построчном порядке.
Сначала изменяется `X`, а плоский индекс равен `Y * W + X`:

```csharp
using Akeldov.Math.Hexes;
using Akeldov.Math.Spatial2D;

var topology = new HexMapTopology(
    width: 4,
    height: 3,
    layout: Layout.OddR);
var terrain = new HexMap<string>(topology);

var index = new VectorXYInt(1, 2);
terrain[index] = "forest";

int flatIndex = index.Y * topology.Resolution.X + index.X; // 9
```

Индексатор с `VectorXYInt` проверяет обе границы карты. Преобразование QRS/XY работает на
бесконечной координатной сетке и не ограничивает результат конкретной картой, поэтому проверяйте
его перед обращением к карте.

## Поиск смежных индексов

Методы расширения топологии вычисляют соседей прямо в координатах со смещением и применяют
правила чётности раскладки:

```csharp
using Akeldov.Math.Hexes;
using Akeldov.Math.Hexes.Topology;
using Akeldov.Math.Spatial2D;

Layout layout = Layout.OddR;
var center = new VectorXYInt(1, 1);

VectorXYInt next = center.GetAdjacent(
    SixfoldAngle.Deg60,
    layout);
VectorXYInt[] neighbors = center.GetAdjacents(layout);
```

`GetAdjacents` возвращает новый массив из всех шести индексов соседей, смежных по ребру. Как и
преобразование координат, смежность вычисляется на бесконечной сетке и может вернуть отрицательные
или выходящие за карту индексы.

Не определяйте расстояние между гексами или все направления соседей обычным вычитанием `X`/`Y`:
смещение меняется вместе с чётностью строки или столбца. Используйте методы смежности либо
преобразуйте оба индекса в QRS для не зависящих от раскладки вычислений.

## Работа с отрицательными индексами

Преобразование координат и операции смежности поддерживают отрицательные строки и столбцы.
Чётность остаётся числовой: `-1` и `-3` нечётные, а `-2` чётное. Формулы преобразования намеренно
используют битовую чётность, чтобы прямое и обратное преобразования отрицательных значений были
согласованы.

Отрицательные индексы полезны для неограниченной логической сетки, временных смещений и карт, чьё
мировое начало координат не совпадает с нулевым индексом хранилища. Для прямоугольной
`HexMap<T>` они остаются за границами, пока прикладной код не преобразует их в допустимый диапазон
или не отфильтрует.

Затем переходите к [пространственным координатам](spatial-coordinates.md), чтобы разместить индекс
в мировом пространстве, или к [дискретизации координат](../coordinate-discretization.md), чтобы
получить индекс из точки.
