# QRS-координаты

QRS-координаты описывают гексагональную решётку тремя осями, разделёнными углами 120°. Это
кубические координаты, ограниченные плоскостью

```text
Q + R + S = 0
```

Независимы только два компонента. Akeldov.Math.Hexes принимает `Q` и `R` в конструкторах и
вычисляет `S`, но предоставляет все три компонента для симметричных вычислений.

## Выбор целочисленного или дробного QRS

В пространстве имён `Akeldov.Math.Hexes.Vectors.QRS` определены два неизменяемых типа значений:

| Тип | Компоненты | Применение |
|---|---|---|
| <xref:Akeldov.Math.Hexes.Vectors.QRS.VectorQRSInt> | `int` | Координаты ячеек, точные смещения по сетке, ключи словарей и повороты с шагом 60° |
| <xref:Akeldov.Math.Hexes.Vectors.QRS.VectorQRS> | `float` | Значения между центрами ячеек, интерполяция, масштабирование, произвольный поворот и округление |

Создайте значение любого типа из независимых компонентов:

```csharp
using Akeldov.Math.Hexes.Vectors.QRS;

var cell = new VectorQRSInt(q: 2, r: -1);
var sample = new VectorQRS(q: 1.5f, r: -0.25f);

int cellS = cell.S;       // -1
float sampleS = sample.S; // -1.25
```

У `VectorQRSInt` также есть конструктор с тремя компонентами. Он принимает значение только при
нулевой сумме:

```csharp
var sameCell = new VectorQRSInt(q: 2, r: -1, s: -1);
```

Целочисленный конструктор с двумя компонентами отклоняет значения, для которых вычисленный `S`
не помещается в `Int32`. Конструктор с тремя компонентами отклоняет любую ненулевую сумму.

## Работа с неизменяемыми значениями

Оба QRS-типа — неизменяемые структуры `readonly struct`. Присваивание копирует значение, их
свойства нельзя изменить, а арифметические операции возвращают новую координату:

```csharp
var start = new VectorQRSInt(1, -2);
var offset = new VectorQRSInt(2, 0);

VectorQRSInt destination = start + offset; // Q/R/S: 3, -2, -1
VectorQRSInt difference = destination - start; // Q/R/S: 2, 0, -2
VectorQRSInt doubled = offset * 2; // Q/R/S: 4, 0, -4
```

Целочисленные сложение, вычитание и умножение проверяют переполнение `Q` и `R` и выбрасывают
`OverflowException` вместо перехода к другой ячейке. Если эти компоненты помещаются в диапазон, а
вычисленный `S` — нет, конструктор выбрасывает `ArgumentOutOfRangeException`. Целочисленное деление
делит `Q` и `R` с обычным усечением и вычисляет новый `S`; если нужен дробный масштаб, сначала
преобразуйте значение в `VectorQRS`.

Дробная арифметика следует обычным правилам вычислений с плавающей точкой одинарной точности:

```csharp
var value = new VectorQRS(3f, -1f);

VectorQRS half = value / 2f; // (1.5, -0.5, -1)
VectorQRS moved = half + new VectorQRS(0.25f, 0.5f);
```

Дробный конструктор не отклоняет `NaN` или бесконечность. Операции, которым нужны конечные
координаты, например дискретизация и геометрическое преобразование, проверяют аргументы при вызове
публичного метода.

## Равенство и деконструкция

`Equals`, `==` и `!=` точно сравнивают независимые компоненты. Производный `S` однозначно задан
инвариантом, поэтому достаточно сравнить `Q` и `R`. Точное равенство делает `VectorQRSInt`
естественным ключом словарей и множеств.

Деконструкция возвращает два независимых компонента:

```csharp
var coordinate = new VectorQRSInt(2, -1);
var (q, r) = coordinate;
int s = coordinate.S;
```

Для сравнения дробных значений, полученных разными вычислениями с плавающей точкой, задавайте
допуск явно в прикладном коде.

## Преобразование целочисленных и дробных значений

Преобразование `VectorQRSInt` в `VectorQRS` неявное, поскольку оно намеренно не отбрасывает
дробную часть:

```csharp
VectorQRSInt cell = new VectorQRSInt(2, -1);
VectorQRS fractional = cell;
```

`VectorQRS` использует компоненты `float`, поэтому очень большие целочисленные координаты могут
потерять точность при таком преобразовании.

Обратное преобразование явное и усекает `Q` и `R` к нулю:

```csharp
var fractional = new VectorQRS(2.8f, -1.2f);
var truncated = (VectorQRSInt)fractional; // Q/R/S: 2, -1, -1
```

Усечение не является округлением к ближайшему гексу. Для выбора ближайшей ячейки используйте
`ToQRSIndex(Layout)`; см. [«Дискретизация координат»](../coordinate-discretization.md).

## Расстояние по сетке

Расстояние между двумя гексами — наименьшее число шагов между смежными по ребру ячейками. Для
разности QRS оно равно наибольшему абсолютному компоненту:

```csharp
using System;

var from = new VectorQRSInt(0, 0);
var to = new VectorQRSInt(2, -1);

long deltaQ = (long)to.Q - from.Q;
long deltaR = (long)to.R - from.R;
long deltaS = (long)to.S - from.S;

long distance = Math.Max(
    Math.Abs(deltaQ),
    Math.Max(Math.Abs(deltaR), Math.Abs(deltaS)));

// distance == 2
```

Эквивалентное выражение — `(abs(deltaQ) + abs(deltaR) + abs(deltaS)) / 2`. Вычисляйте разности в
`long`, как в примере, чтобы вычитание и `Math.Abs` были корректны для любых компонентов
`VectorQRSInt`. В пакете нет отдельного метода расстояния QRS, поэтому при необходимости
оставьте это вычисление в прикладном коде.

Шесть единичных смещений к смежным по ребру гексам: `(1, 0, -1)`, `(1, -1, 0)`,
`(0, -1, 1)`, `(-1, 0, 1)`, `(-1, 1, 0)` и `(0, 1, -1)`. Для индексов строк и столбцов
предоставлены учитывающие раскладку методы смежности; см.
[«Индексы строк и столбцов»](row-and-column-indices.md).

## Связь QRS с раскладкой

QRS-значение не хранит смещение строк или столбцов. Поэтому нечётный и чётный варианты одной
ориентации используют одинаковые оси QRS. <xref:Akeldov.Math.Hexes.Layout> всё же требуется при
преобразовании QRS в прямоугольный индекс или ориентированный пространственный базис.

Ориентация и чётность описаны на странице [«Раскладки»](../layouts.md), геометрическое
преобразование QRS/XY — на странице [«Пространственные координаты»](spatial-coordinates.md), а
точные и произвольные повороты — на странице
[«Повороты и преобразования»](../rotations-and-transformations.md).
