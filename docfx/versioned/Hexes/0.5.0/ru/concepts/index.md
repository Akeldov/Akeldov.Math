# Концепции

Концептуальная документация объясняет основные идеи и проектные решения Hexes: системы координат
и раскладки, модель гексагональной сетки, хранение данных, пространственные алгоритмы и
растеризацию. Этот раздел помогает понять, как библиотека представляет гексагональные данные и
как связаны её API.
