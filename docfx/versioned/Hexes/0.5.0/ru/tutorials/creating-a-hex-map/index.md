# Создание гексагональной карты

Создайте консольное приложение .NET с прямоугольной гексагональной картой на основе
Akeldov.Math.Hexes. Вы настроите раскладку и QRS-координаты, заполните карту, найдёте
соседей и кольца, а затем выведете результат в терминал.

Установите .NET SDK 6 или новее. Шаги продолжают друг друга, поэтому проходите их по порядку:

1. [Создайте проект](creating-a-project.md) и установите пакет.
2. [Выберите раскладку](choosing-a-layout.md) гексагональной сетки.
3. [Поработайте с QRS-координатами](working-with-qrs-coordinates.md).
4. [Создайте топологию](creating-the-topology.md) карты 7×5.
5. [Сохраните данные](storing-map-data.md) в `HexMap<char>`.
6. [Найдите соседей и кольца](finding-neighbors-and-rings.md).
7. [Визуализируйте карту](visualizing-the-map.md) в консоли.

Начните с раздела [«Создание проекта»](creating-a-project.md).
