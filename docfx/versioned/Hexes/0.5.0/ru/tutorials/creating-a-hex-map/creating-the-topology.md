# Создание топологии

В этой части руководства вы зададите конечную прямоугольную область гексагональной карты.
Топология объединяет размеры хранилища и выбранную ранее раскладку, но ещё не содержит значения
ячеек.

## Карта размером 7×5

После объявления `layout` создайте <xref:Akeldov.Math.Hexes.HexMapTopology>:

```csharp
var topology = new HexMapTopology(
    width: 7,
    height: 5,
    layout: layout);

Console.WriteLine(
    $"Разрешение: {topology.Resolution.X} × {topology.Resolution.Y}");
Console.WriteLine($"Количество гексов: {topology.Count}");
Console.WriteLine($"Раскладка топологии: {topology.Layout}");
```

Результат:

```text
Разрешение: 7 × 5
Количество гексов: 35
Раскладка топологии: OddR
```

`Resolution.X` задаёт число столбцов, `Resolution.Y` — число строк, а `Count` равен их
произведению. Допустимые индексы лежат в диапазонах `0..6` по `X` и `0..4` по `Y`.

Топология описывает только существующие ячейки и их раскладку. Она не задаёт радиус гекса,
положение сетки в пространстве или данные внутри ячеек. Для хранения значений на следующем шаге
вы создадите карту с этой топологией.

Оставьте переменную `topology` в `Program.cs` и переходите к разделу
[«Хранение данных в карте»](storing-map-data.md).
