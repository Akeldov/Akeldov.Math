# Преобразование в геометрию Spatial2D

В этой части руководства вы свяжете всю неизменяемую маску с физическим радиусом гекса.
<xref:Akeldov.Math.Hexes.Geometry.PolyhexGeometry> объединяет топологию полигекса с размерами,
необходимыми для преобразования в Spatial2D.

## Добавление геометрической оболочки

Добавьте этот код после создания рёбер образца:

```csharp
var geometry = new PolyhexGeometry(polyhex, hexRadius);

Console.WriteLine($"Гексов в геометрии: {geometry.HexCount}");
Console.WriteLine($"Радиус гекса: {geometry.HexRadius}");
```

Последние строки результата:

```text
Гексов в геометрии: 11
Радиус гекса: 1
```

Оболочка сохраняет неизменяемый `polyhex` и предоставляет его маску через те же доступные только
для чтения индексаторы. Она также хранит `HexRadius` и вычисляет `HexApothem` как
`HexRadius * sqrt(3) / 2`.

Раскладка намеренно не хранится в `PolyhexGeometry`. Используйте одну раскладку при каждом
преобразовании маски в XY-точки, контуры или регионы. В руководстве продолжает использоваться
`OddR`.

Радиус должен быть конечным и больше нуля. Он выражается в единицах координатного пространства
результирующей геометрии Spatial2D.

Переходите к разделу [Создание региона](creating-a-region.md).
