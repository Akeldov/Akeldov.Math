# Обработка частичных окрестностей на границах

Используйте частичный растр, когда выборки могут касаться конечной карты или выходить за её
границы. Он сохраняет порядок `Main`, `Left`, `Right` и явно отмечает позиции, попавшие в исходную
топологию.

## Переход к частичным индексам

Замените создание `IndexTripletRaster` из предыдущего шага следующим кодом:

```csharp
var indexRaster = new IndexPartialTripletRaster(
    mapGeometry,
    rasterGeometry);
```

Теперь каждая выборка имеет тип `PartialTriplet<VectorXYInt>`. Перед чтением индекса из
`elevationMap` проверяйте соответствующее свойство `HasMain`, `HasLeft` или `HasRight`. Не
сравнивайте индекс с `VectorXYInt.Zero`: `(0, 0)` — допустимая ячейка карты, а не признак отсутствия.

В добавленное поле попадают и выборки, которым не соответствует ни одна ячейка карты. У такой
выборки `Presence == TripletPresenceFlags.None`; позднее она станет прозрачным пикселем.

Частичный растр не прижимает индекс за границей к ближайшей ячейке. Флаги присутствия сохраняют
явную границу конечной карты, а на этапе интерполяции можно нормализовать оставшиеся веса либо
оставить пиксель пустым.

Перейдите к [созданию барицентрического растра](creating-a-barycentric-raster.md).
