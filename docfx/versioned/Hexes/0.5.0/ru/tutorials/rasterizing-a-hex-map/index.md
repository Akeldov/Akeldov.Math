# Растеризация гексагональной карты

Преобразуйте значения в центрах гексов в тепловую карту PNG с плавными переходами. Вы создадите
общую сетку выборки, найдёте три гекса вокруг каждого пикселя, интерполируете их значения с
барицентрическими весами, обработаете границу конечной карты и назначите результату цвета.

В руководстве используется карта 9×7 с раскладкой `OddR` и 8-битные цвета RGBA из
Akeldov.Math.Spatial2D. Сначала пройдите [Создание гексагональной карты](../creating-a-hex-map/index.md)
либо подготовьте консольный проект для .NET 6 или новее со ссылкой на `Akeldov.Math.Hexes`.

Выполняйте шаги последовательно:

1. [Подготовьте топологию и исходную карту](preparing-topology-and-source-map.md).
2. [Создайте индексный растр](creating-an-index-raster.md) для пространственного поиска.
3. [Обработайте частичные окрестности на границах](handling-partial-boundary-neighborhoods.md).
4. [Создайте барицентрический растр](creating-a-barycentric-raster.md) на той же сетке выборки.
5. [Перенесите значения гексов в пиксели](mapping-map-values-to-pixels.md) с интерполяцией.
6. [Преобразуйте интерполированные значения в цвета](mapping-values-to-colors.md).
7. [Экспортируйте изображение](exporting-the-image.md) в PNG.

В результате получатся плавные переходы между значениями в центрах гексов и прозрачный фон за
границей конечной карты. Начните с раздела
[Подготовка топологии и исходной карты](preparing-topology-and-source-map.md).
