# Создание индексного растра

Индексный растр определяет, центры каких трёх гексов окружают каждую пиксельную выборку. Он хранит
данные для пространственного поиска, но ещё не рисует изображение.

## Создание общей сетки выборки

Добавьте следующий код после заполнения `elevationMap`:

```csharp
const float PixelsPerApothem = 32f;

RasterGeometry rasterGeometry = mapGeometry.ToRasterGeometry(
    pixelsPerApothem: PixelsPerApothem,
    margin: mapGeometry.Radius * 0.5f);

var indexRaster = new IndexTripletRaster(mapGeometry, rasterGeometry);
```

`RasterGeometry` фиксирует начало координат, размер в пространстве и разрешение в пикселях для
всех следующих шагов. Плотность 32 пикселя на апофему даёт плавное изображение, а поле в половину
радиуса позволяет увидеть прозрачную область вокруг карты.

Для каждой ячейки растра `IndexTripletRaster` хранит `Triplet<VectorXYInt>` в порядке `Main`,
`Left`, `Right`. `Main` — содержащий либо ближайший гекс. `Left` и `Right` — два других гекса,
которые встречаются с ним у ближайшей вершины.

## Почему полного растра недостаточно

Полный растр описывает бесконечную гексагональную сетку, заданную геометрией. Поэтому около внешней
границы некоторые индексы выходят за пределы конечной топологии 9×7. Это полезно в геометрических
вычислениях, но обращение к `elevationMap` по такому индексу вызовет `IndexOutOfRangeException`.

На следующем шаге этот растр будет заменён вариантом, учитывающим границу. Перейдите к
[обработке частичных окрестностей на границах](handling-partial-boundary-neighborhoods.md).
