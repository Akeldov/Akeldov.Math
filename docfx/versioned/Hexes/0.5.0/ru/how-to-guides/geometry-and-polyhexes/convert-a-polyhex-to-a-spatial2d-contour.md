# Преобразовать полигекс в контур Spatial2D

Используйте `ToRegion()`, чтобы построить точную границу занятых гексов в Spatial2D, затем
получите коллекцию `Contours` созданного региона. Преобразование удаляет общие рёбра соседних
гексов и возвращает замкнутые объекты `IContour`.

> [!NOTE]
> `GetContour()` — топологическая операция: она возвращает маску `Polyhex` из незанятых ячеек,
> соседних с исходной фигурой. Геометрический контур Spatial2D этот метод не создаёт.

## Построение граничного контура

Создайте <xref:Akeldov.Math.Hexes.Geometry.PolyhexGeometry>, чтобы задать физический радиус гексов,
подключите расширения для контуров и вызовите `ToRegion()` с раскладкой фигуры:

```csharp
using System.Collections.Generic;
using Akeldov.Math.Hexes;
using Akeldov.Math.Hexes.Geometry;
using Akeldov.Math.Hexes.Geometry.Contours;
using Akeldov.Math.Spatial2D.Contours;
using Akeldov.Math.Spatial2D.Regions;

var geometry = new PolyhexGeometry(
    new bool[,]
    {
        { true, true  },
        { true, false }
    },
    radius: 2f);

ContourBasedRegion region = geometry.ToRegion(Layout.OddR);
IReadOnlyList<IContour> contours = region.Contours;

IContour contour = contours[0];

Console.WriteLine($"Контуров: {contours.Count}");
Console.WriteLine($"Длина границы: {contour.Length}");
```

Результат:

```text
Контуров: 1
Длина границы: 24
```

В примере одна связная компонента без отверстий, поэтому обращение к `contours[0]` безопасно.
Контур представляет собой замкнутую цепочку отрезков вокруг объединения трёх занятых гексов.
`ToRegion()` возвращает новый результат и не изменяет геометрию или её маску.

## Обработка нескольких контуров

Полигекс с отверстием или несколькими несвязными занятыми компонентами создаёт несколько
замкнутых контуров. Если важна вся заполненная фигура, сохраняйте полную коллекцию:

```csharp
foreach (IContour boundary in region.Contours)
{
    Console.WriteLine($"Длина границы: {boundary.Length}");
}
```

Не полагайтесь на порядок контуров и не считайте первый контур внешней границей во всех случаях.
Возвращённый регион интерпретирует все границы вместе по правилу заливки «чёт-нечет». Если нужно
проверить принадлежность или найти расстояние для всего полигекса, а не для отдельной границы,
используйте `region.Contains(point)`, `region.Distance(point)` или `region.SignedDistance(point)`.

## Согласованный выбор раскладки

Перегрузка без аргумента раскладки использует `Layout.OddR`. R-раскладки создают гексы вершиной
вверх, а Q-раскладки — гексы горизонтальной стороной вверх. `PolyhexGeometry` не хранит
раскладку, поэтому при каждом преобразовании маски передавайте одну и ту же ориентацию.

Параметра пользовательского начала координат нет. В R-раскладках центр ячейки маски `[0, 0]`
равен `(HexApothem, HexRadius)`, а в Q-раскладках — `(HexRadius, HexApothem)`. При объединении
возвращённых границ с другой геометрией примените нужное приложению размещение отдельно.

Маска должна содержать хотя бы одну занятую ячейку. У пустой маски нет геометрической границы,
поэтому `ToRegion()` выбрасывает `InvalidOperationException`. Значение `null` вместо геометрии
приводит к `ArgumentNullException`, а неподдерживаемое значение раскладки — к
`ArgumentOutOfRangeException`.

Различия между топологическими масками и пространственной геометрией описаны в разделе
[«Полигексы»](../../concepts/hex-grid-model/polyhexes.md). Ориентации раскладок и формулы размещения
приведены в разделе
[«Геометрия гексагональной сетки»](../../concepts/hex-grid-model/geometry.md).
