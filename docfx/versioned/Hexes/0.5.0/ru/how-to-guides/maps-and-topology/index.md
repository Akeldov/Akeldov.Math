# Карты и топология

Практические руководства по созданию конечных гексагональных карт и работе со связями между их
ячейками:

  каждой ячейке.
- [Использовать специализированные карты](use-specialized-hex-maps.md) для масок и числовых полей.
- [Объединять карты и выбирать значения](combine-and-select-hex-map-values.md) без ручных циклов.
- [Создать и сгладить шум](generate-and-smooth-noise.md) для детерминированных процедурных полей.
- [Найти соседей гекса](find-hex-neighbors.md) в выбранной раскладке.
- [Получить кольцо заданного радиуса](get-a-ring-of-a-given-radius.md) по расстоянию на
  гексагональной сетке.
- [Получить рёбра и вершины](get-edges-and-vertices.md) для работы с общими сторонами и углами.
- [Построить топологию полигекса из маски](build-polyhex-topology-from-a-mask.md), чтобы представить
  произвольную конечную форму.
