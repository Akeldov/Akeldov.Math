# Rasters

Practical guides for sampling hex maps on rectangular grids and exporting the results:

- [Create an index triplet raster](create-an-index-triplet-raster.md) for the three hexes around each sample.
- [Create an index septuplet raster](create-an-index-septuplet-raster.md) for a hex and all six edge neighbors.
- [Handle partial neighborhoods](handle-partial-neighborhoods.md) at finite-map boundaries.
- [Create a barycentric raster](create-a-barycentric-raster.md) for interpolation weights.
- [Rasterize HexMap values](rasterize-hex-map-values.md) by sampling one containing hex per cell.
- [Convert a raster to an image](convert-a-raster-to-an-image.md) and export PNG or BMP.

For the underlying model, see [Rasterization](../../concepts/rasterization.md).
