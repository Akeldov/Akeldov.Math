# Akeldov.Math.Hexes

Akeldov.Math.Hexes предоставляет координаты, раскладки, топологию, геометрию, карты, поиск пути,
растеризацию, обработку полигексов и взвешенное разбиение гексагональных сеток.

## Установка

```powershell
dotnet add package Akeldov.Math.Hexes --version 0.9.0
```

## Основные возможности

- Дробные и целочисленные QRS-координаты
- Раскладки с горизонтальными и вертикальными рядами гексов
- Логические, целочисленные и вещественные карты с обычными и пространственными вариантами
- Поячеечная арифметика, сравнения, преобразования диапазона и логическая морфология
- Выборка шести соседей с учётом раскладки, заливка, маркировка компонент и преобразование расстояний
- Генерация шума Перлина и гауссово размытие
- Взвешенный поиск пути, растеризация, хроматизация и геометрия полигексов
- [Сериализация в поток и файл](how-to-guides/maps-and-topology/save-and-load-hex-maps.md) для всех шести типов карт

[Открыть пакет на NuGet](https://www.nuget.org/packages/Akeldov.Math.Hexes/)

регионов, разделение несвязных ячеек и настраиваемая релаксация Вороного.

См. [примеры разбиения и диффузии](how-to-guides/geometry-and-polyhexes/partition-and-diffuse-territories.md)
