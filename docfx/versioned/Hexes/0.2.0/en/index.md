# Akeldov.Math.Hexes

Akeldov.Math.Hexes provides hex-grid coordinates, layouts, topology, geometry, maps, pathfinding, rasterization, polyhex processing, and weighted partitioning.

## Install

```powershell
dotnet add package Akeldov.Math.Hexes --version 0.2.0
```

## Highlights

- Fractional and integer QRS coordinates
- Pointy-top and flat-top layouts
- Specialized Boolean, integer, and floating-point hex maps
- Perlin-noise generation and Gaussian blur
- Hex-map topology and geometry
- Weighted pathfinding
- Rasterization and chromatization
- Polyhex contours and regions
