# Импорт

Импорт восстанавливает гексагональную карту из бинарной записи, созданной при
[экспорте](export.md). Для чтения файла используйте <xref:Akeldov.Math.Hexes.HexMapFile>,
для существующего потока — методы <xref:Akeldov.Math.Hexes.HexMapBinaryReaderExtensions>
у `BinaryReader`. Каждый успешный вызов создаёт новую изменяемую карту с независимым
хранилищем, принадлежащую вызывающему коду.

## Выбор метода чтения

Метод должен соответствовать типу значений и наличию пространственной геометрии в записи:

| Значения | Импорт карты без геометрии | Импорт пространственной карты |
|---|---|---|
| `bool` | `ReadBoolHexMap` | `ReadSpatialBoolHexMap` |
| `int` | `ReadIntHexMap` | `ReadSpatialIntHexMap` |
| `float` | `ReadFloatHexMap` | `ReadSpatialFloatHexMap` |

Все шесть методов доступны и у `HexMapFile`, и у `BinaryReader`. Чтение карты без геометрии
восстанавливает размеры, раскладку и значения ячеек. Пространственные методы также восстанавливают
начало координат и радиус гекса. Импорт не преобразует типы значений и не отбрасывает геометрию:
чтение другого вида записи вызывает `InvalidDataException`. Произвольные типы значений
`HexMap<T>` не поддерживаются.

Вид записи определяется перегрузкой записи. Пространственная карта, экспортированная через
переменную `IHexMap<T>`, содержит только топологию и значения, поэтому требует метода чтения
карты без геометрии. См. [Сохранение пространственной геометрии](export.md#сохранение-пространственной-геометрии).

## Импорт файла

Прочитайте булеву карту, сохранённую в `mask.hmap` в примере [экспорта](export.md):

```csharp
using Akeldov.Math.Hexes;

BoolHexMap mask = HexMapFile.ReadBoolHexMap(
    "mask.hmap", maxCellCount: 1_000_000);
```

Поддерживаются абсолютные и относительные пути; относительные отсчитываются от текущего рабочего
каталога процесса. Файловые методы закрывают файл и при успехе, и при ошибке. Они читают первую
запись и игнорируют оставшиеся байты. Для чтения нескольких записей используйте `BinaryReader`.

## Импорт из потока

Reader должен находиться в начале следующей записи `HMAP`. В примере булева карта читается из
файлового потока, который остаётся открытым после освобождения reader:

```csharp
using System.IO;
using System.Text;
using Akeldov.Math.Hexes;

using var stream = File.OpenRead("mask.hmap");
using var reader = new BinaryReader(stream, Encoding.UTF8, leaveOpen: true);
BoolHexMap mask = reader.ReadBoolHexMap(maxCellCount: 1_000_000);
```

Метод расширения оставляет reader и поток открытыми. Их временем жизни управляет вызывающий
код; здесь `using` освобождает оба объекта в конце области видимости. Успешный вызов потребляет
ровно одну запись, оставляя последующие данные доступными. Читайте несколько карт в порядке
записи, выбирая соответствующий метод для каждой. Поддерживаются потоки как с возможностью
перемещения, так и без неё.

После записи в поток с возможностью перемещения сбросьте буфер writer и установите позицию
на начало записи перед чтением. При ошибке чтения прежняя позиция потока не восстанавливается.

## Импорт пространственной карты

Прочитайте пространственную вещественную карту, сохранённую в `heights.hmap` в примере экспорта:

```csharp
using Akeldov.Math.Hexes;

SpatialFloatHexMap heights = HexMapFile.ReadSpatialFloatHexMap(
    "heights.hmap", maxCellCount: 1_000_000);
```

Восстановленная карта сохраняет топологию, начало координат, радиус и значения. Передавать новую
`HexMapGeometry` не нужно. Вещественные значения сохраняют битовое представление, включая
знаковый ноль, бесконечности и полезную нагрузку NaN. Пустые карты сохраняют размеры, а
пространственные записи — также геометрию.

## Ограничения и некорректные данные

`maxCellCount` задаёт максимальное число ячеек и проверяется до выделения памяти под значения.
По умолчанию он равен `int.MaxValue`; укажите лимит, подходящий приложению. Ноль разрешает только
пустые карты. При чтении проверяются сигнатура `HMAP`, версия формата, вид записи, размеры,
раскладка и пространственная геометрия. Для потоков с возможностью перемещения наличие всех
байтов значений также проверяется до выделения массива.

| Исключение | Причина |
|---|---|
| `InvalidDataException` | Некорректная или неподдерживаемая запись, несовпадение вида карты или значений, неверный булев байт, некорректная геометрия или превышение лимита ячеек |
| `EndOfStreamException` | Неполный заголовок или данные значений |
| `ArgumentOutOfRangeException` | Отрицательный `maxCellCount` |
| `ArgumentNullException` | Путь или reader равен null |

Исключения файловой системы передаются вызывающему коду. Формат не содержит контрольной суммы,
поэтому структурная проверка не обнаруживает все возможные изменения сохранённых значений.
