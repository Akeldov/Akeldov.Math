# Экспорт

Экспорт записывает гексагональную карту в бинарном формате через
<xref:Akeldov.Math.Hexes.HexMapFile> или методы расширения для `BinaryWriter`. Запись сохраняет
размеры, раскладку и значения ячеек; пространственная запись также сохраняет начало координат
и радиус гекса. Восстановление карт через `ReadBoolHexMap` и остальные методы чтения описано
в разделе [Импорт](import.md).

## Поддерживаемые типы карт

Все перегрузки экспорта называются `Write`. Они поддерживают булевы, целочисленные и
вещественные карты:

| Значения | Источник без геометрии | Пространственный источник |
|---|---|---|
| `bool` | `IHexMap<bool>` | `ISpatialHexMap<bool>` |
| `int` | `IHexMap<int>` | `ISpatialHexMap<int>` |
| `float` | `IHexMap<float>` | `ISpatialHexMap<float>` |

Эти перегрузки доступны и у `HexMapFile`, и у `BinaryWriter`. Произвольные типы значений
`HexMap<T>` не поддерживаются. Не изменяйте исходную карту во время записи.

## Экспорт файла

```csharp
using Akeldov.Math.Hexes;

var mask = new BoolHexMap(
    new HexMapTopology(3, 2, Layout.OddR),
    new[] { true, false, true, false, true, false });

HexMapFile.Write("mask.hmap", mask);
```

`Write` создаёт или перезаписывает файл. Родительский каталог должен существовать, а относительные
пути отсчитываются от текущего рабочего каталога процесса. При успехе буфер файла сбрасывается
и файл закрывается; при ошибке файл также закрывается. Запись не атомарна: ошибка после открытия
может оставить частично записанный файл. Исключения файловой системы передаются вызывающему коду.

## Экспорт в поток

Используйте <xref:Akeldov.Math.Hexes.HexMapBinaryWriterExtensions> для записи в существующий
бинарный поток. Пример экспортирует булеву карту в массив байтов в памяти:

```csharp
using System.IO;
using System.Text;
using Akeldov.Math.Hexes;

var mask = new BoolHexMap(
    new HexMapTopology(2, 1, Layout.OddR), new[] { true, false });

using var stream = new MemoryStream();
using var writer = new BinaryWriter(stream, Encoding.UTF8, leaveOpen: true);
writer.Write(mask);
writer.Flush();
byte[] data = stream.ToArray();
```

Методы расширения оставляют writer и сам поток открытыми. Они не сбрасывают буферы и не меняют
позицию отдельно от записи; временем жизни и позиционированием управляет вызывающий код.
Потоки без возможности перемещения также поддерживаются. Каждый вызов добавляет одну запись,
поэтому поток может содержать несколько карт и другие данные. Чтение таких записей описано
в разделе [Импорт из потока](import.md#импорт-из-потока).

## Сохранение пространственной геометрии

Выбор перегрузки зависит от типа источника на этапе компиляции. Конкретная пространственная
карта или `ISpatialHexMap<T>` выбирает пространственную перегрузку `Write`, сохраняющую начало
координат и радиус:

```csharp
using Akeldov.Math.Hexes;
using Akeldov.Math.Hexes.Geometry;
using Akeldov.Math.Spatial2D;

var geometry = new HexMapGeometry(
    new HexMapTopology(2, 2, Layout.EvenQ), new VectorXY(-10f, 20f), radius: 2f);
var heights = new SpatialFloatHexMap(geometry, new[] { 1f, 2f, 3f, 4f });

HexMapFile.Write("heights.hmap", heights);
```

Если передать тот же объект как `IHexMap<float>`, экспорт сохранит только топологию и значения,
без геометрии. Такую запись нужно читать через `ReadFloatHexMap`; пространственную запись
из примера — через `ReadSpatialFloatHexMap`. Это правило выбора перегрузки действует и для
`BinaryWriter.Write`.

## Бинарный формат

Запись начинается с сигнатуры `HMAP` и версии формата `1`, независимой от версии пакета.
Значения следуют за заголовком построчно: сначала изменяется X. Булевы значения занимают один
байт на ячейку, целые и вещественные — четыре байта в порядке little-endian. Вещественные
значения сохраняют битовое представление. Пространственные записи содержат координаты начала
и радиус перед значениями. Формат не использует сжатие или контрольную сумму.

Побайтовое описание формата приведено в разделе
[Сохранение и загрузка гексагональных карт](../../../how-to-guides/maps-and-topology/save-and-load-hex-maps.md).
Чтение и проверка данных описаны в разделе [Импорт](import.md), типы карт — в разделе [Карты](../maps.md).
