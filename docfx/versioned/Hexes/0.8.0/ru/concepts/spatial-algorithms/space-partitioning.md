# Разбиение пространства

Akeldov.Math.Hexes переносит взвешенную модель Вороного из Spatial2D на конечную карту гексов.
Каждый гекс целиком назначается одному сайту по мировому положению своего центра. Результат удобно
использовать для территорий, зон влияния и распределения ячеек между опорными точками.

## Дискретное разбиение по центрам

Исходные точки предоставляет <xref:Akeldov.Math.Hexes.Geometry.HexCenterMap>. Для каждого индекса
она вычисляет центр гекса из <xref:Akeldov.Math.Hexes.Geometry.HexMapGeometry>: топологии, начала
координат и радиуса.

Алгоритм сравнивает только эти центры. Он не разрезает гексы линией Вороного и не возвращает
векторные полигоны. Если непрерывная граница проходит через ячейку, вся ячейка всё равно получает
сайт, ближайший к её центру по взвешенной метрике.

Из этого следуют два важных свойства:

- одинаковые топологии с разным началом или радиусом могут получить разные назначения;
- сайт может находиться за пределами геометрии карты и всё равно получить ближайшие гексы.

## Взвешенные сайты

`Site` из пространства имён `Akeldov.Math.Spatial2D.Partitioning.Voronoi` содержит мировую
позицию `Position` и неотрицательный вес `Weight`. Для обычного конечного положительного веса
алгоритм сравнивает:

```text
weightedDistance² = distance(center, site.Position)² / site.Weight²
```

Больший вес уменьшает взвешенное расстояние и расширяет область влияния сайта. Вес не является
добавочной ценой: он масштабирует расстояние до позиции.

Нулевой и бесконечный веса имеют специальные значения:

| Вес | Поведение |
|---|---|
| Конечный и положительный | Участвует в обычном сравнении взвешенных расстояний |
| `0` | Получает только центр, совпадающий с позицией сайта в пределах геометрической точности |
| `float.PositiveInfinity` | Для несовпадающих точек имеет приоритет над конечными весами; среди бесконечных сайтов выбирается ближайший |

Список сайтов не может быть пустым, и хотя бы один сайт должен иметь ненулевой вес. Позиции
должны быть конечными, а веса — неотрицательными и не `NaN`. Вычисленные координаты центров
гексов также должны оставаться конечными.

## Карты разбиения и идентификаторы

`centers.ToVoronoiHexPartitionMap(sites)` возвращает `VoronoiHexPartitionMap`, унаследованную от
`HexPartitionMap<VoronoiHexPartitionCell>` и `IntHexMap`. Индексатор возвращает идентификатор ячейки:

```csharp
int cellId = partition[index];
VoronoiHexPartitionCell cell = partition.Cells[cellId];
```

Частичные перегрузки называются `ToPartialVoronoiHexPartitionMap`. Их результат наследует
`PartialHexPartitionMap<VoronoiHexPartitionCell>` и `HexMap<int?>`; исключённые гексы изначально
содержат `null`. Логическая маска выбирает участвующие гексы. Nullable-маска регионов объединяет
участие и метки: `null` исключает гекс, а любое целое число обозначает регион. При маске регионов
подходят только сайты того же региона; участвующий гекс без подходящего сайта вызывает
`InvalidOperationException`.

`Cells` — структурный результат только для чтения. `VoronoiHexPartitionCell` предоставляет
`Id`, `SiteIndex`, `Site`, `Center` и индексы `HexIndexes` только для чтения. Исходные идентификаторы
равны `SiteIndex` и индексируют `Cells`. `EmptyCellPolicy.LeaveAsIs` сохраняет пустые ячейки,
`Exclude` удаляет их и уплотняет идентификаторы в порядке исходных сайтов, а `ThrowException`
отклоняет пустую ячейку. После уплотнения `SiteIndex` уже не индекс исходного списка сайтов.

Публичные точки входа — расширения `HexCenterMap`; `VoronoiHexPartitioner` является internal.
`HexCenterMap` изначально вычисляет значения из геометрии и теперь наследует изменяемую
`HexMap<PointXY>`. Разбиение использует сохранённые центры; их изменение не меняет геометрию.

## Несвязные компоненты

Маски и веса могут разделить ячейку на несколько компонент связности по шести соседям.
`ExclavePolicy.LeaveAsIs` сохраняет их. `ReassignToClosestCell` оставляет компоненту с гексом,
ближайшим к сайту ячейки, и распространяется от оставленных компонент одновременно по слоям.
Переназначаемый гекс выбирает соседнюю растущую ячейку по невзвешенному евклидову расстоянию
до её сайта; равенство разрешается в пользу более раннего исходного сайта. Исключённые гексы
и границы регионов сохраняются.

Компонента, недостижимая от оставленных, становится новой ячейкой после исходных ячеек.
Её сайт — гекс компоненты, ближайший к исходному сайту, с исходным весом; при равенстве
используется построчный порядок. Политика пустых ячеек применяется после перераспределения.

## Изменяемые назначения и общие фасады

Индексаторы разбиения изменяемые. Запись меняет только карту идентификаторов, без перестройки
`Cells`, их `HexIndexes` и исходной маски участия. Сохранённые группы описывают первоначальный
результат алгоритма; после редактирования поддерживайте собственные группы отдельно.

Неявное преобразование в `SpatialHexMap<int>` или `SpatialHexMap<int?>` создаёт новый фасад
с той же геометрией и общим массивом назначений за O(1). Запись через любой фасад видна через
другой. `ToMutableHexMap()` возвращает новую независимую карту назначений во владении вызывающего.
`ToMutableParticipationMask()` копирует исходную маску частичного разбиения.

Примеры, маски и переход с 0.7.0 описаны в руководстве
[«Разбиение карты по ближайшим сайтам»](../../how-to-guides/geometry-and-polyhexes/partition-a-map-by-nearest-sites.md).
