# Создание карты влияния

В этом учебнике вы создадите карту влияния: непрерывное числовое поле, значение которого
определяется несколькими точечными источниками. Такие поля подходят для карт опасности,
стоимости перемещения, привлекательности целей и других пространственных оценок.

Итогом будет PNG-файл, в котором малые значения показаны холодными цветами, а большие —
тёплыми.

## Что вы сделаете

Последовательно вы:

1. зададите положения, веса и значения источников;
2. соберёте из них поле;
3. выберете способ интерполяции;
4. ограничите набор источников для каждой точки;
5. зададите геометрию растра;
6. сохраните тепловую карту в PNG.

Каждый шаг продолжает код предыдущего. В конце учебника приведён полный `Program.cs`.

## Создание проекта

Установите .NET SDK 6 или новее, затем выполните:

```powershell
dotnet new console --name Spatial2D.InfluenceMap
Set-Location Spatial2D.InfluenceMap
dotnet add package Akeldov.Math.Spatial2D --version 1.1.0
```

Создайте пустой `Program.cs` и переходите к разделу
[«Источники влияния»](influence-sources.md).
