# Процедурное разбиение пространства

В этом учебнике вы сгенерируете равномерно распределённые центры и разделите с их помощью
прямоугольную карту на взвешенные области Вороного. Затем вы сместите центры к центроидам областей
и экспортируете результат в SVG.

Разбиение будет дискретным: Spatial2D распределяет расположенные элементы карты между центрами.
Чем выше разрешение сетки, тем точнее она приближает непрерывные границы Вороного.

## Что вы сделаете

Последовательно вы:

1. сгенерируете воспроизводимый набор точек Пуассона;
2. превратите точки в центры Вороного;
3. распределите регулярную сетку элементов карты;
4. усилите влияние некоторых центров с помощью весов;
5. примените релаксацию по центроидам;
6. отрисуете полученные области и центры.

Каждая страница продолжает одно консольное приложение. На последней странице приведён полный код.

## Создание проекта

Установите .NET SDK 6 или новее, затем выполните:

```powershell
dotnet new console --name Spatial2D.Partitioning
Set-Location Spatial2D.Partitioning
dotnet add package Akeldov.Math.Spatial2D --version 1.1.0
```

Создайте пустой `Program.cs` и переходите к разделу
[«Генерация точек Пуассона»](generating-poisson-points.md).
