# Загрузить изображение PNG или BMP

Используйте <xref:Akeldov.Math.Spatial2D.Imaging.RasterImageLoader>, чтобы прочитать файл
изображения или доступный для чтения поток в новый изменяемый `Raster<TColor>`, принадлежащий
вызывающему коду. Выбирайте метод, соответствующий формату пикселей: загрузка PNG не преобразует
типы цветов или глубину каналов.

## Выбор типа пикселя

| Метод | Поддерживаемый вход | Тип ячейки результата |
| --- | --- | --- |
| `LoadGray8FromPng` | 8-битный grayscale PNG без альфа-канала | `Gray8BitColor` |
| `LoadGray16FromPng` | 16-битный grayscale PNG без альфа-канала | `Gray16BitColor` |
| `LoadRgba8FromPng` | PNG с 8 битами на каждый канал RGBA | `RGBA8BitColor` |
| `LoadRgba16FromPng` | PNG с 16 битами на каждый канал RGBA | `RGBA16BitColor` |
| `LoadGray8FromBmp` | Несжатый индексированный 8-битный BMP с палитрой оттенков серого | `Gray8BitColor` |
| `LoadRgba8FromBmp` | Несжатый индексированный 8-битный BMP с любой палитрой или 32-битный BGRA BMP | `RGBA8BitColor` |

Загрузка PNG поддерживает все пять фильтров строк и чересстрочную развёртку Adam7. Значения
каналов и альфа сохраняются без преобразования цветового пространства. Другие форматы цветов
и глубины каналов PNG не поддерживаются.

Загрузка BMP поддерживает информационные заголовки Windows, выравнивание строк и изображения
с порядком строк снизу вверх и сверху вниз. Индексы палитры преобразуются в цвета:
индексированный RGBA-результат непрозрачен, а загрузка grayscale требует палитру оттенков серого.
В 32-битном BGRA четвёртый байт сохраняется как альфа, что соответствует `SaveAsBmp`.
Другие глубины пикселей BMP, способы сжатия и заголовки OS/2 не поддерживаются.

## Загрузка из файла или потока

```csharp
using System.IO;
using Akeldov.Math.Spatial2D.Imaging;
using Akeldov.Math.Spatial2D.Rasterization;

Raster<Gray16BitColor> heightmap = RasterImageLoader.LoadGray16FromPng("heightmap.png");
Raster<Gray8BitColor> mask = RasterImageLoader.LoadGray8FromBmp("mask.bmp");

using Stream input = File.OpenRead("preview.png");
Raster<RGBA8BitColor> preview = RasterImageLoader.LoadRgba8FromPng(input);
preview.SaveAsPng("preview-copy.png");
```

У каждого метода есть перегрузки для пути к файлу и потока. Чтение начинается с текущей позиции,
не требует перемотки и оставляет поток вызывающего кода открытым. Чтение PNG заканчивается
после блока `IEND`; чтение BMP потребляет размер файла, объявленный в заголовке.

## Координаты и ошибки

В возвращённом растре Y растёт от нижней строки изображения, как и в методах экспорта.
Растр содержит разрешение и значения пикселей без мировых границ `RasterGeometry`.
Храните пространственные метаданные отдельно, если изображение представляет поле в мировых
координатах.

Некорректные, усечённые или слишком большие данные изображения вызывают `InvalidDataException`;
неподдерживаемые форматы — `NotSupportedException`. Путь или поток со значением null вызывает
`ArgumentNullException`, а недоступный для чтения поток — `ArgumentException`.

О типах цветов и экспорте читайте в разделе [Изображения](../../concepts/imaging.md),
о создании изображения из геометрии — в разделе [Растеризация](index.md).
