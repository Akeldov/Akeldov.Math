# Создать B-сплайн

Используйте <xref:Akeldov.Math.Spatial2D.Curves.BSpline>, чтобы построить конечный направленный
полиномиальный сплайн из степени, управляющих точек и неубывающего вектора узлов. Полученная
кривая реализует <xref:Akeldov.Math.Spatial2D.Curves.IContourPath>, поэтому по ней можно двигаться,
на неё можно проецировать точки и использовать её как часть составного контура.

## Задать управляющие точки и узлы

Количество узлов должно быть равно количеству управляющих точек плюс степень плюс один. В этом
закреплённом кубическом примере каждый конец области повторяется `degree + 1` раз, поэтому кривая
начинается в первой управляющей точке и заканчивается в последней:

```csharp
using Akeldov.Math.Spatial2D;
using Akeldov.Math.Spatial2D.Curves;

PointXY[] controlPoints =
{
    new PointXY(0f, 0f),
    new PointXY(1f, 3f),
    new PointXY(3f, -1f),
    new PointXY(4f, 2f)
};

float[] knots = { 0f, 0f, 0f, 0f, 1f, 1f, 1f, 1f };

var curve = new BSpline(
    degree: 3,
    controlPoints: controlPoints,
    knots: knots);

PointXY middle = curve.GetPointAt(0.5f);
```

Незакреплённый вектор узлов тоже допустим. Его активная область равна
`[knots[degree], knots[controlPoints.Count]]`; в этом случае `StartPoint` и `EndPoint` могут не
совпадать с первой и последней управляющими точками.

Узлы должны быть конечными и неубывающими, а активная область должна иметь положительную ширину.
Кратность внутреннего узла не может превышать степень, поскольку путь должен оставаться
непрерывным. Кратность концевых и внеобластных узлов не может превышать `degree + 1`.

## Выбрать систему координат

Используйте член, координата которого соответствует операции:

| Член | Входная область | Значение |
|---|---|---|
| `GetPointAt(t)` | `[0, 1]` | Линейно отображает нормализованное значение на активную область узлов. |
| `GetPointAtKnot(knot)` | `[KnotStart, KnotEnd]` | Вычисляет сплайн в исходных единицах вектора узлов. |
| `GetPoint(curveCoordinate)` | `[0, Length]` | Двигается от `StartPoint` на приближённое расстояние в мировых единицах. |

Нормализованный параметр и параметр узла обычно не пропорциональны длине дуги. Используйте
`GetPoint` для движения или размещения по расстоянию вдоль кривой.

## Настроить качество аппроксимации

`GetPointAt` и `GetPointAtKnot` вычисляют полиномиальный сплайн напрямую по алгоритму де Бура.
`Length`, `GetPoint`, `Distance`, `Project`, `ProjectWithParameter`, `CountRightwardCrossings` и
`Flatten` используют кэшированную аппроксимацию ломаной.

Необязательный аргумент `segmentsPerKnotSpan` задаёт количество равных подразделений параметра в
каждом непустом узловом интервале. Значение по умолчанию — `64`. Увеличивайте его для резких
изгибов или сильно различающихся интервалов; он управляет разрешением, но не задаёт геометрическую
границу ошибки:

```csharp
var detailed = new BSpline(
    degree: 3,
    controlPoints: controlPoints,
    knots: knots,
    segmentsPerKnotSpan: 128);

ParameterizedCurveProjection projection =
    detailed.ProjectWithParameter(new PointXY(2f, 1f));

float distance = projection.Distance;
float distanceFromStart = projection.CurveCoordinate;
```

`Flatten` возвращает новый изменяемый список направленных отрезков, принадлежащий вызывающему
коду. `ControlPoints` и `Knots` являются представлениями только для чтения над состоянием,
скопированным при создании, поэтому последующие изменения входных массивов не меняют кривую.

Чтобы влиять на форму рациональными весами, [создайте NURBS-кривую](create-a-nurbs-curve.md).
Общие контракты описаны на странице [«Кривые»](../../concepts/geometry-model/curves.md), а
[построение замкнутого контура](build-a-closed-contour.md) показывает использование сплайна как
части границы.
