# Построить замкнутый контур

Используйте `CompositeContour`, чтобы превратить упорядоченные вершины или цепочку путей контура
в одну замкнутую границу. После этого контур позволяет проверять охват, измерять расстояние,
строить проекции и находить пересечения с лучом.

## Создать многоугольник по вершинам

Передайте не менее трёх вершин в порядке обхода границы. Конструктор соединит соседние точки
параметризованными отрезками и автоматически замкнёт последнюю точку на первую:

```csharp
using System.Collections.Generic;
using Akeldov.Math.Spatial2D;
using Akeldov.Math.Spatial2D.Contours;
using Akeldov.Math.Spatial2D.Curves;

var contour = new CompositeContour(
    new PointXY(0f, 0f),
    new PointXY(6f, 0f),
    new PointXY(6f, 4f),
    new PointXY(0f, 4f));

float perimeter = contour.Length;                    // 20
bool isInside = contour.Encloses(new PointXY(2f, 1f)); // true
IReadOnlyList<IContourPath> edges = contour.Curves;    // 4 отрезка
```

Не повторяйте первую вершину, если только входной формат уже не содержит замыкающую точку.
Поддерживаются оба варианта, причём явно повторённая первая вершина не создаёт дополнительный
отрезок нулевой длины.

Конструктор сохраняет переданный порядок и не сортирует вершины. Перечислите их в порядке обхода
границы — по часовой стрелке или против неё. Ориентация не меняет обычную проверку охвата, но
задаёт направление обхода, если эти пути затем используются в параметризованном контуре.

## Объединить отрезки, дуги и кривые Безье

Для смешанной границы создайте `IReadOnlyList<IContourPath>`. `EndPoint` каждого пути должен
совпадать со `StartPoint` следующего, а последний путь должен соединяться с первым. В этом
примере диаметр соединяется с полуокружностью, направленной против часовой стрелки:

```csharp
using System;

IContourPath[] paths =
{
    new ParameterizedSegment(
        startPoint: new PointXY(-2f, 0f),
        endPoint: new PointXY(2f, 0f)),
    new ParameterizedArc(
        center: new PointXY(0f, 0f),
        radius: 2f,
        startAngle: 0f,
        endAngle: MathF.PI,
        angularDirection: AngularDirection.Counterclockwise)
};

var curvedContour = new CompositeContour(paths);
```

Углы дуги задаются в радианах. `ParameterizedSegment`, `ParameterizedArc`,
`ParameterizedSegmentChain` и пути Безье реализуют `IContourPath`. Этот интерфейс объединяет
контракт конечного направленного пути с запросами подсчёта пересечений направленного вправо луча
и пересечения с произвольным лучом, необходимыми составным контурам.

Конструктор проверяет стыки со стандартным геометрическим допуском, но не меняет порядок путей и
не перемещает концы для устранения небольших разрывов. Создавайте пути в порядке обхода и по
возможности используйте одинаковые значения точек в общих концах.

## Добавить координату обхода границы

Используйте `ParameterizedCompositeContour`, если нужно двигаться по контуру или сохранять
координату границы при проекции. Координата равна расстоянию в мировых единицах от `StartPoint`
первого пути:

```csharp
var directedContour = new ParameterizedCompositeContour(contour.Curves);

PointXY start = directedContour.GetPoint(0f);       // (0, 0)
PointXY position = directedContour.GetPoint(5f);    // (5, 0)
PointXY closedEnd =
    directedContour.GetPoint(directedContour.Length); // (0, 0)

ParameterizedCurveProjection projection =
    directedContour.ProjectWithParameter(new PointXY(7f, 1f));

PointXY closest = projection.ProjectedPoint;        // (6, 1)
float coordinate = projection.CurveCoordinate;      // 7
float distance = projection.Distance;               // 1
```

Допустимый диапазон координаты — `[0, Length]`. Его концы обозначают одну геометрическую точку,
поскольку контур замкнут.

## Не передавать некорректные данные

Для построения по точкам нужны конечные координаты, не менее трёх вершин границы и различные
соседние вершины. Контур на основе путей требует хотя бы один путь `IContourPath`, не равный
`null`; длина каждого пути должна быть конечной и неотрицательной, а суммарная длина —
оставаться конечной.

Конструктор проверяет непрерывность и замкнутость, но не отбрасывает все самопересечения и не
определяет предполагаемый порядок неупорядоченного набора точек. Если нужна простая граница с
однозначной внутренней областью, избегайте пересекающихся рёбер.

Контур копирует ссылки на переданные пути в закрытое хранилище. `Curves` предоставляет
структурное представление этой копии только для чтения, поэтому через публичный контракт нельзя
добавлять, удалять или переставлять пути.

## Скруглить углы многоугольника

Вызовите `FilletCorners`, чтобы заменить углы между соседними параметризованными отрезками
касательными дугами. Радиус измеряется в мировых единицах:

```csharp
CompositeContour rounded = contour.FilletCorners(radius: 0.5f);
```

Метод возвращает новый контур и не изменяет исходный. Углы с участием других типов путей
сохраняются. Используйте конечный положительный радиус, подходящий для длин соседних отрезков.
