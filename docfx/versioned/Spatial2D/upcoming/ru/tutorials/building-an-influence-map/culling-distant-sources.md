# Выбор локальных источников

Без индекса семплер получает все источники поля. Для небольшого массива это допустимо, но
локальная карта обычно должна зависеть от геометрического окружения точки, а не от каждого
далёкого источника.

Создайте <xref:Akeldov.Math.Spatial2D.Fields.DelaunayInfluenceSourceIndex`1> и передайте полю сам
индекс:

```csharp
var sampler = new BarycentricFloatSampler<FloatPointInfluenceSource>();
var sourceIndex =
    new DelaunayInfluenceSourceIndex<FloatPointInfluenceSource>(sources);
var field = new FloatPointInfluenceField(sampler, sourceIndex);
```

`DelaunayInfluenceSourceIndex` копирует источники в неизменяемый снимок и заранее строит
триангуляцию Делоне по их положениям. Для точки внутри триангулированной области он возвращает
вершины содержащего её треугольника. Снаружи выпуклой оболочки используются ближайшая вершина
или ребро оболочки. Поэтому барицентрический семплер обычно работает с одним, двумя или тремя
локальными источниками.

Создавайте индекс один раз и переиспользуйте вместе с полем: построение триангуляции дороже одной
выборки. Ему требуется хотя бы три источника с различными положениями. Если все положения лежат
на одной прямой, `DelaunayInfluenceSourceIndex` автоматически применяет запасную стратегию и
оставляет не более двух источников.

Индексированный выбор меняет не только стоимость вычисления, но и смысл поля. Если требуется
учитывать вклад каждого источника, передайте полю `sources` напрямую вместо создания индекса.
Для этой карты локальные треугольные области подходят, поэтому сохраните вариант с
`DelaunayInfluenceSourceIndex`.
