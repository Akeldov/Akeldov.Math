# Пространственные алгоритмы

Spatial2D предоставляет алгоритмы генерации равномерно разреженных наборов точек, назначения
расположенных объектов взвешенным сайтам и выбора локальных окрестностей источников влияния. Эти
алгоритмы дополняют [геометрическую модель](geometry-model/index.md): они работают с положениями
и полями, а не вводят новые примитивы фигур.

## Выбор алгоритма

Начните с результата, который нужен приложению:

| Цель | Алгоритм | Основной тип |
|---|---|---|
| Сгенерировать нерегулярные точки с управляемым расстоянием | Выборка дисков Пуассона | <xref:Akeldov.Math.Spatial2D.Sampling.Point.PoissonDisk.PoissonDiskPointSampler> |
| Назначить существующие расположенные объекты взвешенным центрам | Взвешенное разбиение элементов Вороного | <xref:Akeldov.Math.Spatial2D.Partitioning.Voronoi.VoronoiItemPartitioner`1> |
| Выбрать локальный треугольник или элемент оболочки около точки запроса | Индексирование источников по Делоне | <xref:Akeldov.Math.Spatial2D.Fields.DelaunayInfluenceSourceIndex`1> |
| Исключить точечные источники, скрытые за границами полуплоскостей более близких источников | Индексирование полуплоскостями | <xref:Akeldov.Math.Spatial2D.Fields.HalfPlaneInfluenceSourceIndex`1> |

Выборка дисков Пуассона создаёт новые положения. Разбиение Вороного группирует объекты, у
которых положения уже есть. Индексы источников влияния владеют неизменяемым снимком и возвращают
временное локальное подмножество для одной выборки поля, не перераспределяя этот снимок навсегда.

## Генерация точек дисками Пуассона

Выборка дисков Пуассона заполняет прямоугольное поле, соблюдая минимальное расстояние между
принятыми точками. Результат нерегулярен, но в нём нет тесных скоплений и больших случайных
пробелов, характерных для независимой равномерной случайной выборки.

```csharp
using System;
using System.Collections.Generic;
using Akeldov.Math.Spatial2D;
using Akeldov.Math.Spatial2D.Sampling.Point.PoissonDisk;

var sampler = new PoissonDiskPointSampler(
    random: new Random(12345),
    maxAttempts: 30);

var fieldSize = new VectorXY(100f, 60f);

List<PoissonDiskPointSample> samples = sampler.Sample(
    fieldSize,
    minimalDistance: 6f);

PointXY firstPoint = samples[0].Point;
float firstSpacing = samples[0].MinimalDistance;
```

Точки лежат в полуоткрытом прямоугольнике от `(0, 0)` включительно до `fieldSize` исключительно.
У выборщика нет параметра начала координат; сместите возвращённые точки, если целевой мировой
прямоугольник начинается в другом месте.

`maxAttempts` ограничивает количество кандидатов, проверяемых около каждой активной точки.
Большее значение может дать более плотный результат ценой дополнительных вычислений. Передача
`Random` с фиксированным зерном делает запуски повторяемыми в контролируемом окружении, что
удобно для тестов и процедурной генерации.

Возвращаемый `List<PoissonDiskPointSample>` является новым изменяемым списком и принадлежит
вызывающему коду.

## Изменение расстояния с помощью поля

Минимальное расстояние может поступать из любого `IFloatField`. Это позволяет создавать области
с разной плотностью в одном наборе точек:

```csharp
using Akeldov.Math.Spatial2D.Fields;

var spacingField = new FloatPointInfluenceField(
    new BarycentricFloatSampler<FloatPointInfluenceSource>(),
    new[]
    {
        new FloatPointInfluenceSource(
            weight: 1f,
            position: new PointXY(0f, 0f),
            value: 4f),
        new FloatPointInfluenceSource(
            weight: 1f,
            position: new PointXY(fieldSize.X, 0f),
            value: 12f)
    });

List<PoissonDiskPointSample> adaptiveSamples =
    sampler.Sample(fieldSize, spacingField);
```

`Min`, `Max` поля и каждое выбранное значение должны быть конечными и положительными. Каждая
принятая точка хранит расстояние, запрошенное в её положении. Для любой пары фактическое
расстояние не меньше большего из двух сохранённых минимальных расстояний, поэтому точку с
большим интервалом нельзя окружить соседями с малым интервалом.

## Разбиение элементов по взвешенным сайтам Вороного

`VoronoiItemPartitioner<TItem>` назначает каждый элемент `IHasPosition2D` одному настроенному
`Site`. Это семантический разделитель элементов: он возвращает группы объектов, а не
многоугольную геометрию ячеек Вороного.

`PointXY` сам реализует `IHasPosition2D`, поэтому точки можно разбивать напрямую:

```csharp
using System.Collections.Generic;
using Akeldov.Math.Spatial2D.Partitioning.Voronoi;

var sites = new[]
{
    new Site(new PointXY(0f, 0f), weight: 1f),
    new Site(new PointXY(10f, 0f), weight: 2f)
};

var items = new[]
{
    new PointXY(1f, 0f),
    new PointXY(4f, 0f),
    new PointXY(8f, 0f)
};

var partitioner = new VoronoiItemPartitioner<PointXY>(
    sites,
    EmptyCellPolicy.LeaveAsIs);

IReadOnlyList<VoronoiItemPartition<PointXY>> partitions =
    partitioner.Partition(items);
```

В стороне от точного положения сайта конечные сайты с положительным весом сравниваются по
квадрату расстояния, делённому на квадрат веса. Поэтому увеличение веса позволяет сайту
получать элементы с большего расстояния.

Особые случаи веса заданы явно:

- сайт в положении элемента побеждает до сравнения взвешенных расстояний;
- сайт с нулевым весом получает только совпадающие с ним элементы;
- при наличии сайтов с положительным бесконечным весом для несовпадающего элемента выбирается
  ближайший из них;
- как минимум один настроенный сайт должен иметь положительный вес.

Положения сайтов и элементов должны быть конечными. Коллекция элементов должна быть непустой и
не содержать `null`.

## Обработка пустых разделов Вороного

Некоторые сайты могут не получить элементов.
<xref:Akeldov.Math.Spatial2D.Partitioning.Voronoi.EmptyCellPolicy> определяет обработку таких
случаев в конечном результате:

| Политика | Поведение |
|---|---|
| `ThrowException` | Завершает операцию ошибкой при наличии пустого раздела; используется по умолчанию. |
| `Exclude` | Удаляет пустые разделы из семантического результата. |
| `LeaveAsIs` | Сохраняет по одному разделу на настроенный сайт, включая пустые. |

Используйте `LeaveAsIs`, если индексы результата должны соответствовать индексам сайтов.
`Exclude` подходит, когда важны только заполненные группы. `ThrowException` нужен, когда каждый
последующий раздел обязан содержать хотя бы один элемент.

Возвращаемый список разделов доступен только для чтения, поскольку его размер и связь с сайтами
являются частью результата алгоритма. Коллекция `VoronoiItemPartition<TItem>.Items` также
представляет скопированную структуру только для чтения.

## Релаксация сайтов к центроидам элементов

Трёхаргументный конструктор разделителя принимает `relaxationIterations`. После каждого
назначения заполненный сайт перемещается в центроид своих элементов с сохранением веса, затем
элементы разбиваются снова. Пустые сайты сохраняют прежние положения.

```csharp
var relaxedPartitioner = new VoronoiItemPartitioner<PointXY>(
    sites,
    relaxationIterations: 2,
    emptyCellPolicy: EmptyCellPolicy.LeaveAsIs);

IReadOnlyList<VoronoiItemPartition<PointXY>> relaxed =
    relaxedPartitioner.Partition(items);
```

Релаксация балансирует сайты вокруг переданных дискретных элементов и не вычисляет центроиды
непрерывных многоугольных ячеек. Поэтому сайты в конечных разделах могут отличаться от исходных
настроенных положений.


## Выбор локальных окрестностей поля

Индексы источников влияния решают другую задачу, чем разбиение Вороного: они владеют неизменяемым
снимком точечных источников и для каждой точки запроса возвращают источники, которые должна
учитывать стратегия выборки.

`DelaunayInfluenceSourceIndex<TPointSource>` требует как минимум три источника с уникальными
положениями. Для неколлинеарных входов он строит триангуляцию. Запрос внутри оболочки получает
три источника содержащего треугольника, а запрос снаружи — ближайшую вершину оболочки или два
конца ближайшего ребра. Для коллинеарных входов используется явная запасная стратегия.

`HalfPlaneInfluenceSourceIndex<TPointSource>` принимает один или несколько источников. Он
обрабатывает их от ближних к дальним и удаляет скрытые за перпендикулярными границами
полуплоскостей, созданными уже выбранными источниками.

Оба индекса предоставляют сохранённый снимок через доступное только для чтения свойство
`Sources`. Каждый результат выбора является новым изменяемым непустым списком и принадлежит
вызывающему коду. Передавайте полю влияния сам индекс; полный конвейер описан на странице
[«Поля»](fields.md).

## Объединение алгоритмов в рабочий процесс

Алгоритмы могут передавать результаты друг другу, не образуя жёсткой связи:

1. Сгенерируйте кандидаты сайтов выборкой дисков Пуассона.
2. Назначьте выбранным положениям веса или значения поля.
3. Распределите существующие объекты между сайтами взвешенным разбиением Вороного.
4. Выполните выборку или растеризацию результата для визуализации и дальнейшей обработки.

Используйте одну мировую единицу для всех линейных величин. Применяйте фиксированное зерно
случайности, если процедурный конвейер должен быть воспроизводимым, и явно выбирайте поведение
пустых ячеек, когда следующие шаги зависят от размера результата.
