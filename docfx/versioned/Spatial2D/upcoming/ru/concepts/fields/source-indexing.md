# Индексирование источников

Индекс источников влияния выбирает локальное окружение источников до того, как сэмплер поля
объединит их значения. Индексирование может уменьшить число источников, рассматриваемых в точке,
но оно также является частью математического определения поля: изменение выбранного окружения
может изменить результат сэмплирования.

Встроенные индексы работают с точечными источниками влияния и реализуют
<xref:Akeldov.Math.Spatial2D.Fields.IInfluenceSourceIndex`1>.

## Контракт индекса

У индекса две обязанности:

1. Хранить структурно неизменяемый снимок источников в `Sources`.
2. Возвращать релевантное непустое подмножество из `SelectSources(point)`.

`SelectSources` возвращает новый изменяемый список, принадлежащий вызывающему коду. Каждый
элемент списка должен входить в сохранённый снимок. Если основной геометрический алгоритм не
нашёл кандидатов, именно индекс обязан выбрать запасной источник.

Передавайте индекс непосредственно в конструктор поля влияния. Поле предоставляет тот же снимок
через `InfluenceSources` и при каждом сэмплировании запрашивает у индекса локальную выборку:

```text
Снимок источников, принадлежащий индексу
        |
        v
SelectSources(point) -> локальное непустое окружение
        |
        v
Сэмплер -> ограниченный результат поля
```

## Выбор индекса

| Индекс | Требования | Выборка в точке | Типичное применение |
|---|---|---|---|
| <xref:Akeldov.Math.Spatial2D.Fields.HalfPlaneInfluenceSourceIndex`1> | Один или несколько точечных источников | Источники, которые остаются видимыми после добавления ближайшими источниками перпендикулярных границ полуплоскостей | Локальное ближайшее или взвешенное сэмплирование, где близкие источники должны скрывать расположенные за ними |
| <xref:Akeldov.Math.Spatial2D.Fields.DelaunayInfluenceSourceIndex`1> | Не менее трёх точечных источников с различными позициями | Три вершины содержащего треугольника Делоне; вне триангуляции — одна вершина или две вершины ближайшего ребра выпуклой оболочки | Кусочно-линейная барицентрическая интерполяция рассеянных значений |

`HalfPlaneInfluenceSourceIndex` обходит источники от ближайшего к самому дальнему. Каждый принятый
источник добавляет прямую, перпендикулярную направлению от точки запроса к источнику; более
дальние источники с противоположной стороны исключаются. Источник, практически совпадающий с
точкой запроса, принимается, но не создаёт неустойчивую границу.

`DelaunayInfluenceSourceIndex` один раз строит триангуляцию в конструкторе. Внутри триангуляции он
передаёт сэмплеру один треугольник. Вне выпуклой оболочки он передаёт ближайший элемент оболочки:
один источник для вершины или два для ребра. Если все позиции коллинеарны, индекс использует
линейное окружение из одного или двух источников вместо построения треугольников.

## Создание и повторное использование

Следующее поле использует по одному треугольнику Делоне для барицентрической интерполяции:

```csharp
using Akeldov.Math.Spatial2D;
using Akeldov.Math.Spatial2D.Fields;

var sources = new[]
{
    new FloatPointInfluenceSource(1f, new PointXY(0f, 0f), 0f),
    new FloatPointInfluenceSource(1f, new PointXY(10f, 0f), 100f),
    new FloatPointInfluenceSource(1f, new PointXY(0f, 10f), 50f),
    new FloatPointInfluenceSource(1f, new PointXY(10f, 10f), 75f)
};

var sourceIndex =
    new DelaunayInfluenceSourceIndex<FloatPointInfluenceSource>(sources);
var sampler = new BarycentricFloatSampler<FloatPointInfluenceSource>();
var field = new FloatPointInfluenceField(sampler, sourceIndex);

float value = field.Sample(new PointXY(4f, 3f));
```

Создавайте индекс один раз и используйте его для повторных запросов. Оба встроенных индекса
копируют ссылки на источники в собственный снимок, поэтому добавление или удаление элементов в
исходной коллекции не меняет индекс. Если набор источников или их позиции изменились, создайте
новый индекс; в частности, триангуляция Делоне не обновляется инкрементально.

## Границы и вырожденные случаи

- Для корректного индекса выборка всегда непуста, в том числе далеко за пределами области
  источников.
- Индекс Делоне выбирает три источника внутри триангуляции, один или два вне её выпуклой оболочки
  и не более двух для коллинеарного набора.
- Совпадающие или практически совпадающие позиции не принимаются индексом Делоне, поскольку они
  не задают различные вершины триангуляции.
- Оба встроенных индекса требуют конечных координат точки запроса и позиций источников.
- Встроенные индексы принимают только точечные источники. Для источников на кривых пока нужно
  непосредственное сэмплирование или пользовательский индекс.

Не добавляйте индекс только как прозрачную оптимизацию. Например, обратно-взвешенное по
расстоянию сэмплирование всех источников создаёт глобальное смешивание, а тот же сэмплер с
индексом смешивает только выбранное окружение. Используйте прямое сэмплирование, когда каждый
источник должен влиять на каждый запрос или когда набор источников и так мал.
