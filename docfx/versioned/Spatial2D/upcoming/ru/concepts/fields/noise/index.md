# Шум

Шумовое поле вычисляет значение по мировым координатам и начальному значению генератора.
Значения плавно меняются от точки к точке, поэтому такое поле подходит для карт высот
и температуры. При одинаковых настройках значение в каждой точке воспроизводится независимо
от порядка запросов.

[PerlinNoiseField](perlin-noise-field.md) объединяет несколько слоёв шума Перлина. Можно
запрашивать значения в отдельных точках или передать поле алгоритму, который принимает
<xref:Akeldov.Math.Spatial2D.Fields.IFloatField>.
