# PerlinNoiseField

<xref:Akeldov.Math.Spatial2D.Fields.PerlinNoiseField> вычисляет нормированное значение шума
в точке с мировыми координатами. Нижняя граница `Min` равна 0, верхняя `Max` — 1.

## Высота рельефа в точке

```csharp
using Akeldov.Math.Spatial2D;
using Akeldov.Math.Spatial2D.Fields;

IFloatField terrain = new PerlinNoiseField(seed: 42, scale: 32f);
float height = terrain.Sample(new PointXY(12.5f, -4f));
```

Здесь `height` — доля диапазона высот. Для рельефа высотой от 100 до 250 метров используйте
формулу `100f + 150f * height`. Чтобы высоты на границах соседних участков карты совпадали,
запрашивайте одно поле в общей системе мировых координат.

## Настройка шума

| Параметр | Действие |
|---|---|
| `seed` | Задаёт воспроизводимое расположение градиентов шума. |
| `scale` | Задаёт размер базовых деталей в мировых единицах. Чем больше значение, тем крупнее формы рельефа. |
| `octaves` | Количество слоёв шума. По умолчанию 4. |
| `persistence` | Множитель амплитуды каждого следующего слоя. По умолчанию 0,5. При нуле вклад даёт только первый слой. |
| `lacunarity` | Множитель частоты каждого следующего слоя. По умолчанию 2, то есть с каждым слоем частота удваивается. |
| `offset` | Смещение, которое прибавляется к координатам запроса. По умолчанию это нулевой вектор. |

Для получения целой сетки используйте `RasterGeometry.CreatePerlinNoise`. С теми же параметрами
он вычисляет тот же шум в центрах ячеек. См. [SpatialFloatRaster](../../rasterization/spatial-rasters/spatial-float-raster.md).
