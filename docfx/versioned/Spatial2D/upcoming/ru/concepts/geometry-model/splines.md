# B-сплайны и NURBS

Spatial2D предоставляет два конечных направленных сплайновых пути:

| Тип | Данные формы | Когда использовать |
|---|---|---|
| <xref:Akeldov.Math.Spatial2D.Curves.BSpline> | Степень, управляющие точки и неубывающий вектор узлов | Достаточно полиномиального B-сплайна. |
| <xref:Akeldov.Math.Spatial2D.Curves.Nurbs> | Те же данные и один положительный вес для каждой управляющей точки | Рациональные веса должны притягивать кривую к выбранным точкам или нужна точная рациональная форма, например дуга окружности. |

Оба типа реализуют <xref:Akeldov.Math.Spatial2D.Curves.IContourPath>. Они предоставляют
упорядоченные концы, обход по длине, проекцию точки, измерение расстояния и запрос пересечений,
необходимый составным контурам.

## Создание B-сплайна

Количество узлов должно быть равно количеству управляющих точек плюс степень плюс один. В этом
закреплённом кубическом примере каждый конец области повторяется `degree + 1` раз, поэтому кривая
начинается в первой управляющей точке и заканчивается в последней:

```csharp
using Akeldov.Math.Spatial2D;
using Akeldov.Math.Spatial2D.Curves;

var curve = new BSpline(
    degree: 3,
    controlPoints: new[]
    {
        new PointXY(0f, 0f),
        new PointXY(1f, 3f),
        new PointXY(3f, -1f),
        new PointXY(4f, 2f)
    },
    knots: new[] { 0f, 0f, 0f, 0f, 1f, 1f, 1f, 1f });

PointXY middle = curve.GetPointAt(0.5f);
```

Незакреплённый вектор узлов тоже допустим. Активная область узлов равна
`[knots[degree], knots[controlPoints.Count]]`; в этом случае `StartPoint` и `EndPoint` могут не
совпадать с первой и последней управляющими точками.

Узлы должны быть конечными и неубывающими, а активная область должна иметь положительную ширину.
Кратность внутреннего узла не может превышать степень, поскольку путь должен оставаться
непрерывным. Кратность концевых и внеобластных узлов не может превышать `degree + 1`.

## Добавление рациональных весов

`Nurbs` добавляет по одному конечному строго положительному весу для каждой управляющей точки.
Равные веса дают ту же форму, что и `BSpline`; изменение веса меняет силу влияния соответствующей
управляющей точки:

```csharp
float diagonalWeight = MathF.Sqrt(0.5f);

var quarterCircle = new Nurbs(
    degree: 2,
    controlPoints: new[]
    {
        new PointXY(1f, 0f),
        new PointXY(1f, 1f),
        new PointXY(0f, 1f)
    },
    weights: new[] { 1f, diagonalWeight, 1f },
    knots: new[] { 0f, 0f, 0f, 1f, 1f, 1f });

PointXY pointOnArc = quarterCircle.GetPointAt(0.5f);
```

При вычислении через `GetPointAt` или `GetPointAtKnot` эта рациональная квадратичная кривая точно
представляет четверть окружности.

## Выбор нужного параметра

Сплайновые пути предоставляют три связанные системы координат:

| Член | Входная область | Значение |
|---|---|---|
| `GetPointAt(t)` | `[0, 1]` | Линейно отображает нормализованное значение на активную область узлов и вычисляет сплайн. |
| `GetPointAtKnot(knot)` | `[KnotStart, KnotEnd]` | Вычисляет сплайн в исходных единицах вектора узлов. |
| `GetPoint(curveCoordinate)` | `[0, Length]` | Двигается от `StartPoint` на приближённое расстояние в мировых единицах координат. |

Нормализованный параметр и параметр узла обычно не пропорциональны длине дуги. Используйте
`GetPoint`, когда движение или размещение должно основываться на расстоянии вдоль кривой.

## Управление качеством аппроксимации

`GetPointAt` и `GetPointAtKnot` вычисляют полиномиальный или рациональный сплайн напрямую по
алгоритму де Бура. `Length`, `GetPoint`, `Distance`, `Project`, `ProjectWithParameter`,
`CountRightwardCrossings` и `Flatten` используют кэшированную аппроксимацию ломаной.

Аргумент конструктора `segmentsPerKnotSpan` задаёт количество равных подразделений параметра в
каждом непустом узловом интервале. Значение по умолчанию — `64`. Увеличивайте его для резких
изгибов, сильно различающихся интервалов или экстремальных весов NURBS. Этот аргумент управляет
разрешением, но не задаёт геометрическую границу ошибки.

```csharp
var detailed = new BSpline(
    degree: 3,
    controlPoints: controlPoints,
    knots: knots,
    segmentsPerKnotSpan: 128);

ParameterizedCurveProjection projection =
    detailed.ProjectWithParameter(new PointXY(2f, 1f));

float distance = projection.Distance;
float distanceFromStart = projection.CurveCoordinate;
```

`Flatten` возвращает новый изменяемый список направленных отрезков, принадлежащий вызывающему
коду. `ControlPoints`, `Knots` и `Nurbs.Weights` являются представлениями только для чтения над
состоянием, скопированным при создании, поэтому последующие изменения входных коллекций не меняют
кривую.

части границы, [постройте замкнутый контур](../../how-to-guides/curves-and-contours/build-a-closed-contour.md).
