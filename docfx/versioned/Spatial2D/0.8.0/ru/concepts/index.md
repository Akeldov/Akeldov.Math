# Концепции

Концептуальная документация объясняет основные идеи и проектные решения Spatial2D: системы
координат, модели геометрии, поля, семплеры, разбиения, растеризацию, единицы измерения и
правила владения данными. Этот раздел помогает понять представление задачи в библиотеке и связи
между её API.
