# Концепции

Концептуальная документация объясняет основные идеи и проектные решения Spatial2D: системы
координат, модели геометрии, поля, семплеры, разбиения, растеризацию, изображения, единицы измерения и
правила владения данными. Этот раздел помогает понять представление задачи в библиотеке и связи
между её API.

[«Растеризация»](rasterization.md) описывает сэмплирование геометрии и полей на сетке, а
[«Изображения»](imaging.md) — типы цвета, альфа-композицию и экспорт изображений.
