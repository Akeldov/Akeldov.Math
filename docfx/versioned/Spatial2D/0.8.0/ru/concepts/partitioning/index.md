# Разбиения

Алгоритмы разбиения распределяют существующие объекты по группам с учётом их положения.
Они определяют принадлежность элементов, а не создают новые точки.

## Доступные алгоритмы

- [Разбиение элементов Вороного](voronoi.md) — назначение объектов взвешенным сайтам,
  обработка пустых разделов и релаксация сайтов к центроидам назначенных элементов.

Результат такого разбиения содержит группы объектов, а не многоугольные границы ячеек Вороного.
Если сначала нужно сгенерировать положения сайтов, используйте [семплеры](../samplers/index.md).
