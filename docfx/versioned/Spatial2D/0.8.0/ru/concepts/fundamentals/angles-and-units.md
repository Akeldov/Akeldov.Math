# Углы и единицы измерения

Akeldov.Math.Spatial2D по умолчанию выражает углы в радианах. Линейные величины используют
выбранную вызывающим кодом мировую единицу координат, а индексы и разрешения растров являются
целочисленными количествами. Явное различение этих ролей предотвращает малозаметные ошибки на
границах API.

## Радианы по умолчанию

Параметр или свойство угла без суффикса единицы измеряется в радианах. Числовые свойства,
возвращающие градусы, имеют явный суффикс `Deg`, например `Arc.StartAngleDeg` и
`Arc.EndAngleDeg`; имена других членов для градусов явно содержат слово `Degrees`.
То же правило действует для параметров: параметр с суффиксом `Deg` уже принимает градусы,
поэтому перед вызовом его значение не нужно преобразовывать в радианы.

Распространённые углы:

| Направление или оборот | Радианы | Градусы |
|---|---:|---:|
| Положительная ось X | `0` | `0°` |
| Положительная ось Y | `MathF.PI / 2f` | `90°` |
| Отрицательная ось X | `MathF.PI` | `180°` |
| Отрицательная ось Y | `3f * MathF.PI / 2f` | `270°` |
| Полный оборот | `2f * MathF.PI` | `360°` |

Например, луч под углом 45 градусов создаётся с углом в радианах:

```csharp
using System;
using Akeldov.Math.Spatial2D;
using Akeldov.Math.Spatial2D.Curves;

var ray = new Ray(
    origin: new PointXY(0f, 0f),
    angle: MathF.PI / 4f);

float angleRad = ray.Angle; // PI / 4, приблизительно 0,7854 рад
```

Имя `Angle` не означает градусы. Передавайте `45f` только тогда, когда действительно требуется
угол 45 радиан.

## Декартово направление поворота

Нулевой угол направлен вдоль положительной оси X. Положительные углы задают поворот против
часовой стрелки к положительной оси Y, отрицательные — по часовой стрелке:

```csharp
VectorXY counterclockwise = VectorXY.BasisX.Rotate(MathF.PI / 2f);
// Приблизительно (0, 1)

VectorXY clockwise = VectorXY.BasisX.Rotate(-MathF.PI / 2f);
// Приблизительно (0, -1)
```

То же соглашение действует для повёрнутых точек, лучей, дуг и ориентированных прямоугольников.
Для ориентированного прямоугольника `Rotation` задаёт поворот его локальной оси X против часовой
стрелки относительно мировой оси X.

## Знаковые углы

<xref:Akeldov.Math.Spatial2D.VectorXY> вычисляет кратчайший знаковый угол между направлениями
методом `VectorXY.Angle(from, to)`. Результат следует диапазону `Atan2` от `-PI` до `PI`:

```csharp
float toUp = VectorXY.Angle(VectorXY.BasisX, VectorXY.BasisY);
// PI / 2

float toDown = VectorXY.Angle(VectorXY.BasisX, new VectorXY(0f, -1f));
// -PI / 2
```

Положительный результат означает, что кратчайший поворот от `from` к `to` направлен против
часовой стрелки. Отрицательный результат означает поворот по часовой стрелке.

## Нормализация только по требованию контракта

Углы, отличающиеся на полный оборот, задают одно направление. Если требуется каноническое
представление, используйте `NormalizeAngleRad`:

```csharp
using Akeldov.Math.Spatial2D.Curves;

float normalized = (-MathF.PI / 2f).NormalizeAngleRad();
// 3 * PI / 2, приблизительно 4,7124
```

Метод возвращает угол в полуоткрытом диапазоне `[0, 2 * PI)` и отклоняет `NaN` и бесконечность.

Не предполагайте, что каждое свойство угла нормализовано. Например,
<xref:Akeldov.Math.Spatial2D.Curves.Ray> сохраняет конечный угол, переданный конструктору, поэтому
эквивалентные направления могут иметь значения, отличающиеся на один или несколько полных
оборотов.

Круговые дуги ведут себя иначе: <xref:Akeldov.Math.Spatial2D.Curves.Arc> нормализует
`StartAngle` и `EndAngle` в диапазон `[0, 2 * PI)`. Отдельно сохраняется информация о том, были ли
входные углы разделены ненулевым целым числом полных оборотов, поэтому различаются геометрически
разные случаи:

```csharp
var center = new PointXY(0f, 0f);

var zeroLength = new Arc(center, 2f, 0f, 0f);
var fullCircle = new Arc(center, 2f, 0f, 2f * MathF.PI);

bool emptySweep = zeroLength.IsFullCircle; // false
bool fullSweep = fullCircle.IsFullCircle;  // true
```

Обе дуги возвращают нулевые нормализованные начальный и конечный углы, поэтому `IsFullCircle`
содержит существенную информацию о развёртке.

## Преобразование градусов на границах системы

Если внешние данные используют градусы, преобразуйте их до вызова API с параметром в радианах:

```csharp
float degrees = 30f;
float radians = degrees * MathF.PI / 180f;

VectorXY direction = VectorXY.BasisX.Rotate(radians);
```

При необходимости преобразуйте результат в радианах обратно в градусы для отображения или
обмена данными:

```csharp
float displayedDegrees = radians * 180f / MathF.PI; // 30
```

Некоторые круговые типы предоставляют вспомогательные свойства `StartAngleDeg` и
`EndAngleDeg`. Эти свойства возвращают градусы; соответствующие свойства без суффикса и
параметры конструкторов остаются в радианах.

Выполняйте преобразование один раз на границе системы и храните внутренние вычисления в
радианах. Повторные преобразования добавляют ошибку округления и затрудняют обнаружение ошибок
в единицах.

## Только конечные углы

Публичные API поворота и геометрии, принимающие угол, требуют конечное значение. `NaN`,
положительная и отрицательная бесконечность приводят к `ArgumentOutOfRangeException`:

```csharp
var point = new PointXY(2f, 0f);
var pivot = new PointXY(1f, 0f);

PointXY rotated = point.Rotate(pivot, MathF.PI / 2f);
// Приблизительно (1, 1)
```

Обычно углы не нужно заранее нормализовать. Тригонометрический поворот периодичен, а API,
которым нужен канонический диапазон, выполняют нормализацию согласно своему документированному
контракту.

## Согласованные мировые единицы

Spatial2D не предписывает метры, пиксели или другую физическую единицу. Следующие значения
измеряются в мировой единице координат, выбранной вызывающим кодом:

- координаты `PointXY`, смещения и размеры `VectorXY`;
- расстояния, длины, радиусы, ширины и высоты;
- начала растров, их размеры в мировом пространстве и размеры ячеек;
- геометрические допуски, передаваемые операциям на основе расстояния.

В одном вычислении эти величины должны использовать одинаковый масштаб. Если координаты точек
заданы в метрах, то радиус окружности, смещение и допуск расстояния для этих точек также должны
быть заданы в метрах.

```csharp
using Akeldov.Math.Spatial2D.Contours;

// Все линейные величины в этом примере интерпретируются как метры.
var centerMeters = new PointXY(12f, 5f);
float radiusMeters = 2f;
var circle = new Circle(centerMeters, radiusMeters);

float distanceMeters = circle.Distance(new PointXY(15f, 5f)); // 1
```

Углы не зависят от выбранной мировой единицы. Масштабирование модели изменяет длины, но не
направления и углы поворота.

## Количества и нормализованные значения

Значения `VectorXYInt`, используемые как индексы или разрешения растров, являются количествами,
а не длинами в мировом пространстве.
<xref:Akeldov.Math.Spatial2D.Rasterization.RasterGeometry> связывает эти количества с мировыми
единицами:

```csharp
using Akeldov.Math.Spatial2D.Rasterization;

var geometry = new RasterGeometry(
    origin: new PointXY(0f, 0f),
    size: new VectorXY(10f, 6f),        // Мировые единицы
    resolution: new VectorXYInt(5, 3)); // Количество ячеек

VectorXY cellSize = geometry.CellSize; // (2, 2) мировых единицы на ячейку
```

Значения, явно описанные как нормализованные, безразмерны и обычно относятся к диапазону вроде
`[0, 1]`. Не смешивайте нормализованную координату напрямую с длиной в мировом пространстве,
сначала примените масштаб и начало координат, определённые соответствующим API.

Роли координат и соглашения об индексах растров описаны на странице
[«Система координат»](coordinate-system/index.md).
