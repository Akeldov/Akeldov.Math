# Система координат

Akeldov.Math.Spatial2D использует двумерную декартову систему координат. Положения, направления,
размеры и дискретные значения содержат компоненты `X` и `Y`, а их типы сохраняют смысл этих
компонентов.

## Декартовы оси

Положительная ось X направлена вправо, а положительная ось Y — вверх:

```csharp
using Akeldov.Math.Spatial2D;

VectorXY right = VectorXY.BasisX; // (1, 0)
VectorXY up = VectorXY.BasisY;    // (0, 1)
```

Направление поворота и соглашения об измерениях описаны на странице
[«Углы и единицы измерения»](../angles-and-units.md).

## Выбор значения по смыслу

| Тип | Смысл | Типичные применения |
|---|---|---|
| <xref:Akeldov.Math.Spatial2D.PointXY> | Положение в непрерывном пространстве | Концы, центры, точки выборки и пересечения |
| <xref:Akeldov.Math.Spatial2D.VectorXY> | Вектор с плавающей точкой | Направления, смещения, размеры и преобразования |
| <xref:Akeldov.Math.Spatial2D.VectorXYInt> | Целочисленный вектор | Целочисленные направления, смещения, размеры, индексы и разрешения |

`PointXY` представляет положение, а `VectorXY` и `VectorXYInt` — векторы. `VectorXYInt` не
ограничен индексами: некоторые API также используют его как двумерный индекс или разрешение.

`PointXY` и `VectorXY` используют компоненты `float`. Преобразование в `VectorXYInt` может
отбросить дробную часть, поэтому доступные правила преобразования описаны на странице
[«Векторы»](vectors.md).

Растровые API явно связывают непрерывные и дискретные значения. Например,
<xref:Akeldov.Math.Spatial2D.Rasterization.RasterGeometry> объединяет начало `PointXY` и размер
`VectorXY` с разрешением `VectorXYInt`. Адресация растров и связь с мировым пространством
описаны на странице [«Дискретные индексы»](discrete-indices.md).
