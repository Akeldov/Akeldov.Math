# Akeldov.Math.Spatial2D

Akeldov.Math.Spatial2D предоставляет практические средства для двумерной геометрии: векторную
математику, кривые, контуры, регионы, растеризацию, пространственную выборку, разбиение и поля
влияния.

## Установка

```powershell
dotnet add package Akeldov.Math.Spatial2D
```

## Основные возможности

- точки и векторы;
- линейные, круговые кривые и кривые Безье;
- контуры и регионы;
- растеризация и работа с изображениями;
- выборка дисков Пуассона и взвешенное разбиение Вороного;
- поля влияния от точек и кривых.
