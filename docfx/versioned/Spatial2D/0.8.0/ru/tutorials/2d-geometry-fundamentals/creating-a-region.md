# Создание региона

В этой части руководства вы превратите замкнутый контур из предыдущего шага в заполненный регион
и используете его для классификации точек. Продолжайте работу в проекте
`Spatial2D.Fundamentals`, где в `Program.cs` уже определены `contour` и функция `ToWorld`.

## Заполнение контура

Добавьте пространство имён регионов в начало `Program.cs`:

```csharp
using Akeldov.Math.Spatial2D.Regions;
```

Создайте <xref:Akeldov.Math.Spatial2D.Regions.ContourBasedRegion> из контура:

```csharp
var region = new ContourBasedRegion(
    new IContour[] { contour },
    FillRule.EvenOdd);

Console.WriteLine($"Количество контуров: {region.Contours.Count}");
Console.WriteLine($"Правило заполнения:  {region.FillRule}");
```

Результат:

```text
Количество контуров: 1
Правило заполнения:  EvenOdd
```

Контур описывает только замкнутую границу. `ContourBasedRegion` интерпретирует эту границу как
заполненную двумерную область. Правило чётности заполняет точки, охваченные нечётным количеством
контуров; при одном контуре оно заполняет его внутреннюю область.

Свойство `Contours` предоставляет структурное представление только для чтения. Регион копирует
ссылки на контуры в собственное хранилище, поэтому вызывающий код не может изменить количество
или порядок границ через публичный контракт.

## Классификация точек

Выберите одну точку внутри фигуры и одну слева от неё. Задайте их в той же локальной системе
координат, что и исходную границу, а затем преобразуйте в мировое пространство:

```csharp
PointXY insidePoint = ToWorld(new PointXY(3f, 2.5f));
PointXY outsidePoint = ToWorld(new PointXY(0f, 2.5f));

bool containsInsidePoint = region.Contains(insidePoint);
bool containsOutsidePoint = region.Contains(outsidePoint);

Console.WriteLine($"Внутренняя точка: {containsInsidePoint}");
Console.WriteLine($"Внешняя точка:    {containsOutsidePoint}");
```

Программа выведет:

```text
Внутренняя точка: True
Внешняя точка:    False
```

Преобразование проверяемых точек той же функцией `ToWorld` сохраняет их положение относительно
масштабированной, повёрнутой и перемещённой границы. Если передать в `Contains` локальные точки
без преобразования, будут проверены другие позиции в мировом пространстве.

`Contains` возвращает `true` для точек внутри заполненной области и на её границе.

## Измерение знакового расстояния

Используйте `SignedDistance`, когда алгоритму нужны и расстояние до границы, и сторона, на которой
находится точка:

```csharp
float insideDistance = region.SignedDistance(insidePoint);
float outsideDistance = region.SignedDistance(outsidePoint);
float boundaryDistance = region.Distance(worldEdge.StartPoint);

Console.WriteLine($"Расстояние внутри отрицательно: {insideDistance < 0f}");
Console.WriteLine($"Расстояние снаружи положительно: {outsideDistance > 0f}");
Console.WriteLine($"Расстояние до точки границы:     {boundaryDistance}");
```

Результат:

```text
Расстояние внутри отрицательно: True
Расстояние снаружи положительно: True
Расстояние до точки границы:     0
```

Знаковое расстояние отрицательно внутри региона, равно нулю на границе и положительно снаружи.
Метод `Distance` всегда возвращает неотрицательное расстояние до ближайшей границы и подходит,
когда различие между внутренней и внешней сторонами неважно.

Теперь у вас есть заполненная фигура, которую можно использовать в алгоритмах проверки
принадлежности, измерения расстояния и растеризации. Переходите к разделу
[«Проверка точек и пересечений»](checking-points-and-intersections.md).
