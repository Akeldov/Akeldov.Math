# Основы двумерной геометрии

Создайте небольшое консольное приложение .NET для построения и преобразования двумерной
геометрии с Akeldov.Math.Spatial2D 0.8.0. В результате вы получите контур из прямых и кривой
Безье, заполненный регион и запросы принадлежности, расстояния, проекции и пересечений с лучом.

Установите .NET SDK 6 или новее. Шаги продолжают друг друга, поэтому проходите их по порядку:

1. [Создайте проект](creating-a-project.md) и установите пакет.
2. [Поработайте с точками и векторами](points-and-vectors.md).
3. [Создайте и преобразуйте кривые](curves-and-transformations.md).
4. [Постройте замкнутый контур](building-a-closed-contour.md).
5. [Создайте заполненный регион](creating-a-region.md).
6. [Проверьте точки и пересечения](checking-points-and-intersections.md).

Начните с раздела [«Создание проекта»](creating-a-project.md).
