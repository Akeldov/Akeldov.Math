# Источники влияния

Источник влияния связывает положение в двумерном пространстве с числовым значением. На этом
шаге вы разместите пять источников внутри прямоугольной области размером 100 на 70 мировых
единиц.

Добавьте в `Program.cs` пространства имён и массив источников:

```csharp
using Akeldov.Math.Spatial2D;
using Akeldov.Math.Spatial2D.Fields;

var sources = new[]
{
    new FloatPointInfluenceSource(1f, new PointXY(12f, 12f), 0f),
    new FloatPointInfluenceSource(1f, new PointXY(88f, 14f), 25f),
    new FloatPointInfluenceSource(1f, new PointXY(18f, 58f), 50f),
    new FloatPointInfluenceSource(1f, new PointXY(83f, 54f), 75f),
    new FloatPointInfluenceSource(1f, new PointXY(50f, 34f), 100f)
};
```

Конструктор <xref:Akeldov.Math.Spatial2D.Fields.FloatPointInfluenceSource> принимает три
аргумента:

- `weight` — неотрицательный вес источника, используемый некоторыми стратегиями выборки;
- `position` — положение источника в мировых координатах;
- `value` — значение поля непосредственно в источнике.

Все источники в примере имеют одинаковый вес, поэтому на результат влияют только их положения и
значения. Позже можно увеличить вес отдельного источника, чтобы усилить его вклад при
интерполяции по обратному расстоянию.

Положения должны быть конечными, вес не может быть отрицательным или `NaN`, а значение не может
быть `NaN`. Для геометрических стратегий вроде триангуляции также используйте различные
положения источников.

Массив готов. Переходите к разделу [«Построение поля»](building-the-field.md).
