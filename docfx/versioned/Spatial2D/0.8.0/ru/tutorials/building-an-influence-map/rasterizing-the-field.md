# Растеризация поля

Поле непрерывно: его можно вычислить в любой конечной точке. Чтобы получить изображение, задайте
прямоугольную область и разрешение дискретной сетки.

Добавьте пространства имён:

```csharp
using Akeldov.Math.Spatial2D.Imaging;
using Akeldov.Math.Spatial2D.Rasterization;
```

Затем создайте геометрию растра и тепловую карту:

```csharp
var grid = new RasterGeometry(
    origin: new PointXY(0f, 0f),
    size: new VectorXY(100f, 70f),
    resolution: new VectorXYInt(800, 560));

SpatialRaster<RGBA16BitColor> raster = field.RasterizeHeatMap(grid);
```

<xref:Akeldov.Math.Spatial2D.Rasterization.RasterGeometry> отделяет мировую геометрию от
разрешения изображения:

- `origin` задаёт нижний угол области в мировых координатах;
- `size` задаёт ширину и высоту области в мировых единицах;
- `resolution` задаёт количество столбцов и строк растра.

В примере соотношение сторон мира и изображения одинаково, поэтому масштаб по осям не
искажается. Каждый элемент растра получает значение поля в центре соответствующей ячейки.

`RasterizeHeatMap` преобразует диапазон `field.Min`–`field.Max` в 16-битные RGBA-цвета. Это
удобный вариант для диагностики и визуализации поля. Если приложению нужна другая палитра или
числовой растр, используйте собственный rasterizer.

Растр находится в памяти. На последнем шаге вы сохраните его в файл:
[«Экспорт изображения»](exporting-the-image.md).
