# Отсечение удалённых источников

Без отсечения стратегия получает все источники поля. Для небольшого массива это допустимо, но
локальная карта обычно должна зависеть от геометрического окружения точки, а не от каждого
далёкого источника.

Создайте <xref:Akeldov.Math.Spatial2D.Fields.DelaunayCuller`1> и передайте его полю третьим
аргументом:

```csharp
var sampler = new BarycentricFloatSampler<FloatPointInfluenceSource>();
var culler = new DelaunayCuller<FloatPointInfluenceSource>(sources);
var field = new FloatPointInfluenceField(sampler, sources, culler);
```

`DelaunayCuller` заранее строит триангуляцию Делоне по положениям источников. Для точки внутри
триангулированной области он возвращает вершины содержащего её треугольника. Снаружи выпуклой
оболочки используются ближайшая вершина или ребро оболочки. Поэтому барицентрический sampler
обычно работает с одним, двумя или тремя локальными источниками.

Создавайте culler один раз и переиспользуйте вместе с полем: построение триангуляции дороже одной
выборки. Ему требуется хотя бы три источника с различными положениями. Если все положения лежат
на одной прямой, `DelaunayCuller` автоматически применяет запасную стратегию и оставляет не более
двух источников.

Отсечение меняет не только стоимость вычисления, но и смысл поля. Если требуется учитывать вклад
каждого источника, оставьте конструктор поля без culler. Для этой карты локальные треугольные
области подходят, поэтому сохраните вариант с `DelaunayCuller`.
