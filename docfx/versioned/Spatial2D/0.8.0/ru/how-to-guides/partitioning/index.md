# Разбиение

Средства разбиения Spatial2D распределяют существующие расположенные объекты по смысловым группам.
Текущий API использует взвешенные сайты Вороного: каждый элемент назначается сайту, победившему
при сравнении взвешенных расстояний.

Этот раздел подходит, когда у вас уже есть объекты с положениями — ячейки карты, поселения,
ресурсы или точки выборки — и требуется определить владельца каждого объекта. Результат содержит
группы элементов, а не многоугольные границы Вороного.

## Выбор рабочего процесса

| Задача | Подход |
| --- | --- |
| Назначить каждый элемент ближайшему сайту | Задайте всем сайтам одинаковый положительный вес. |
| Позволить выбранным сайтам захватывать более широкую область | Увеличьте веса этих сайтов. |
| Сохранить результат для каждого настроенного сайта | Используйте `EmptyCellPolicy.LeaveAsIs`. |
| Вернуть только заполненные разделы | Используйте `EmptyCellPolicy.Exclude`. |
| Отклонить результат с пустым разделом | Используйте `EmptyCellPolicy.ThrowException`. |
| Переместить сайты к центрам назначенных элементов | Задайте положительное значение `relaxationIterations`. |
| Получить равномерно разреженные начальные положения сайтов | Перед разбиением используйте выборку дисков Пуассона. |

## Основные типы

| Тип | Назначение |
| --- | --- |
| <xref:Akeldov.Math.Spatial2D.IHasPosition2D> | Предоставляет положение разбиваемого элемента. |
| <xref:Akeldov.Math.Spatial2D.Partitioning.Voronoi.Site> | Задаёт положение сайта и его неотрицательный вес. |
| <xref:Akeldov.Math.Spatial2D.Partitioning.Voronoi.VoronoiItemPartitioner`1> | Распределяет элементы между сайтами и при необходимости выполняет релаксацию по центроидам. |
| <xref:Akeldov.Math.Spatial2D.Partitioning.Voronoi.VoronoiItemPartition`1> | Содержит один результирующий сайт и назначенные ему элементы. |
| <xref:Akeldov.Math.Spatial2D.Partitioning.Voronoi.EmptyCellPolicy> | Определяет обработку пустых разделов в конечном результате. |

## Базовая схема

Определите тип элемента с реализацией `IHasPosition2D`, настройте хотя бы один взвешенный сайт и
передайте partitioner непустую коллекцию элементов:

```csharp
var sites = new[]
{
    new Site(new PointXY(20f, 30f), weight: 1f),
    new Site(new PointXY(80f, 30f), weight: 1.5f)
};

var partitioner = new VoronoiItemPartitioner<MapCell>(
    sites,
    EmptyCellPolicy.LeaveAsIs);

IReadOnlyList<VoronoiItemPartition<MapCell>> partitions =
    partitioner.Partition(items);
```

Возвращаемый список является семантическим результатом: его порядок и размер описывают модель
разбиения. Каждый раздел также предоставляет назначенные элементы как скопированное структурное
представление только для чтения.

## Важное различие

`VoronoiItemPartitioner<TItem>` не обрезает плоскость и не возвращает кривые, контуры или вершины
многоугольников. Он сравнивает положение каждого переданного элемента с настроенными сайтами и
помещает элемент в одну группу. Чтобы приблизить видимые области, создайте регулярную сетку
расположенных элементов и отрисуйте каждый из них цветом результирующего раздела.
