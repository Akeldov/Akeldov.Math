# Растеризация

Растеризация вычисляет непрерывную геометрию или поле на прямоугольной сетке. Используйте её для
создания изображений, масок, тепловых карт, знаковых полей расстояний и других регулярных
пространственных буферов.

Spatial2D отделяет мировую геометрию от разрешения изображения:
<xref:Akeldov.Math.Spatial2D.Rasterization.RasterGeometry> задаёт границы и количество ячеек, а
rasterizer или selector преобразует каждое вычисленное значение в нужный тип ячейки.

## Выбор рабочего процесса

| Задача | Подход |
| --- | --- |
| Нарисовать кривую как линию | Растеризуйте беззнаковое расстояние с шириной, расстоянием затухания и цветами линии и фона. |
| Создать маску внутри/снаружи | Растеризуйте контур или регион и преобразуйте знаковые расстояния не больше нуля во внутреннее значение. |
| Сохранить расстояния для дальнейшей обработки | Растеризуйте в `SpatialRaster<float>` или преобразуйте расстояния в 16-битные оттенки серого. |
| Визуализировать поле влияния | Вычислите поле на сетке и преобразуйте диапазон значений в цвета. |
| Объединить несколько геометрических объектов | Добавьте слои на основе расстояния в `GeometryScene<TColor>`. |
| Экспортировать изображение | Используйте поддерживаемый серый или RGBA-тип ячейки, затем вызовите `SaveAsPng` или `SaveAsBmp`. |

## Основные типы

| Тип | Назначение |
| --- | --- |
| <xref:Akeldov.Math.Spatial2D.Rasterization.RasterGeometry> | Связывает ячейки растра с прямоугольной областью мировых координат. |
| <xref:Akeldov.Math.Spatial2D.Rasterization.Raster`1> | Хранит изменяемую непространственную прямоугольную сетку значений. |
| <xref:Akeldov.Math.Spatial2D.Rasterization.SpatialRaster`1> | Хранит изменяемые значения вместе с их мировой геометрией. |
| <xref:Akeldov.Math.Spatial2D.Rasterization.IRasterizer`2> | Создаёт растр из источника и разрешения. |
| <xref:Akeldov.Math.Spatial2D.Rasterization.ISpatialRasterizer`2> | Создаёт пространственный растр из источника и `RasterGeometry`. |
| <xref:Akeldov.Math.Spatial2D.Rasterization.GeometryScene`1> | Объединяет несколько растеризованных геометрических слоёв. |

## Базовая схема

Задайте мировые границы и разрешение, растеризуйте источник, затем экспортируйте полученный растр:

```csharp
var grid = new RasterGeometry(
    origin: new PointXY(-1f, -1f),
    size: new VectorXY(6f, 4f),
    resolution: new VectorXYInt(600, 400));

SpatialRaster<Gray8BitColor> mask = region.Rasterize(
    signedDistance => signedDistance <= 0f
        ? Gray8BitColor.White
        : Gray8BitColor.Black,
    grid);

mask.SaveAsPng("region-mask.png");
```

Источники вычисляются в центрах ячеек. `Origin` — нижний левый угол в мировых координатах,
`Size` измеряется в мировых единицах, а `Resolution` независимо задаёт число столбцов и строк.

## Выбор точности результата

- `Gray8BitColor` компактен и подходит для масок.
- `Gray16BitColor` лучше сохраняет точность скалярных значений и градиентов.
- `RGBA8BitColor` подходит для обычных цветных изображений с прозрачностью.
- `RGBA16BitColor` полезен для высокоточных градиентов и композиции.

Сохраняйте `SpatialRaster<T>`, пока следующим операциям требуется преобразовывать ячейки обратно
в мировые координаты. Растеризация возвращает новый изменяемый растр, принадлежащий вызывающему
коду.

Полный пример с регионом с отверстием, преобразованием знакового расстояния, 16-битным результатом
и экспортом PNG см. в руководстве
[«Растеризовать знаковое поле расстояний»](rasterize-a-signed-distance-field.md).
Общая модель описана в разделе [«Растеризация»](../../concepts/rasterization.md).
