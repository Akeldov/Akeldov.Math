# Выборка

Пространственная выборка создаёт положения для процедурных раскладок, размещения объектов,
тестовых данных и сайтов разбиения. Сейчас Spatial2D предоставляет выборку дисков Пуассона для
нерегулярных наборов точек с управляемым расстоянием между элементами.

## Выберите способ выборки

| Задача | Подход |
| --- | --- |
| Сохранить одно расстояние между всеми парами точек | Вызовите <xref:Akeldov.Math.Spatial2D.Sampling.Point.PoissonDisk.PoissonDiskPointSampler.Sample(Akeldov.Math.Spatial2D.VectorXY,System.Single)> с постоянным конечным положительным расстоянием. |
| Создать плотные и разреженные области в одном наборе | Передайте <xref:Akeldov.Math.Spatial2D.Fields.IFloatField>, конечные положительные значения которого задают локальный интервал. |
| Воспроизвести процедурную раскладку | Создайте выборщик с `Random`, имеющим фиксированное зерно, в контролируемой среде. |
| Получать новую раскладку при каждом запуске | Передайте принадлежащий приложению случайный источник с изменяющимся состоянием. |
| Проверить точки и их запрещённые интервалы | Растеризуйте результат с помощью <xref:Akeldov.Math.Spatial2D.Rasterization.PoissonDiskPointSampleCollectionRingsGray16BitRasterizer>. |

<xref:Akeldov.Math.Spatial2D.Sampling.Point.PoissonDisk.PoissonDiskPointSampler> создаёт точки в
полуоткрытом прямоугольнике от `(0, 0)` включительно до заданного размера исключительно. Если
целевой прямоугольник имеет другое начало, перенесите возвращённые положения.

Каждый <xref:Akeldov.Math.Spatial2D.Sampling.Point.PoissonDisk.PoissonDiskPointSample> хранит
положение и минимальное расстояние, запрошенное в этой точке. Возвращаемая коллекция является
новым изменяемым списком и принадлежит вызывающему коду.

## Выберите параметры

| Параметр | Компромисс |
| --- | --- |
| Размер поля | Задаёт конечные положительные ширину и высоту прямоугольника выборки в мировых единицах. |
| Минимальное расстояние | Большие значения создают меньше точек с большими интервалами. |
| `maxAttempts` | Большие значения могут плотнее заполнить пробелы, но увеличивают количество проверяемых кандидатов. |
| Случайный источник | Определяет конфигурацию точек и возможность её воспроизведения. |

При пространственно изменяемом интервале расстояние между любыми двумя принятыми точками не
меньше большего из двух сохранённых минимальных расстояний. `Min`, `Max` поля расстояний и все
вычисленные значения должны быть конечными и положительными.
