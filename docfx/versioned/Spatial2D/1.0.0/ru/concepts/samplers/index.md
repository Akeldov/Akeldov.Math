# Семплеры

Семплеры точек создают новые положения для процедурной генерации, тестовых данных и начальных
сайтов разбиения. Их параметры определяют область генерации и расстояния между точками.

## Доступные семплеры

- [Семплер Пуассона](poisson-disk.md) — нерегулярный набор точек с постоянным минимальным
  расстоянием или расстоянием, заданным полем.

Не путайте генерацию точек с сэмплированием [поля](../fields.md): поле вычисляет значение в уже
заданной точке, а семплер точек создаёт сам набор положений.
