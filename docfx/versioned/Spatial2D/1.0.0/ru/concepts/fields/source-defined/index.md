# Заданные источниками

У этих полей вы задаёте источники и семплер. При вызове `Sample(point)` точечный источник сообщает своё значение и расстояние до точки запроса. Источник на кривой использует проекцию точки на кривую. Семплер выбирает значение одного источника или объединяет значения нескольких.

| Поле | Источник | Результат | Пример |
|---|---|---|---|
| [FloatPointInfluenceField](float-point-influence-field.md) | Точка | `float` | Температура по показаниям датчиков |
| [IntPointInfluenceField](int-point-influence-field.md) | Точка | `int` | Идентификатор района по ближайшей метке |
| [BoolPointInfluenceField](bool-point-influence-field.md) | Точка | `bool` | Открыты ли ближайшие ворота |
| [FloatCurveInfluenceField](float-curve-influence-field.md) | Кривая | `float` | Высота дороги по расстоянию от её начала |

Способы объединения значений описаны в статье [«Стратегии сэмплирования»](../sampling-strategies.md). Для выбора локальной группы источников см. [«Индексирование источников»](../source-indexing.md).
