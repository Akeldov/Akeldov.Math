# Регионы

Регионы представляют заполненные двумерные области. Spatial2D напрямую предоставляет круговые
и прямоугольные регионы, а также умеет интерпретировать один или несколько замкнутых
[контуров](contours.md) как заполненную область. Регионы проверяют принадлежность точки и
измеряют беззнаковое или знаковое расстояние до границы.

Типы регионов находятся в пространстве имён <xref:Akeldov.Math.Spatial2D.Regions>.

## Регион и его граница

Контур описывает замкнутую одномерную границу. Регион описывает выбранную этой границей
двумерную площадь:

| Вопрос | Контур | Регион |
|---|---:|---:|
| Охватывает ли одна граница эту точку? | `Encloses(point)` | — |
| Принадлежит ли точка заполненной площади? | — | `Contains(point)` |
| Каково расстояние до границы? | `Distance(point)` | `Distance(point)` |
| Находится ли точка внутри или снаружи? | `SignedDistance(point)` | `SignedDistance(point)` |
| Могут ли несколько границ создавать отверстия? | Нет семантики заполнения | Да, через `ContourBasedRegion` |

Для одной простой фигуры охват контуром и принадлежность региону обычно выбирают одни и те же
точки. Различие становится существенным, когда несколько вложенных границ задают отверстия или
заполненные острова.

## Интерфейсы регионов

Spatial2D предоставляет два интерфейса регионов:

| Интерфейс | Возможности |
|---|---|
| <xref:Akeldov.Math.Spatial2D.Regions.IRegion> | Проверяет принадлежность заполненной площади с помощью `Contains` и предоставляет беззнаковое и знаковое расстояние до границы. |
| <xref:Akeldov.Math.Spatial2D.Regions.IContourBasedRegion> | Добавляет структурное представление задающих контуров только для чтения и правило их заполнения. |

`IRegion` расширяет <xref:Akeldov.Math.Spatial2D.ISignedPointDistanceProvider>, поэтому регионы
можно передавать API полей расстояний и растеризации без зависимости от конкретной формы.

## Выбор конкретного региона

Выбирайте наиболее прямое представление заполненной фигуры:

| Тип | Модель формы | Когда использовать |
|---|---|---|
| <xref:Akeldov.Math.Spatial2D.Regions.Disk> | Центр и неотрицательный радиус | Область имеет форму круга. |
| <xref:Akeldov.Math.Spatial2D.Regions.Rectangle> | Две противоположные вершины, нормализованные в границы по осям | Область является прямоугольником по мировым осям. |
| <xref:Akeldov.Math.Spatial2D.Regions.OrientedRectangle> | Центр, размер и угол поворота | Прямоугольник следует повёрнутой локальной системе координат. |
| <xref:Akeldov.Math.Spatial2D.Regions.ContourBasedRegion> | Один или несколько произвольных замкнутых контуров | Граница составная, содержит отверстия или вложенные заполненные области. |

`Disk`, `Rectangle` и `OrientedRectangle` — неизменяемые типы-значения. Они не требуют общего
списка контуров и предоставляют свойства конкретной формы: радиус, вершины, локальные оси и
размер.

## Создание стандартных регионов

Создайте регион непосредственно из параметров его формы:

```csharp
using System;
using Akeldov.Math.Spatial2D;
using Akeldov.Math.Spatial2D.Regions;

var disk = new Disk(
    center: new PointXY(0f, 0f),
    radius: 5f);

var rectangle = new Rectangle(
    cornerA: new PointXY(-4f, -2f),
    cornerB: new PointXY(4f, 2f));

var orientedRectangle = new OrientedRectangle(
    center: new PointXY(0f, 0f),
    size: new VectorXY(8f, 3f),
    rotation: MathF.PI / 6f);
```

`Rectangle` принимает противоположные вершины в любом порядке и предоставляет нормализованные
границы `Min` и `Max`. Для `OrientedRectangle` требуются положительные компоненты размера; его
угол поворота — это направленный против часовой стрелки угол локальной оси X в радианах.
Соглашение о повороте описано на странице
[«Углы и единицы измерения»](../fundamentals/angles-and-units.md).

## Проверка принадлежности и расстояние

`Contains` включает границу. `Distance` — неотрицательное расстояние до этой границы, в том
числе для точки внутри региона. `SignedDistance` дополнительно учитывает сторону границы:

- отрицательное значение соответствует точке внутри;
- ноль соответствует точке на границе;
- положительное значение соответствует точке снаружи.

```csharp
var sample = new PointXY(3f, 0f);

bool contained = disk.Contains(sample);             // true
float distance = disk.Distance(sample);             // 2
float signedDistance = disk.SignedDistance(sample); // -2

float outside = disk.SignedDistance(new PointXY(7f, 0f)); // 2
```

Используйте `Distance`, когда важна только близость к границе. `SignedDistance` подходит для
знаковых полей расстояний, эффектов внутри и снаружи и плавного затухания около границы. Его
необязательный параметр `geometryEpsilon` измеряется в мировых единицах координат и управляет
классификацией рядом с границей; точный контракт `Contains` при этом не изменяется.

## Создание региона из контуров

`ContourBasedRegion` применяет правило заполнения к одному или нескольким экземплярам
`IContour`. Одна произвольная граница становится заполненным регионом без специализированного
типа формы:

```csharp
using Akeldov.Math.Spatial2D.Contours;

var triangleBoundary = new CompositeContour(
    new PointXY(0f, 0f),
    new PointXY(6f, 0f),
    new PointXY(3f, 4f));

var triangle = new ContourBasedRegion(
    new IContour[] { triangleBoundary });

bool insideTriangle = triangle.Contains(new PointXY(3f, 2f));
```

Конструктор копирует ссылки на контуры в закрытое хранилище. `Contours` предоставляет
структурное представление этой копии только для чтения, поэтому порядок и количество контуров
региона нельзя изменить через публичный контракт.

Задающие контуры не должны пересекаться или касаться друг друга. Для отверстий и островов
используйте вложенные непересекающиеся границы, чтобы принадлежность и расстояние до границы
оставались однозначными.

## Отверстия и правило чётности

Сейчас Spatial2D поддерживает <xref:Akeldov.Math.Spatial2D.Regions.FillRule.EvenOdd>. Точка
находится внутри, если она охвачена нечётным числом контуров. Направление обхода контуров не
влияет на результат.

Поэтому две вложенные окружности создают круговой регион с круглым отверстием:

```csharp
var regionWithHole = new ContourBasedRegion(new IContour[]
{
    new Circle(center: new PointXY(0f, 0f), radius: 5f),
    new Circle(center: new PointXY(0f, 0f), radius: 2f)
});

bool inFilledArea = regionWithHole.Contains(new PointXY(3f, 0f)); // true
bool inHole = regionWithHole.Contains(new PointXY(1f, 0f));       // false

float holeDistance = regionWithHole.SignedDistance(
    new PointXY(1f, 0f)); // Положительное: отверстие находится вне заполненного региона
```

Третий контур внутри отверстия создаёт ещё один заполненный остров. Каждое пересечение границы
переключает принадлежность между заполненным и незаполненным пространством.

## Преобразование стандартных регионов в контуры

Используйте `ToContour`, когда алгоритму нужна граница `Disk`, `Rectangle` или
`OrientedRectangle`. `Rectangle` и `OrientedRectangle` также предоставляют `ToRegion`, который
оборачивает их границу в `ContourBasedRegion`, сохраняя ту же заполненную площадь.

```csharp
Circle diskBoundary = disk.ToContour();
RectangleContour rectangleBoundary = rectangle.ToContour();
ContourBasedRegion contourRegion = rectangle.ToRegion();
```

Общий `ContourBasedRegion` не преобразуется в один контур, поскольку его заполнение может
зависеть от нескольких границ.

## Использование регионов при выводе

Регионы подходят как источники для растеризации знакового расстояния и слоёв геометрической
сцены. Соглашение об отрицательном расстоянии внутри позволяет использовать один регион для
заливки, обводки, затухания и пороговых масок.
