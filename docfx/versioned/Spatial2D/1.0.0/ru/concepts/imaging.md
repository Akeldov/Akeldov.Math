# Изображения

Раздел Imaging описывает представление цветов в Spatial2D, их смешивание и экспорт цветового
растра в изображение. Типы цветов и расширения экспорта находятся в пространстве имён
<xref:Akeldov.Math.Spatial2D.Imaging>.

[Растеризация](rasterization.md) определяет, где сэмплировать геометрию или поле и какое значение
записать в каждую ячейку. Imaging предоставляет цветовые значения для этих ячеек и сохраняет
полученную сетку в PNG или BMP. Те же методы экспорта работают с растром, заполненным вручную.

## Цвета и точность

Четыре типа цвета — неизменяемые типы значений. Оттенок серого хранит одну интенсивность в
`Value`; RGBA хранит красный, зелёный, синий и альфа-канал в `R`, `G`, `B` и `A`.

| Тип цвета | Диапазон канала | Типичные задачи |
|---|---|---|
| <xref:Akeldov.Math.Spatial2D.Imaging.Gray8BitColor> | `byte`: 0–255 | Маски и компактные скалярные изображения. |
| <xref:Akeldov.Math.Spatial2D.Imaging.Gray16BitColor> | `ushort`: 0–65535 | Карты высот и визуализация расстояний с повышенной точностью. |
| <xref:Akeldov.Math.Spatial2D.Imaging.RGBA8BitColor> | `byte`: 0–255 на канал | Обычные цветные изображения с прозрачностью. |
| <xref:Akeldov.Math.Spatial2D.Imaging.RGBA16BitColor> | `ushort`: 0–65535 на канал | Плавные градиенты и послойная композиция. |

Для оттенков серого ноль означает чёрный, а максимум — белый. Для альфа-канала ноль означает
полную прозрачность, а максимум — полную непрозрачность. У серых цветов нет альфа-канала:
чёрная ячейка маски содержит нулевую интенсивность, а её интерпретацию как пустой или прозрачной
области задаёт использующий маску код.

Конструкторы принимают целочисленные значения каналов. `FromNormalized` принимает значения с
плавающей точкой в диапазоне `[0, 1]`, ограничивает выходящие за него значения и округляет до
ближайшего представимого целого значения канала:

```csharp
using Akeldov.Math.Spatial2D.Imaging;

Gray8BitColor middleGray = Gray8BitColor.FromNormalized(0.5f); // Value = 128
RGBA16BitColor translucentBlue = RGBA16BitColor.FromNormalized(
    red: 0f, green: 0f, blue: 1f, alpha: 0.5f);
```

8-битный канал имеет 256 возможных значений, 16-битный — 65536. Дополнительные биты уменьшают
ошибку квантования при отображении непрерывных значений в цвета, но точность результата остаётся
конечной. Используйте 8-битные цвета для компактного результата и 16-битные, когда важна
дополнительная точность.

Сохраняйте физические величины в числовом растре, пока дальнейшим вычислениям нужны исходные
значения. Отображение знакового расстояния или высоты в оттенки серого требует выбора диапазона;
нормализация, ограничение и округление могут приводить к потере информации. Изображение не
содержит правила восстановления исходных значений.

## Интерполяция и альфа-композиция

Все четыре типа цвета предоставляют `Blend(from, to, amount)`. Метод независимо интерполирует
каждый сохранённый канал, включая альфа-канал RGBA. При нуле возвращается начальный цвет, при
единице — конечный; значения за пределами `[0, 1]` ограничиваются этим диапазоном. Метод подходит
для градиентов и переходов между цветами.

`RGBA16BitColor.AlphaOver(background, foreground)` накладывает передний план на фон с учётом
их альфа-каналов. Порядок аргументов важен. Непрозрачный передний план закрывает фон, прозрачный
оставляет его видимым. При наложении на непрозрачный фон результат остаётся непрозрачным.

```csharp
RGBA16BitColor background = RGBA16BitColor.FromNormalized(0f, 0f, 1f, 1f);
RGBA16BitColor foreground = RGBA16BitColor.FromNormalized(1f, 0f, 0f, 0.5f);

RGBA16BitColor transition = RGBA16BitColor.Blend(background, foreground, 0.5f);
RGBA16BitColor composite = RGBA16BitColor.AlphaOver(background, foreground);
// У transition альфа примерно 0.75; composite полностью непрозрачен.
```

`AlphaOver` использует непредумноженную альфу: RGB-каналы описывают цвет независимо от
альфа-канала. Передавайте полные значения RGB вместе с нужной непрозрачностью. Например,
наполовину прозрачный красный задаётся как `FromNormalized(1f, 0f, 0f, 0.5f)`.

`RGBA16BitColor` также предоставляет `ScaleAlpha(coverage)` для уменьшения непрозрачности при
частичном покрытии. Например, `foreground.ScaleAlpha(0.5f)` вдвое уменьшает его текущий
альфа-канал. `AlphaOver` и `ScaleAlpha` доступны у 16-битного типа RGBA; `Blend` есть и у
остальных типов цвета.

Эти операции вычисляются непосредственно над сохранёнными значениями каналов без автоматического
преобразования цветового пространства. [Геометрическая сцена](rasterization.md#сборка-геометрической-сцены)
может использовать `AlphaOver` как функцию смешивания для накопления слоёв в порядке добавления.

## Экспорт изображений

<xref:Akeldov.Math.Spatial2D.Imaging.RasterPngExtensions> и
<xref:Akeldov.Math.Spatial2D.Imaging.RasterBmpExtensions> предоставляют перегрузки `SaveAsPng` и
`SaveAsBmp` для пути к файлу или потока, доступного для записи.

| Тип ячейки растра | PNG | BMP |
|---|---|---|
| `Gray8BitColor` | 8-битный серый | 8-битный индексированный серый |
| `Gray16BitColor` | 16-битный серый | Нет перегрузки |
| `RGBA8BitColor` | 8 бит на канал RGBA | 32-битный BGRA |
| `RGBA16BitColor` | 16 бит на канал RGBA | Нет перегрузки |

PNG сохраняет разрядность выбранного типа цвета, включая 16-битные каналы и альфа-канал RGBA.
При сохранении 16-битного цветового растра в PNG предварительного перехода к 8 битам нет.
Для экспорта в BMP нужен один из поддерживаемых 8-битных типов цвета.

Экспорт принимает <xref:Akeldov.Math.Spatial2D.Rasterization.IRaster`1>, поэтому сохранять можно
как `Raster<TColor>`, так и `SpatialRaster<TColor>`. В файл попадают разрешение в пикселях и
цветовые значения. Мировые границы и размер ячеек из `RasterGeometry` остаются метаданными
приложения; храните их отдельно, если изображение нужно привязать к мировым координатам.

Числовой или булевый растр перед экспортом требует явного отображения в поддерживаемый тип
цвета. Например, через `MapValues` можно отобразить `false` в `Gray8BitColor.Black`, а `true` в
`Gray8BitColor.White`. Страница [«Растеризация»](rasterization.md#растеризация-полей-и-преобразование-значений)
объясняет связь преобразования значений с сеткой и её пространственной геометрией.
