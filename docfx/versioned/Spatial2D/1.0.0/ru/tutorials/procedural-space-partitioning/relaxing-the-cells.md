# Релаксация областей

Диски Пуассона уже распределяют центры достаточно равномерно, но соответствующие области всё ещё
могут заметно отличаться формой. Релаксация по центроидам перемещает каждый центр к среднему
положению назначенных ему элементов, после чего повторяет разбиение.

Замените создание partitioner следующим кодом:

```csharp
var partitioner = new VoronoiItemPartitioner<MapCell>(
    sites,
    relaxationIterations: 2,
    emptyCellPolicy: EmptyCellPolicy.LeaveAsIs);

IReadOnlyList<VoronoiItemPartition<MapCell>> partitions =
    partitioner.Partition(mapCells);
```

Перед возвратом окончательного результата partitioner выполняет два прохода релаксации. На каждом
проходе он:

1. назначает каждый элемент карты взвешенному центру;
2. вычисляет центроид элементов каждой области;
3. создаёт в центроиде новый центр с прежним весом;
4. снова распределяет исходные элементы карты.

Пустая область сохраняет прежнее положение центра. Веса центров также сохраняются, поэтому более
тяжёлые центры остаются такими после релаксации.

Релаксация использует дискретные положения `mapCells`. Повышение разрешения сетки делает
центроиды точнее, но увеличивает количество сравнений расстояний. Два прохода — подходящая
начальная настройка; дополнительные проходы стоят дороже и не обязательно улучшают нужный стиль.
