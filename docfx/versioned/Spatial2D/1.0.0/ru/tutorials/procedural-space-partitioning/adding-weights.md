# Добавление весов

Равные веса создают обычные области ближайших центров. Больший положительный вес позволяет центру
конкурировать на большей территории: взвешенное разбиение Вороного сравнивает квадрат расстояния,
делённый на квадрат веса.

Замените создание `sites` проекцией с индексом:

```csharp
var sites = samples
    .Select((sample, index) => new Site(
        sample.Point,
        weight: index % 5 == 0 ? 1.8f : 1f))
    .ToArray();
```

Теперь каждый пятый центр имеет вес `1.8`, остальные сохраняют вес `1`. Снова запустите программу
и сравните количество ячеек в областях. Более тяжёлые центры обычно получают больше ячеек, хотя
точный размер зависит также от соседей и близости к границе карты.

Вес центра должен быть неотрицательным и не может быть `NaN`; хотя бы один настроенный центр
должен иметь положительный вес. Центр с нулевым весом получает только элемент, расположенный точно
в нём. Положительная бесконечность поддерживается как доминирующий вес; если бесконечный вес есть
у нескольких центров, побеждает ближайший из них.

Вес описывает относительную область влияния, а не гарантированную площадь ячейки. Удвоение веса не
гарантирует удвоения количества назначенных элементов сетки.

Сохраните взвешенный массив `sites` и переходите к разделу
[«Релаксация областей»](relaxing-the-cells.md).
