# Построение поля

Поле объединяет источники и стратегию, которая вычисляет значение в произвольной точке. Сначала
используйте простейшую стратегию: значение ближайшего источника.

Добавьте код после массива `sources`:

```csharp
var nearestSampler =
    new NearestFloatInfluenceSampler<FloatPointInfluenceSource>();

var field = new FloatPointInfluenceField(nearestSampler, sources);

float valueAtCenter = field.Sample(new PointXY(50f, 34f));
Console.WriteLine($"Значение в центре: {valueAtCenter}");
```

Точка `(50, 34)` совпадает с положением последнего источника, поэтому программа выводит:

```text
Значение в центре: 100
```

<xref:Akeldov.Math.Spatial2D.Fields.FloatPointInfluenceField> копирует переданный список и
предоставляет сохранённые источники через `InfluenceSources` только для чтения. Последующее
изменение массива `sources` не меняет состав уже созданного поля; чтобы заменить набор
источников, создайте новый экземпляр поля.

Поле также вычисляет диапазон исходных значений. В этом примере `field.Min` равен `0`,
`field.Max` — `100`, а `field.DistinctValues` содержит пять значений. Результат `Sample`
ограничивается этим диапазоном, даже если стратегия интерполяции вычислит значение за его
пределами.

Сейчас карта будет состоять из резких областей вокруг источников. На следующем шаге вы замените
стратегию выборки и получите плавные переходы:
[«Выбор стратегии интерполяции»](choosing-an-interpolation-strategy.md).
