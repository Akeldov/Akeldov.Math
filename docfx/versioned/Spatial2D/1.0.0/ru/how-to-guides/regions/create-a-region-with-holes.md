# Создать регион с отверстиями

Используйте `ContourBasedRegion`, когда заполненная область ограничена несколькими замкнутыми
контурами. При правиле чётности внешний контур создаёт заполненную область, а каждый вложенный
контур переключает её между заполненным и пустым состояниями.

## Определите границы

Создайте внешнюю границу и отверстие как отдельные экземпляры `IContour`. Конкретные типы
контуров могут различаться: в этом примере круглое отверстие находится внутри прямоугольного
составного контура.

```csharp
using Akeldov.Math.Spatial2D;
using Akeldov.Math.Spatial2D.Contours;
using Akeldov.Math.Spatial2D.Regions;

var outerBoundary = new CompositeContour(
    new PointXY(0f, 0f),
    new PointXY(12f, 0f),
    new PointXY(12f, 8f),
    new PointXY(0f, 8f));

var holeBoundary = new Circle(
    center: new PointXY(6f, 4f),
    radius: 1.5f);
```

Перечисляйте вершины многоугольника в порядке обхода границы. `CompositeContour` соединяет
последнюю вершину с первой, поэтому повторять первую вершину не нужно.

## Примените правило чётности

Передайте оба контура в `ContourBasedRegion`:

```csharp
var region = new ContourBasedRegion(
    new IContour[] { outerBoundary, holeBoundary },
    FillRule.EvenOdd);
```

`EvenOdd` используется по умолчанию и пока является единственным поддерживаемым правилом, поэтому
аргумент можно опустить. Точка принадлежит региону, если она охвачена нечётным числом контуров.
Порядок контуров и направление их обхода не влияют на результат.

## Проверьте результат

Используйте `Contains`, чтобы различить заполненную область, отверстие и пространство снаружи:

```csharp
bool inFilledArea = region.Contains(new PointXY(2f, 4f)); // true
bool inHole = region.Contains(new PointXY(6f, 4f));       // false
bool outside = region.Contains(new PointXY(14f, 4f));     // false
```

`Distance` возвращает кратчайшее расстояние до любого задающего контура. `SignedDistance`
делает это расстояние отрицательным в заполненной области и положительным в отверстии или за
пределами внешней границы:

```csharp
float filledDistance = region.SignedDistance(new PointXY(2f, 4f)); // -2
float holeDistance = region.SignedDistance(new PointXY(6f, 4f));   // 1.5
float boundaryDistance =
    region.SignedDistance(new PointXY(6f, 5.5f));                   // 0
```

Благодаря этому соглашению регион можно напрямую использовать при растеризации знакового
расстояния и в других потребителях `ISignedPointDistanceProvider`.

## Добавьте другие отверстия или заполненные острова

Добавьте отдельный контур для каждого дополнительного отверстия. Контур, вложенный в отверстие,
снова переключает заполнение и создаёт заполненный остров. При более глубокой вложенности
заполненные и пустые области продолжают чередоваться при пересечении каждой границы.

Контуры должны быть вложенными или непересекающимися. Конструктор принимает пересекающиеся и
касающиеся контуры, но для них ожидаемая граница и расстояние могут оказаться неоднозначными.
Каждый контур должен быть ненулевым, а коллекция должна содержать хотя бы один контур.

Конструктор копирует ссылки на контуры в закрытое хранилище. Свойство `Contours` предоставляет
структурное представление только для чтения, поэтому вызывающий код не может добавлять, удалять
или менять местами границы региона через публичный контракт.
