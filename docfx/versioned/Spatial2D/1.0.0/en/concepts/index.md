# Concepts

Conceptual documentation explains the ideas and design decisions behind Spatial2D: coordinate
systems, geometry models, fields, samplers, partitioning, rasterization, imaging, units, and ownership rules.
Use this section to understand how the library represents a problem and how its APIs relate to one
another.

See [Rasterization](rasterization.md) for sampling geometry and fields on a grid, and
[Imaging](imaging.md) for color types, alpha composition, and image export.
