# Akeldov.Math.Spatial2D

Akeldov.Math.Spatial2D provides practical two-dimensional geometry, vector math, curves, contours, regions, rasterization, spatial sampling, partitioning, and influence fields.

## Install

```powershell
dotnet add package Akeldov.Math.Spatial2D
```

## Highlights

- Points and vectors
- Linear, circular, and Bézier curves
- Contours and regions
- Rasterization and imaging
- Poisson disk sampling and weighted Voronoi partitioning
- Point and curve influence fields

[View the package on NuGet](https://www.nuget.org/packages/Akeldov.Math.Spatial2D/)
