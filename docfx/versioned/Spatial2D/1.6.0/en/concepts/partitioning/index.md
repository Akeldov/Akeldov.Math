# Partitioning

- [Partition a rectangle into Voronoi regions](voronoi-regions.md) builds geometric cells from site positions and weights. Each nonempty cell has a region bounded by one or more closed contours.
- [Voronoi item partitioning](voronoi.md) assigns each supplied object to a site and returns groups of objects.

Use [samplers](../samplers/index.md) to generate initial site positions.
