# Семплер случайных точек

<xref:Akeldov.Math.Spatial2D.Sampling.Point.UniformRandom.RandomPointSampler> генерирует заданное
число точек в прямоугольнике. Каждая точка выбирается независимо и с равномерным распределением
по площади. Поэтому в выборке встречаются скопления и пустые участки, а координаты двух точек
могут совпасть. Если важно выдержать минимальное расстояние между соседними точками,
используйте [семплер Пуассона](poisson-disk.md).

## Генерация точек в прямоугольнике

В примере семплер генерирует 128 точек в мировых координатах. Угол прямоугольника с минимальными
координатами находится в `(-56, 32)`, поэтому точки можно сразу использовать в сцене.

```csharp
using System;
using System.Collections.Generic;
using Akeldov.Math.Spatial2D;
using Akeldov.Math.Spatial2D.Regions;
using Akeldov.Math.Spatial2D.Sampling.Point.UniformRandom;

var bounds = new Rectangle(new PointXY(-56, 32), new PointXY(248, 224));
var sampler = new RandomPointSampler(new Random(42));
List<PointXY> points = sampler.Sample(bounds, count: 128);
```

![128 случайных точек внутри прямоугольника, видны небольшие скопления и пустые участки](~/assets/spatial2d/samplers/uniform-random-points.png)

На рисунке показана выборка для начального значения генератора `42`. Следующий вызов того же
семплера продолжит последовательность. Чтобы повторить пример в той же среде выполнения,
создайте новый семплер с тем же начальным значением.

Для прямоугольника с началом в `(0, 0)` достаточно передать размер, например
`sampler.Sample(new VectorXY(304, 192), count: 128)`. Оба размера должны быть положительными.
Каждый вызов возвращает новый изменяемый список `List<PointXY>`, принадлежащий вызывающему коду.
При нулевом количестве точек список будет пустым.
