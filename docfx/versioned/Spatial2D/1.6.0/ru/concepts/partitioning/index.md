# Разбиения

- [Разбиение прямоугольника на области Вороного](voronoi-regions.md) строит геометрические ячейки по положениям и весам сайтов. У каждой непустой ячейки есть регион с одним или несколькими замкнутыми контурами.
- [Разбиение элементов Вороного](voronoi.md) назначает каждый из переданных объектов одному сайту и возвращает группы объектов.

Начальные положения сайтов можно сгенерировать с помощью [семплеров](../samplers/index.md).
