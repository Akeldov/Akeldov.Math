# Akeldov.Math.Spatial2D

Spatial2D предоставляет двумерную геометрию, кривые, контуры, регионы, растеризацию,
пространственную выборку, разбиение и поля влияния.

## Установка

```powershell
dotnet add package Akeldov.Math.Spatial2D --version 1.6.0
```

## Новое в 1.6.0

- Метод `bounds.PartitionByVoronoi(sites)` разбивает прямоугольник на регионы. При равных весах границы прямые, при разных положительных весах могут появиться дуги окружностей. У ячейки могут быть отверстия или несколько компонент.
- Метод `GetCentroid()` возвращает центроид ячейки с ненулевой площадью. Параметр `relaxationIterations` задаёт число шагов релаксации к центроидам.
- `RandomPointSampler` генерирует заданное число независимых случайных точек. Для выборки Пуассона метод `SamplePoissonDiskSites` берёт минимальное расстояние из поля в мировых координатах.
- В пространственном RGBA-растре можно заливать регионы и задавать цвет по расстоянию. Пространственные растры с элементами `bool`, `int` и `float` поддерживают преобразования между обобщённым и специализированным типами в обе стороны.

Пакет поддерживает .NET Standard 2.1 и .NET 6. Конструктор `VoronoiItemPartition<TItem>` по-прежнему копирует переданные элементы. Используйте `FromList`, если последующие изменения списка должны быть видны в разделе.
