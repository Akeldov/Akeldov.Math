# IntRaster

<xref:Akeldov.Math.Spatial2D.Rasterization.IntRaster> предназначен для целочисленных счётчиков и меток без привязки к мировым координатам.

## Операции

Поддерживает поэлементные `+`, бинарный `-` и унарный `-`. Сложение и вычитание со скаляром
работают в обоих порядках. Растровые операнды могут быть специализированными или общими
контейнерами с соответствующим типом значения.

Целочисленная арифметика использует unchecked-переполнение: значения переходят через границу диапазона, а не ограничиваются ею.

```csharp
using Akeldov.Math.Spatial2D;
using Akeldov.Math.Spatial2D.Rasterization;

var resolution = new VectorXYInt(2, 2);
var raster = new IntRaster(resolution, new[] { 1, 2, 3, 4 });
IntRaster shifted = raster + 2;
IntRaster difference = shifted - raster;
IntRaster inverted = -raster;
```

## Хранение и совместимость

Конструктор сохраняет массив. `Values` и индексаторы предоставляют изменяемое состояние.
Операторы создают новые изменяемые результаты, принадлежащие вызывающему коду, и не меняют операнды.

Для двух растровых операндов требуется одинаковое разрешение; автоматического изменения размера нет.

См. [Растры без пространственной привязки](../non-spatial-rasters.md).
