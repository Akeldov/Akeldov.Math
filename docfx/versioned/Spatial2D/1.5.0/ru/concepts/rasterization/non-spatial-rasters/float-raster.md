# FloatRaster

<xref:Akeldov.Math.Spatial2D.Rasterization.FloatRaster> предназначен для вещественных полей и расстояний без привязки к мировым координатам.

## Операции

Поддерживает поэлементные `+`, бинарный `-` и унарный `-`. Сложение и вычитание со скаляром
работают в обоих порядках. Растровые операнды могут быть специализированными или общими
контейнерами с соответствующим типом значения.

```csharp
using Akeldov.Math.Spatial2D;
using Akeldov.Math.Spatial2D.Rasterization;

var resolution = new VectorXYInt(2, 2);
var raster = new FloatRaster(resolution, new[] { 1f, 2f, 3f, 4f });
FloatRaster shifted = raster + 0.5f;
FloatRaster difference = shifted - raster;
FloatRaster inverted = -raster;
```

## Хранение и совместимость

Конструктор сохраняет массив. `Values` и индексаторы предоставляют изменяемое состояние.
Операторы создают новые изменяемые результаты, принадлежащие вызывающему коду, и не меняют операнды.

Для двух растровых операндов требуется одинаковое разрешение; автоматического изменения размера нет.

## Фильтрация и генерация

`GaussianBlur(sigma)` и `GaussianBlur(sigma, radius)` возвращают новый `Raster<float>`.
Sigma и радиус измеряются в ячейках; на границах веса нормализуются по доступным ячейкам.
`resolution.CreatePerlinNoise(seed: 42, scale: 10f)` создаёт новый `Raster<float>`
со значениями `[0, 1]`. Эти методы возвращают общие контейнеры; для арифметических операторов
оберните их `Values` в `FloatRaster`, учитывая совместное использование массива.

Масштаб шума измеряется в ячейках растра.

См. [Растры без пространственной привязки](../non-spatial-rasters.md).
