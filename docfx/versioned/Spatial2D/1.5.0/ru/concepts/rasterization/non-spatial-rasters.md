# Растры без пространственной привязки

Растр без пространственной привязки хранит прямоугольную сетку значений и её разрешение,
но не положение и размер в мировых координатах. Он подходит для масок, счётчиков, числовых
буферов и изображений, доступных по индексам ячеек.

`Raster<T>` — общий контейнер; булев и числовые варианты добавляют поэлементные операторы.
Конструкторы сохраняют переданный массив, а индексаторы и `Values` позволяют менять значения.
Интерфейс <xref:Akeldov.Math.Spatial2D.Rasterization.IRaster`1> предоставляет доступ только для
чтения, но не делает сам буфер неизменяемым.

## Хранение и операции

Значения идут по строкам: ячейке `(x, y)` соответствует индекс `y * Resolution.X + x`.
Компоненты разрешения должны быть положительными, а длина массива — равна числу ячеек.
Доступ возможен через `raster[x, y]`, `raster[index]` или индекс `VectorXYInt`.

`MapValues` создаёт новый `Raster<TResult>`. Специализированные операторы также возвращают новые
изменяемые растры, принадлежащие вызывающему коду. Для двух растров требуется одинаковое
разрешение; автоматического изменения размера или пересэмплирования нет.
Для привязки к мировым координатам используйте [пространственные растры](spatial-rasters.md),
а для пиксельных значений — [цветовые растры](color-rasters.md).
