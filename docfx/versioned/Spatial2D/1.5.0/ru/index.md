# Akeldov.Math.Spatial2D

Spatial2D предоставляет двумерную геометрию, кривые, контуры, регионы, растеризацию,
пространственную выборку, разбиение и поля влияния.

## Установка

```powershell
dotnet add package Akeldov.Math.Spatial2D --version 1.5.0
```

## Новое в 1.5.0

- Рисование в пространственных RGBA-растрах: кривые, контуры, заливка кругов и прямоугольников,
  стрелки со сплошным или пунктирным стержнем, координатные сетки с подписями.
- Текст с кэшированными глифами TrueType или встроенным пиксельным шрифтом 5×7:
  прописные и строчные латинские и русские буквы, включая Ё/ё.
- Затемнение и осветление цветов в sRGB, линейном RGB и OKLCH.
- Ускорение рисования кривых за счёт отбрасывания незатронутых участков растра
  с сохранением существующей модели покрытия.

Релиз сохраняет публичный API версии 1.4.0 и поддерживает .NET Standard 2.1 и .NET 6.

[концепции](concepts/index.md) и [учебники](tutorials/index.md).
