# Points

Akeldov.Math.Spatial2D represents positions in two-dimensional Cartesian space with [`PointXY`](pointxy.md).

## Point Types

- [`PointXY`](pointxy.md) — an immutable point with single-precision floating-point X and Y coordinates for world-space positions, curve endpoints, region centers, and sample locations.

Use vectors for directions, offsets, and displacement calculations. See the [Vectors](../vectors/index.md) overview for the available vector types.
