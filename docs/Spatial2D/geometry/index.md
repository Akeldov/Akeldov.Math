# Geometry

Geometry contains the core spatial primitives: points, vectors, and curves.

Use [Points](points.md) for positions, [Vectors](vectors.md) for offsets and directions, and [Curves](curves/index.md) for one-dimensional geometry such as lines, rays, segments, circles, and arcs.

Higher-level sections build on these primitives:

- [Contours](../contours/index.md) use bounded parameterized curves.
- [Regions](../regions/index.md) use contours and rectangle primitives for filled area membership.
- [Rasterization](../rasterization/index.md) samples geometry into image-like rasters.
