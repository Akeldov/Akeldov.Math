# Sixfold Angles

Sixfold angles represent the six 60-degree directions natural to a hex grid.

## Values

- `Deg0`.
- `Deg60`.
- `Deg120`.
- `Deg180`.
- `Deg240`.
- `Deg300`.

## Helpers

- Ordered angle access through `SixfoldAngles`.
- Sine and cosine lookup.
- Radian and degree conversion.
- Opposite angle lookup.

## Rotations

- Add 60 degrees.
- Add 120 degrees.
- Add 180 degrees.
- Add 240 degrees.
- Add 300 degrees.
