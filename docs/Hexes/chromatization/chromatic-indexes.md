# Chromatic Indexes

Chromatic indexes assign stable classes to hex indexes and vertex neighborhoods.

## Hex Classes

- Calculate chromatic class values for hex indexes.
- Preserve layout-aware behavior.
- Use compact byte values for chromatic classes.

## Vertex Triplets

- Calculate chromatic classes for vertex triplets.
- Preserve the same vertex ordering as topology triplet grids.
- Feed chromatic triplet grids and rasterization helpers.
