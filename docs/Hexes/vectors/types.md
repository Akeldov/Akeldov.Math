# Vector Types

QRS vector types are the primary coordinate values used by Hexes APIs:

- [`VectorQRS`](vectorqrs.md) stores fractional QRS coordinates for continuous calculations and transformations.
- [`VectorQRSInt`](vectorqrsint.md) stores integer QRS coordinates for discrete hex indexes and offsets.

See the [Vectors overview](../vectors.md) for a side-by-side comparison.
