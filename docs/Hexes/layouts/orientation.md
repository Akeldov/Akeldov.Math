# Orientation

Orientation helpers classify layouts into pointy-top or flat-top hex fields.

## `HexOrientation`

- Represents the geometric orientation of a hex.
- Separates row-oriented and column-oriented behavior.
- Supports pointy-top and flat-top geometry calculations.

## Layout Extension Helpers

- Detect row-based layouts.
- Detect column-based layouts.
- Reject unsupported layout values.

## Geometry Impact

- Orientation controls center spacing.
- Orientation controls vertex order.
- Orientation controls bounding-box formulas.
