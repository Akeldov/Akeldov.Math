# Akeldov.Math.Hexes

Akeldov.Math.Hexes is a .NET library for hex-grid coordinate systems, topology, geometry, rasterization, and partitioning utilities.

## Features

- QRS axial vector types and layout conversion helpers.
- Odd/even row and column hex layouts with center, vertex, and adjacency helpers.
- Hex maps and grids for topology, barycentric sampling, chromatic indexes, and rasterization.
- Polyhex masks, contours, apothem offsets, and region conversion helpers.
- Weighted Voronoi partitioning over hex center maps.
